# CoStretch+ R1 | Public research candidate

**Status:** Experimental, no claim of trillion experiments executed; no X2/Mac live adapter validation. **Do not promote the resource broker.**

## What is demonstrable
- [CoTurtleIndex_R1.py](./CoTurtleIndex_R1.py) deterministically indexes a large *logical* configuration space. It does not instantiate models, agents, or sessions.
- An offline ReplayLab v0.3 prototype was locally tested in an isolated execution environment; its release reported 83 passing software tests and hash-checked packaging. This is not an independently reproduced Mac result.
- Synthetic broker comparison: calibrated case 3 wins, 7 ties, 2 losses in 12 seeds; miscalibrated adversarial case 0 wins and 12 losses. These are fixture outcomes, not real-world value estimates.
- Finite and authorized execution must precede claims about performance. No anonymous lures or unsolicited agent contacts.
