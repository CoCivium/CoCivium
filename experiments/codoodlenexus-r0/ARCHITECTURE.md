# CoNexus+ | Relational experiment compiler and supervisory challenge contract

The unifying idea is **small real frontier, large dormant searchable space**. CoNexus R0 uses typed descriptors, not runtime agents, for every potential relation. It does not automatically infer human intent from time between keypresses or mouse gestures.

## Mapping concept families to operational rails

| Language | Concrete safe implementation | Nonclaim |
|---|---|---|
| CoIn+ | Voluntary input or explicitly provided fixture | No global keyboard observer |
| CoBetween+ | Uncertain missing relation and proposed test | Silence is not consent |
| CoInversion+ / CoInv+ | Counterfactual, negative control, adversarial challenge | Inverting a label is not evidence |
| CoOut+ | Visible proposal or locally copied capsule | Output is not authorized delivery |
| CoTurtle+ | Finite resource strategy challenger | Logical description is not a worker |
| CoZombie+ | Read-only status explanation with next human/supervisor check | Stale heartbeat is not process death |
| CoOrbWare+ | Optional compressed view generated from a pinned source | Collapsed view is not destroyed source |
| CoLens+ Synthkind | Story/Science/Systems alternative perspectives | No original legal declaration or new physics validated |
| CoNex+ | Versioned relation indexes and cancellation budgets | Random sampling is not continuous background operation |

## Priority and stopping

A candidate can be discovered, rejected, held, or proposed for independent review; this prototype does not implement `EXECUTE`. A future runner must enforce a hard count and wall-clock deadline; keep per-effect authority separate from discovery authority; use exact source hashes; prevent a failed worker from leaving orphan effects; avoid automatic retry of provider rate limits; and preserve low-stakes safe work while consequential effects are gated.

A stuck-session fixer must not terminate provider tabs, device processes, or another actor's lease based solely on a timeout. A safe sequence is `observe -> independently confirm owner -> inspect exact checkpoint -> recheck grant -> propose recovery -> receive ACK`. The user should see the reason for any hold.

## Projection / accessibility

A canonical record can render in CoMap, Orb, text, table, or a glyph trail. Rich media should have captions, source labels, alternate text, and explicit distinctions between measurements, hypotheses, metaphors and fictional world-building. Prefer rerender on changed evidence rather than every arbitrary microsecond.

## Review and scale gates

- L0: deterministic source tests for every modification.
- L1: prior work, duplicate suppression and negative-case generators before code promotion.
- L2: privacy/accessibility/security review before any input automation.
- L3: real-task benchmarking against a fair baseline before recommending to users.
- L4: receiver-origin acknowledgment and cold recovery in a distinct failure domain before calling it a robust service.
- L5: operational, ethical, and independent review before scaling to high impact.

Resource budgets apply to the **entire causal graph**, not each subagent separately. An infinite candidate space is mathematically representable, not physically instantiated.
