CoAkimbo / CoInterstice R0 reproducibility

After extracting the ZIP and entering CoAkimbo_Interstice_R0:

python -m pip install -r requirements.txt
python verify_package.py
python -m unittest discover -s tests -v
python src/optical_control.py
python src/gain_control.py
python src/evidence.py

Open CoAkimbo_Viewer.html in a trusted local browser to view the source-bound figure.
The figure itself is regenerated by optical_control.py.

Do not run physical laser or altered-state experiments based on this simulation.
Web page browser opening on an actual Mac/Windows machine is NOT YET independently verified.
