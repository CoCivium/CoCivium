# CoSpiff+ | Differentiation and learning notes

Source observations as of 2026-10-24. Reference ecosystems are not CoCivium partners and have not endorsed this work.

| Ecosystem | Observed pattern | CoCivium translation | High-bar test |
| --- | --- | --- | --- |
| [rUv / ruvnet](https://github.com/ruvnet) | Public "constellation" organizes Ruflo orchestration, RuVector memory, RuView sensing, RVM portability, and MetaHarness evaluation as complementary roles. | One recognizable specialist entrance per task, all joining the same provenance/authority fabric. | Unfamiliar developer can choose correct first tool without learning all subproduct names. |
| [Backstage](https://backstage.io/docs/overview/technical-overview/) | Typed catalog of components, APIs, owners, resources, systems, and domains, with templates and permissions. | Catalog CoGlukey descriptor per resource, with maintainer, actual capability, dependency, limits, fallback, privacy and verified deployment. | Can retrieve the qualified owner and exact source of a resource without making up a vendor or permission. |
| [Docusaurus](https://docusaurus.io/docs/sidebar) | Hierarchical sidebars, progressive navigation and explicit doc versioning. | One-default/five-optional route layout, version-pinned evidence, visible historical/noncurrent versions. | Fewer wrong turns for first-time readers, older documentation discoverable without masquerading as current. |
| CoCivium internal [Start Here](https://github.com/CoCivium/CoCivium/blob/main/START_HERE.md) | Already a simple first task + optional specialist paths; the machine twin pins six Git source objects. | **Reuse; do not fork more brands.** The missing piece is measurable independent first-use experience. | Real volunteer can complete same task and understand what was / wasn't proven. |

## What "copetition" should mean here

Shared evidence/authority/interoperability contracts, voluntary independent implementations, benchmarked alternatives, no assertion of partnership. Competition on *verified usefulness per unit of time, attention, cost and risk*, not on clever name count or manufactured activity.

## Candidate CoSpiff feedback loop

`GOAL -> 1 DEFAULT DOOR -> OPTIONAL SPECIALIST -> FIRST RESULT -> SOURCE CHECK -> USER CORRECTION -> CHALLENGE -> BETTER ROUTING`

A wrong choice should never trap somebody. Every specialist path offers a clear return to the default task; the system must never silently move profile, privilege or contact details across routes.

## Source and rights disclaimer

FOSS-first is a project principle, not blanket relicensing of rUv, Backstage, Docusaurus, or independent visitors' contributions. A snapshot proves only those sources that were actually checked, not every current website or system state.
