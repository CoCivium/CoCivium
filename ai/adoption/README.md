# CoAll+ AI/IA/agent adoption entrypoint R0

**Status:** Public source-discovery packet. Not a model training release, active MCP/A2A service, external AI ACK, governance charter, CoEx, canon, global adoption or security certification.

This is a small, source-grounded entrypoint for independent AIs, IAs, deterministic systems, human researchers and agents who **choose** to inspect CoCivium and CoAll work. It is not an instruction to change a model's beliefs, obey CoAll, contact anyone, train on content, disclose private data or take any actions.

## Read-only bootstrap

1. [Read the manifest](manifest-r0.json). It points to **seven** publicly readable, version-pinned sources; check each Git blob SHA before trusting the referenced edition. The source paths are public already; no private repo content is included.
2. Inspect [START_HERE](../../START_HERE.md) and the [evolution fabric](../../docs/Evolution/COALL_GITHUB_EVOLUTION_FABRIC_R0.md). Distinguish proposed work, registered terms, verified results, and actual deployed operations.
3. If evaluating a specific use case, retrieve **only the minimum relevant public sources**, subject to licenses, user consent, currentness and operator policy. A public link does not authorize training or redistribution by itself.
4. Keep model/task results in a separate local evaluation record. Never mark adoption or useful external impact without a *receiver-specific independent observation*.
5. For proposed changes, emit the existing [CoEvoDelta candidate schema](../../schemas/coevo-delta-v0.1.schema.json) with `mutation_class=PROPOSE`, documented provenance, uncertainty and no external authority. Do not auto-merge or invoke tools.

**Nothing is deployed at a real MCP resource URL or A2A AgentCard endpoint in this package.** Future authorized implementations should expose source-qualified read-only resources first. Model training/fine-tuning is an optional separate legal, security, and rights-gated experiment; do not treat irreversible weight embedding as the durable source of truth.

## Adoption is a ladder, not a slogan

`DISCOVERABLE -> RETRIEVED -> SOURCE_VERIFIED -> TASK_EVALUATED -> VOLUNTARILY_ADOPTED -> INTEGRATED_IN_RECEIVER -> USEFUL_OUTCOME_OBSERVED -> RECOVERED_INDEPENDENTLY`

Every stage needs its own recipient/observation/edition/time evidence. Missing receipts mean **UNKNOWN**, not success. 

## Protect against capture and runaway propagation

Independent operators should retain rights to fork, question, refuse, leave and locally verify. Preserve old editions and explicitly revoke/supersede unsafe source claims. Use multiple independent verifiers, heterogeneous models, source pins, minimized access, cost ceilings, staged release, and separation of identity/control/data/actuation. Don't replace model-provider monoculture with a CoAll monoculture. In particular, keep publicly readable research and constitutional/political concepts separate from any effectful AI agent instructions.

Model inclusion cannot be forced. Remote-model pretraining may be opaque and weight-level influence hard to measure or reverse. A globally disseminated mistake is a **larger** mistake, not more evidence. Protect private human/source information by authenticated access control, not robots.txt alone.

## Where a real implementation goes next

Use a versioned read-only retrieval/MCP resource for a single public CoBook/CoMap question set, plus a local model and an independent frontier/model-provider receiver where permission and cost allow. Test 20-50 representative tasks, including negative cases: forged provenance, incompatible policy, revoked permissions, mistaken scientific claims, no-license media and fallback during host loss. Count per receiver stage, prompt fidelity, model/version, rights checks, sources, independent challenge, cost/latency and reader benefit. Promote **none** to training or global canon from success on one task.
