# CoMap+ / CoOrb+ ForwardCursor R1

**CoHereNow:** Offline, single-file, keyboard-navigable projection canary. It reuses the public architecture's CoDot/CoQuanta, CoTime/PulseField, living-highlight, and receiver-relative subscription ideas instead of installing another runtime.

**Meaning:** Relation-space may be n-dimensional but visual space is a lossy 2D viewport. Keep stable IDs, time, epistemic class, provenance, authority, privacy, wake/stop, and projection-loss descriptors in the source graph; create quiet maps, orb glances, trace timelines, desktop panels, and accessible text twins from that graph. Visual adjacency is not proof of reality.

## Explore

Open `index.html` locally in a modern browser. No server, account, device permission, or external library required. Default: Glance view, five links, future/predicted hidden. Local deterministic input lookahead is on but sends and stores nothing. Use Map/Trails, time lens, optional speculative checkbox, keyboard tab and Enter/Space to inspect any visible edge/node; text list in the details panel is a semantic alternative.

No external network is requested by the application; selecting an outbound source link is a separate user-initiated browser action.

## Proposed render contract

- **CoDot+ / CoQuanta+:** addressable typed unit, not a quantum particle or evidence of consciousness.
- **CoMap+:** one view of selected source-bound relations; location, colour, and visual weight are never treated as evidence.
- **CoOrb+ / CoVIA+:** replaceable glance/interaction projections, not a globally authoritative state or a live subscribed receiver by default.
- **CoTime+:** preserve multiple clocks, forecast class, expiry, replay cursors, and outcome-calibration paths.
- **CoGRAIL+ / node mesh:** federated optional receiver topology with privacy boundaries, opt-in participation, and exact pickup proof.
- **CoOrbWare+/desktop:** surface adapter candidates, user-toggleable and resource-budgeted; no automatic wallpaper, screensaver, camera, microphone, or wearables.
- **CoSpirit+ / G_d / nonmaterial:** if represented at all, retain explicit interpretive/hypothetical/metaphoric type; do not turn absence or metaphors into observed facts.

## R1 delta: input ahead of the cursor, CoAckRAW / ReWise candidate

- From caret-local typed **prefix**, show a deterministic next-term and related **public** architecture link (if any). Not a language model, not a user's intention, no private graph lookup, no network, no data retained.
- `Insert suggested term` modifies only the input text; `Review locally` marks a temporary candidate *locally*; editing invalidates prior review; `ReWise / clear` withdraws the candidate. No actual external `CoAck`, receiver readproof, or transmission takes place.
- The `EVO ALL BETTERS +` visible control switches to the Map lens with a bounded review task. It is keyboard/touch compatible. **There is no automatic middle-button/thumb-button OS binding**; that requires distinct user-configured native adapter/permission and tested undo.
- `CoForward`: `RAW_INPUT -> LOCAL_LOOKAHEAD -> REVIEW_OR_REVISE -> OPTIONAL_OUTBOUND_EFFECT_GATE`. Prediction and review never grant effect authority.
- **All-to-all** means all eligible *relations discoverable* and per-receiver selective, consent-bound projections, **not all private data or raw keypresses broadcast**.
- The renderer is an optional read-only surface. A provider-neutral logical session/checkpoint is not proof an external model account is replaceable. Paid account exit requires tested export, cold-start recovery, provider-specific feature comparison, independent custody and explicit user account closure.
