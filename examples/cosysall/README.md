# CoSysAll+ Semantic Zoom R0 | Source-bound multi-surface demonstrator

**[Open/save the interactive HTML](semantic-zoom-r0.html)**. GitHub may show HTML source rather than execute it; save the single file and open it in a browser.

**State:** browser-tested offline experiment, not a live world-scale CoMap, a deployment on X2 or CoStead, independent hosting, a new universal CoAll ontology or an infinitely detailed image.

## What you can do

1. Switch among **seven semantic depth levels**. Far away shows five source-kind constellations. Deeper levels reveal registered objects, source links, local neighborhoods, provenance, in-between relations and a deliberate **evidence boundary**, not imaginary pixels.
2. Switch among **Registered**, **In-betweens**, **Inversions** and **CoProduce** lenses. Reverse links are questions, not asserted facts. Null/missing relationships remain unknown.
3. Search for CoTheoryAll, CoRails, CoLex, CoBook or other **registered** terms, then click related objects to grow a persistent local navigation path.
4. Choose a rendering surface: **visual canvas**, **accessible navigable list** or **machine-only structured JSON**. Machine-only explicitly renders **zero** canvas primitives.
5. Reduce the node-draw budget. Culling suppresses lower-priority detail without deleting its data.
6. Generate a **local micro-evolution proposal** from a registered two-hop link. It remains `LOCAL_UNVERIFIED`, carries source edge IDs, and grants no effect authority. Export a typed local JSON packet.
7. Follow curated links to the existing AGI reader, CoDemoWow truth gate and prior CoMap exemplar.

## Grounded R0 source and test

- **56 registered objects** across the public source-kind graph: 21 evolution domains, 21 named repositories, 10 highlights, 3 source documents and 1 view.
- **61 registered edges**, based on the existing [CoMap public source projection](../../ai/comap-source-projection-r0.json), itself sourced from [evolution lanes](../../ai/evolution-lanes.json), [repository roles](../../ai/repo-role-map.json) and [highlight assets](../../ai/highlight-assets.json). Source registries include September 2026 timestamps. This reader is **historical**, not a current X2/CoAll service-health report.
- A separately preserved R0 source JSON, tested HTML and QA report are held in the private CoCivium PublicationPackets Library. Exact local source JSON SHA-256: `5590f884a2e159492f7b3ee64c0f99b490f9f54eae22961adce9f6fb2a8a4994`. HTML SHA-256: `c9d07b71b51ea3dcc95c44b368ea3ee58bf9af923702c08bf0a72dceb5a2e357`.
- **Browser tests:** Desktop 1440×900 and mobile 390×844 both passed initial 56/61 read, depth transition and evidence boundary, interstitial lens, CoTheoryAll selection, local two-hop proposal, machine-only zero draw, accessible list, return to canvas and no horizontal overflow. **Zero JS page errors**, no outgoing network requests. QA tested supplied HTML via browser content injection because container browsers blocked file and localhost navigation; this does not establish remote-host behavior.
- **Limits:** No tiled IIIF imagery or spatial 3D source, no real background work, hardware GPU benchmark, independent external reader acceptance, model/provider interchange, cross-provider cold restore, schema adoption, CoEx, X2 or CoOrb runtime effect.
