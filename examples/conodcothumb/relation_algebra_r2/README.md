## The fix that matters

`INVERSE` / `CONVERSE` / `NEGATE` / `ELSE` / `NULL` / `OUTSIDE` / `COUNTERFACTUAL` / `UNKNOWN` mean different things. A reversed relationship is not necessarily a negation; an analogy is not science; absence is not observed unless the domain and completeness are verified.

Examples of **proposed symbolic transformations**, not new facts:

| Original statement type | Proposed converse | What it does *not* prove |
|---|---|---|
| A `DEPENDS_ON` B | B `IS_DEPENDENCY_OF` A | B can substitute for A |
| A `DERIVES_FROM` B | B `IS_SOURCE_FOR` A | Source content has been authenticated |
| A `SUPERSEDES` B | B `SUPERSEDED_BY` A | B is erased or false |
| A `ROUTES_TO` B | B `IS_ROUTE_TARGET_OF` A | B received or consented |
| A `CAUSES` B | B `CAUSED_BY` A | Causation without evidence |
| A `GREATER_THAN` B | B `LESS_THAN` A | Comparison without compatible units |
| A `CONNECTED_WITH` B | B `CONNECTED_WITH` A | Bidirectional influence |
| `NOT(A DEPENDS_ON B)` | No automatic converse | That a negative claim is true |

For each relation, preserve `semantic_id | original_source | context | relation_class | converse_type | symbol | plain-language label | uncertainty | evidence_gate | privacy | time | authority | version`. CoGibberTru/CoPriMath is a *projected compressed representation*, not an independent source of truth. Existing R1 supplies the real offline context rail, Q&A&@ questions, privacy policy and accessibility interface.

## Exact generated field, not a live swarm

- 16 directional relation pairs and four symmetric types = **36** typed relation IDs.
- Seven distinct symbolic transformations × 13 contexts × 17 questions × eight surfaces = **445,536 syntactic addresses**.
- A seeded, deterministic sampling cap of 32 addresses. Expansion from seven to 32 does **not** reshuffle the first seven.
- Source pointer syntactic validation is *not* source byte verification. Private local source pointers are always redacted in the output.
- No Logitech mapping, keyboard hook, network request, clipboard access, provider call, model session, private input capture, filesystem mutation or real experiment execution.

The full R1 contains another **2,313,360** candidate context combinations; do not add or multiply these counts and call the result independent use cases, valuable experiments, workers, or proof of adoption.

## Reproduce locally

With Node.js 22 or newer:

```
node CoRelationInverseR2.cjs
node --test CoRelationInverseR2.test.cjs
node bench.cjs
```

The test suite checks all directed converse pairs in both directions, symmetric forms, non-converse transforms, fail-closed privacy, ordinary middle-button pass-through, nonexistent source/authority rejection, null-result isolation, deterministic lazy addressing and sample stability.

**Observed in one isolated Linux process:** **79/79 PASS**. Five timed 10k-operation passes after three warmups, on AMD EPYC 9V74 / Node v22.16.0: median amortized **0.448 microseconds per decoded address** and **0.313 microseconds per typed shadow preview**. Not OS latency, device UI, live reasoning, useful-experiment execution, a guarantee, or measured energy.

**Preserved negative case:** First mixed-radix prototype incorrectly expanded relation IDs as a character array: the sample printed single letters instead of relation IDs. The source fix and regression tests preserve correct typed output. That is a fixed implementation bug, not an observed failure of R1 or a live mouse.

## How to put it into the existing rail

1. Keep native middle-click and wheel unchanged. Summon the R1 preview with **one explicitly configured alternate thumb/ring or keyboard shortcut** after checking for hotkey conflicts.
2. R1 identifies source/context/privacy; R2 *may* supply a typed converse or non-converse challenge. Show **one** recommended option first and at most **seven** on explicit expansion.
3. Display glyph + text label + evidence-warning. `↔` converse; `¬` proposed negation; `±` alternative; `∅` no-change baseline (not verified absence); `⊃` outside perspective; `◇` counterfactual; `?` unknown.
4. Effectful or outward actions remain separately permission-gated, tested, source-bound and receiver-acknowledged. An icon never confers consent or authority.
5. Only when X2 Desktop Commander can observe an authorized device: run one real MX Master 4 / Perixx input-to-preview canary with Escape/stop and a harmless test object. Avoid installing competing controllers from PR #231 and PR #237.

## Future receivers and the inverse of good UX

Mouse, keyboard, touch, headset and accessibility switches should share the same typed relationship record while respecting device-specific physical controls. The inverse of good contextual UI is not *more menus*: it is **hidden effects, lost undo, unclear source, accidental send, unbounded workers or inaccessible symbols**. Measure those failures and user time, rather than celebrating vocabulary count.
