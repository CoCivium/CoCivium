## CoHereNow

The operating objective is a **low-threshold discovery field with high-threshold promotion**:

```
public inspiration / private historical source
-> discover (link only)
-> dedupe / rights & provenance / privacy
-> CoMap typed relations and CoTurtle challenge
-> score information gain / useful receiver task / accessibility
-> bounded research-only fanout (<=6 logical lanes)
-> fan-in one evidence-bearing proposal (<=3 candidates)
-> source-bound text + visual hypothesis + independent comparison
-> PASS/FAIL/HELD receipt
-> reviewed derivative if and only if license and authority are established
-> sleep/wake on material changes
```

There is no permission to search private accounts or pull images out of prior chats in bulk. The private Library Synthkind artwork is one separately verified source candidate, **not copied into this public index**.

## Find, fan, and spray: three different scopes

**Find:** search widely but within provider terms, rate limits, privacy, cost and relevant task queries. Preserve negative sources, abandoned renders, unlocated priors, and alternative hypotheses. Discovery count is not quality.

**Fan:** six **logical, zero-worker-by-default** review lanes: source/rights, semantic motif, reproduction engineering, accessible twin, counterexamples, and prior-art/reuse cost. Materialize at most what helps a current decision. CoStretch selects adequate resources; CoTurtle challenges relevance and confidence.

**Spray:** only **small public-safe reference/proof packets** to an authorized, explicitly named review receiver, initially a nondefault GitHub PR. Never unsolicited emails, WhatsApp or social posting, bulk asset copying, covert screen/camera capture, group data scraping, automatic publication of images, or blanket agent calls. `FANOUT_NE_AUTHORITY_EXPANSION`.

A public image reference can be linked for discussion; reproducing or transforming the source bytes requires item-appropriate rights and privacy review. Creator attribution remains important even with unrestricted reuse.

## No vanity metrics

The [read-only selector](VisualCandidateSelectorR0.mjs) has deterministic input caps (<=64 references, at most 3 elected research previews), no web calls and zero effects. Its calculated score is advisory. To prove usefulness, compare at least one elected visual idea against a plain-text/no-new-interface baseline using:

- time to correctly answer a fixed question;
- source and claim citation fidelity;
- inverse/negative-case error rate;
- accessibility parity and reduced-motion fallback;
- time/compute/attention cost;
- legitimate reuse/attribution and privacy compliance;
- actual independent receiver understanding, not likes or copy counts.

The per-asset source hash remains **null** until actual original bytes are acquired under an appropriate license and hashed. A source-webpage read does not prove media custody.

## Ongoing continuity and blocked scheduled watcher

Daily/periodic discovery belongs to an existing authorized CoEvoAll research carrier when its own current duty/budget makes the search material. This public review branch **does not register a scheduler**. A new dedicated ChatGPT task could not be created because the account currently has the active-task limit. Do not disable, alter, replace or collide with existing tasks solely to add a visual watcher.

Read-only next deed: select **one source item** with independently verifiable license and demonstrate source reference -> a source-bound CoOrb/CoMap/accessible-text pair -> counterexample -> user-first-use test. The existing public [CoLens Map/Orb/Text](../colensmedia/index.html) is the most economical renderer donor; do not build competing machinery.
