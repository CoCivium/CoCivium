## Ontology: a NOT has multiple dimensions

A statement's state should eventually be a vector, not one all-purpose Boolean or a mutually exclusive 13-state enum:

- **Epistemic:** unknown, unobserved, observed-absent, challenged, supported, contradicted.
- **Ontological/modal:** possible, hypothetical, not-yet-real, inapplicable, logically impossible *under stated assumptions*.
- **Deontic/privacy:** forbidden, not authorized, withheld, deliberately disconnected.
- **Temporal/lifecycle:** expected missing, retired, superseded, expired, unrecoverable *under tested recovery coverage*.
- **Quantifier:** not-all, none, not-yet, not-this, not-known, not-visible, not-permitted. These are not synonyms.

The HTML introduces 13 named states as didactic lenses, not a final ontology lattice. The machine companion `ontology.json` preserves the exact public synthetic fixtures.

### Four-valued evidence, not world truth

Use a support pair `(evidence_for, evidence_against)`:

| Evidence support | Epistemic report |
| --- | --- |
| `(0,0)` | NEITHER; unknown/not established |
| `(1,0)` | Supported true in evidence scope |
| `(0,1)` | Supported false in evidence scope |
| `(1,1)` | BOTH; contradiction to preserve, not a license to infer anything |

These are **evidence claims** rather than universal metaphysical truth assignments. A missing edge yields neither by default. Even a negative witness with full *finite* coverage supports only its recorded domain/time, not a statement about the entire universe.

**NOT_ALL does not mean NONE.** A single counterexample refutes a universal claim under a qualified domain, while it does not eliminate the remaining positive instances. Closed-world quantification requires exact source, domain, complete coverage and observation time. Empty domains are displayed separately.

### Infinitude and CoTurtles+

Open-ended possibility is an exploration frontier, not an infinite observed set. A huge finite logical grammar can be sampled without materializing its members. Concrete execution inherits finite resources, authority ceilings, recovery predicates and cost/energy budgets. Every recursion step must yield a finite receipt and a stop condition. Reduction of a projection can be reversed while its source survives; revocation and actual source destruction are not automatically reversible.
