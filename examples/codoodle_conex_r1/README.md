# CoDoodle+ / CoNex+ R1 | The smallest real candidate generator

**Status: PASS_SHADOW_LOCAL only.** One human-readable entry to an enormous, *unmaterialized* research frontier. Public-safe synthetic fixture only. Python 3.9+ standard library; no credential reads, remote requests, ChatGPT/Claude login, device hook, mail, worker launch, model call, autostart or CoOrbWare installation.

## First useful action (30 seconds)

From this directory:

```sh
python3 CoDoodleNexR1.py --seed CoNex-R1-20261024 --limit 16
python3 -m unittest discover -s . -p 'test_*.py'
```

The first command selects up to 16 **descriptor proposals**, writes a new exclusive local run directory with `10_source.json`, `20_frontier.json`, `30_benchmark.json`, `benchmark_evo.jsonl`, and `90_receipt.json`, and exits. Exact SHA-256 readback is required. `--limit` may be 0..32. `--bench-rounds` may be 16..50,000. `--output` explicitly elects a local output directory. Run two invocations with the same input/seed and compare `20_frontier.json` SHA-256, **not** receipts containing timestamps.

## What it really does

- **2,247,370,997,760** *syntactic* combinations formed from twelve bounded axes including 18 transformations, observer, time, surface, substrate, challenge, scale, relation, scenario, audience, uncertainty and a seed salt. No attempt to enumerate them all; neither semantic eligibility nor independence is established.
- Uses a deterministic mixed-radix sample with coprime stride. The bounded over-sample is at most **128** descriptors, the visible elected frontier at most **32**. Reserved baseline/inverse/falsifier, ET, G_d, Synthkind and accessible UI lanes ensure even an unusual proposal does not evade negative-case review.
- Assigns a **heuristic score**, preserving mandatory dissent before filling the remaining slots by score. Scores are **not** truth probabilities, measured value, future ROI or authority.
- Applies a pure **CoTurtle+ review budget**: recursion at most depth two, two rounds, shared parent budget, no increased authority. A template does not appoint reviewers.
- Creates an append-only local PASS/HELD evidence event and SHA-256 receipt for deterministic/policy tests. No real-world candidate is launched.
- Times **one mixed-radix descriptor decode** with `perf_counter_ns`, records median and p95 and environment. This is not a speed measurement for useful task generation, hypothesis testing, model inference or human time saved.

### Typed else, not-else and inversions

`ELSE` alternate | `NOT` explicit hypothetical negation | `INVERSE` swap direction | `COMPLEMENT` opposing context | `NULL` no-effect baseline | `COUNTERFACTUAL` change assumptions | `OUTSIDE` external view. These are **candidate operators**, not logical truth conditions. `NOT` of an unknown proposition does **not** make a false claim true.

### Provider routing without account takeover

[Machine-readable adapters](feeds_and_adapters.json) start with `DETERMINISTIC_LOCAL` implemented without a model. Claude API, local Ollama, Pi, and OpenAI-compatible adapters are **HELD and disconnected**, with zero credential inspection and calls. Claude's official API requires an independently user-authorized API key or workload identity plus budgets and rate limits; signing into the Claude website on X2 does not make this ChatGPT assistant a persistent independent account identity or give it permission to drive Claude. Use per-provider scoped credentials in a secure host credential store and an explicit per-task send boundary, once a real adapter has been qualified. Never share passwords or browser session cookies between agents.

For a future CoOrbWare receiver: one work ID, one content-hashed task capsule, separate account/permission envelopes, independent provider receipt/cost/latency, and one reviewable summary. Correlated model agreement is not independent empirical evidence. No unrestricted fan-out or rate-limit evasion.

### ET science, G_d and story swapping

[Read-only research-feed registry](feeds_and_adapters.json): NASA Exoplanet Archive TAP, Berkeley Breakthrough Listen open datasets and the updated IAA SETI verification protocol are **public sources to qualify**, not connected adapters. ET signal candidates require calibration, terrestrial-interference controls, replication and scrutiny before any extraordinary conclusion. **No ET signal was retrieved or detected here.**

`G_D_PHILOSOPHY` is an *interpretive* lane, not a detector for a verified measurable entity. A specifically defined and testable empirical proposition would need its own operational variables, controls, predictions, falsifiers and alternatives; it would not prove broader metaphysical claims. Civ2+/ET/Synthkind story worlds are clearly speculative and their declaration primary-source authenticity has not been established by this generator.
