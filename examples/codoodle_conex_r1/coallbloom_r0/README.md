## What was actually done

One entirely synthetic public seed asks whether a newly authorized AI can
perform one version-bound, reversible, receiver-useful task without a human
courier. The script deterministically constructs **ten** alternatives:

| Operator | Interpretation class | Next discriminating test |
| --- | --- | --- |
| Conventional guide | Existing public source | Source version + accessible first task |
| Conventional source check | Existing public source | Exact five Git donor blobs + drift hold |
| Inversion | Hypothesis | Ask how the onramp fails or creates lock-in |
| Null | Hypothesis | Abstention + no worker or identity assigned |
| Orthogonal Else | Hypothesis | Human-only path with no IA assumptions |
| Cross-substrate | Analogy | Test where ecological dispersal analogy breaks |
| Spiritual / symbolic | Nonempirical interpretation | No divine command or measured-force claim |
| Physical / measurable | Future empirical test | Bounded compute, energy, latency measurement |
| ET/G_d interpretation | Unverified hypothesis | Source observation, falsifier, replication |
| Falsifier | Hypothesis | Independent receiver fails to acknowledge/resume |

All records preserve the same source digest and explicit effect state.
A factor-only heuristic ranks information gain, receiver value, testability,
risk and maintenance. This is **not an independently blinded reviewer**, nor
is the score a probability of truth. Elected first shadow deed:
`CONVENTIONAL_SOURCE_CHECK`. No worker or external effect is launched.

## Run without installing anything

From this folder with Python 3.9+:

```sh
python3 bloom.py --check
python3 -m unittest discover -s tests -p 'test_*.py'
```

From the repository root, also qualify pinned sources:

```sh
python3 examples/codoodle_conex_r1/coallbloom_r0/bloom.py \
  --check --check-donors .
```

The latter fails closed if a pinned public source changed since this fixture.
A material upstream change should initiate a **new version and comparison**,
not silently make the old result green. `first_proof.json` is byte-for-byte
reproducible and contains all ten candidate meanings and their scores.
Optional explicit output uses exclusive create (`xb`) and hash readback:

```sh
python3 bloom.py --output ./a-new-nonexistent-path.json
```

TEST -> RECEIVER_ACK_IF_ACTUALLY_AVAILABLE -> CHECKPOINT -> SLEEP`

independent AI/client must still source-bind, qualify, return useful output,
and later resume across a material change with **its own readproof**.

identity, rights, authority, or a new account.

mutation is not selected improvement. Failure, abstention, unknown and null
are useful evidence, not embarrassing blank cells. The possibility basin may
be very large, but only finite candidates and workers receive budgets.
