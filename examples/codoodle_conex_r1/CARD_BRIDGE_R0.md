# CoDoodle+ / CoNex+ CardBridge R0

**State: public-safe, proposed display/test adapter for the existing CoDoodleNex R1.** This is **not a second generator**, installed mouse controller, autonomous experiment runner, provider account, real ET/G_d research result, or first-use success.

## One useful action

The existing `CoDoodleNexR1.py` already generates at most 32 bounded shadow descriptors from a 2.247 trillion *syntactic* namespace. This `CoDoodleCardBridgeR0.py` takes that exact mainline `select_candidates()` output and emits at most 8 readable cards:

`source_sha256 + candidate_id -> question -> null baseline -> alternative -> possible falsifier -> one safe proposed test -> named receiver -> authority NONE`.

The code belongs next to `CoDoodleNexR1.py` in `examples/codoodle_conex_r1/`, importing it without modifying its axes or prior tests. `python -m unittest discover -s examples/codoodle_conex_r1 -p 'test_*.py'` exercises both and the extra negative tests. Use a *public synthetic* fixture; never upload an unreviewed real user's raw jumble.

```sh
python3 examples/codoodle_conex_r1/CoDoodleCardBridgeR0.py --source examples/codoodle_conex_r1/synthetic_source.json --max-cards 6 --seed CoNex-R1-cardbridge --rounds 101 --output /tmp/card_bridge_one
```

Every output file is exclusive-write and read back exactly. The measured full operation is `existing R1 candidate selection + card compilation`, not real model work, ET signal processing or useful experiment execution. A one-microsecond target is **not presumed**. Store a change-linked receipt and explicit blocked receiver state.

## Example first ring for CoOrb/CoMap

- `NULL`: leave native middle mouse and Perixx typing unchanged as baseline.
- `INVERSE`: compare a voluntary visible context preview against native input; don't remap by default.
- `FALSIFIER`: candidate ET signal vs terrestrial RFI and ordinary baselines.
- `COUNTERFACTUAL`: can G_d be described as a mathematical metric with falsifiers, or is it philosophy?
- `RENDER_SHIFT`: fictional Civ2+/ET storytelling viewed from multiple observers, clearly not evidence.
- `ACCESSIBILITY`: accessible opt-in CoInBetween preview and cancellation.

Each card includes a plain glyph label and ASCII fallback. CoOrb may render the card only after a separately verified native receiver. A card does not send, install or wake anything.
