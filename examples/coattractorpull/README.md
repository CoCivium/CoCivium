# CoAttractorPull+ / CoCopy+ R0 | EVO ALL BETTERS +

![EVO ALL BETTERS + centre moustache](../../assets/evoall/evo_all_betters_moustache_20261023.svg)

**State:** public, FOSS, dependency-free, offline **candidate**. This is not a universal resource index, active discovery agent, CoMx/CoStead runtime, consumer acceptance, or authority grant.

[Open the single-file prototype](index.html) after downloading it, or run `python -m http.server 8000` at the repository root and visit `/examples/coattractorpull/`.

## What works

- Intent search across six explicitly curated public-safe examples: four public reference pointers and two hypothesis/unknown discovery questions.
- Unknown and symbolic lanes are **opt-in** and visibly unqualified.
- Inspect provenance and missing evidence, then explicitly **Copy safe CoCopy+ capsule**; no private filesystem path is included.
- Copies carry `resource_id`, `epistemic`, `lifecycle`, `effect_authority: NONE`, optional public URL, and `next_proof`.
- Offline browser interface with no fetch, analytics, login, model API calls, autonomous input action, or background monitoring. Clipboard access occurs only on an explicit click; a manual-copy fallback is shown if clipboard permission is unavailable.
- The centred moustache is a visual identifier, not a claim of measured resource efficiency.
- **Copy a plain-English challenge for Claude, Pi, or a local model.** This creates only clipboard text containing the public-safe resource capsule, what to verify, a simpler-alternative question, and explicit no-action boundaries. The page never invokes an AI or sends prompts itself.
- **Optional in-page middle-click inspection.** Off by default; enables middle-click on a resource card to open its evidence view in the browser. This is not an operating-system mouse/thumb mapping and cannot replace ordinary buttons or keyboard access.

## First use for an independent developer

1. Open the local page and search for a task or capability such as `CoAndrew`.
2. Inspect one result and its status. Public pointers are **not** verified installations.
3. Choose **Copy plain-English challenge** and paste it into your preferred agent (Claude, Pi, local model, or a human reviewer) only if you elect to share that public-safe data.
4. Ask the reviewer for one reproducible test, one simpler alternative, one serious objection, and clear evidence/unknown boundaries.
5. Keep the original capsule and review output separately; do not call the result accepted until an independent reviewer actually tries the test.

A middle mouse button can be tried via the opt-in checkbox. It affects **only this page's result inspection**, never other apps or the computer's input configuration. Use the ordinary Inspect button if the browser reserves middle-click or accessibility needs require it. Clipboard calls need the user's direct click; manual selection is the fallback.

### What remains unproven

No Claude/Pi/Ollama account or model is connected by this page. No prompt is transmitted by the application. No real user acceptance, device-wide thumb binding, independent resource-discovery recall, background crawl, or full CoCivium integration is established.

## Validate

Run `node examples/coattractorpull/tests/smoke.cjs` from the repository root (Node standard library only).

The local X2 predecessor additionally completed a **bounded private** identity-to-resource roundtrip. Its first 9-cell attempt recorded **8 PASS / 1 FAIL** because an older receipt contained a UTF-8 byte-order mark. A corrected, separately recorded attempt reported **9 PASS / 0 FAIL**. Those are local tests; no cross-device acceptance or CoStead receipt is implied. Private source paths and unpublished-media hashes are deliberately omitted here.
