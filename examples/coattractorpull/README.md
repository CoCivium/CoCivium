# CoAttractorPull+ / CoCopy+ R0 | EVO ALL BETTERS +

![EVO ALL BETTERS + centre moustache](../../assets/evoall/evo_all_betters_moustache_20261023.svg)

**State:** public, FOSS, dependency-free, offline **candidate**. This is not a universal resource index, active discovery agent, CoMx/CoStead runtime, consumer acceptance, or authority grant.

[Open the single-file prototype](index.html) after downloading it, or run `python -m http.server 8000` at the repository root and visit `/examples/coattractorpull/`.

## What works

- Intent search across six explicitly curated public-safe examples: four public reference pointers and two hypothesis/unknown discovery questions.
- Unknown and symbolic lanes are **opt-in** and visibly unqualified.
- Inspect provenance and missing evidence, then explicitly **Copy safe CoCopy+ capsule**; no private filesystem path is included.
- Copies carry `resource_id`, `epistemic`, `lifecycle`, `effect_authority: NONE`, optional public URL, and `next_proof`.
- Offline browser interface with no fetch, analytics, login, model API calls, autonomous input action, or background monitoring. Clipboard access occurs only on an explicit click; a manual-copy fallback is shown if clipboard permission is unavailable.
- The centred moustache is a visual identifier, not a claim of measured resource efficiency.

## Validate

Run `node examples/coattractorpull/tests/smoke.cjs` from the repository root (Node standard library only).

The local X2 predecessor additionally completed a **bounded private** identity-to-resource roundtrip. Its first 9-cell attempt recorded **8 PASS / 1 FAIL** because an older receipt contained a UTF-8 byte-order mark. A corrected, separately recorded attempt reported **9 PASS / 0 FAIL**. Those are local tests; no cross-device acceptance or CoStead receipt is implied. Private source paths and unpublished-media hashes are deliberately omitted here.
