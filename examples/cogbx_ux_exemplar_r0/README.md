# CoGbx UX Exemplar R0

**State:** public-safe static source exemplar. Not deployed to CoGbx.org.

Open `index.html` locally in a browser.

## CoEyes+ R1 agentic feedback selector (proposed branch)

The existing CoGbx Orb/Map/Text/Ambient static page now includes a **simulated event-driven CoEyes+ feedback selector** in the focused rail. This is a source upgrade to a browser-local public-safe exemplar, **not an X2 install, autonomous sensor watcher, current device census, or CoOrbWare runtime**.

It demonstrates one reusable loop: **evidence event -> classify materiality/authority -> choose HELD_OBSERVER, PROPOSE_UX, QUIET, or HELD_CONSENT -> deduplicate -> bounded local receipt -> sleep**. Four synthetic events test observer currentness conflict, window overlap, no useful delta, and requests for screen/camera sensing. No polling/timer, no network, no storage, no sensitive capture, no OS/browser window control. The page automatically evaluates the initial synthetic fixture and responds to local radio input changes; repeated identical fixture keys are deduplicated.

The same R1 patch changes misleading static labels from 'local current', 'recovery available', 'crown risk low', and three green independent-path indicators to explicit **synthetic-only / demo / held** language. The intended X2 CoBar/CoTime/CoSync interface still needs real freshness receipts before any green indicators can be believed.

**Next proof:** fresh authorized local observer access -> X2 CoBar/RickBar process and native UI discovery -> instrument one actual allowed UX currentness event -> independently verify a reversible recovery or UX simplification, with user consent for sensitive inputs and a device-side receipt. No receiver pickup, CoEx or production deployment is inferred from the page or tests.

**Acceptance boundary:** Code/smoke parse and source readback are not Chrome/Firefox acceptance, independent accessibility review, actual feedback-loop agent autonomy, or X2 recovery.

## What it demonstrates

- one durable work object projected as Orb/Map/Text/Ambient;
- optional 3D+ perspective without making 3D mandatory;
- responsive layout from narrow screens to X2-class desktops;
- explicit UNKNOWN/currentness state;
- redundancy / no-crown relation;
- local predictive shadow with explicit accept/reject;
- zero network, storage, credential, send or provider effects.

## What it does not prove

- deployed CoGbx.org;
- X2 runtime integration;
- XR/WebXR acceptance;
- screen-reader acceptance;
- provider substitution;
- distributed peer operation;
- receiver pickup;
- CoEx.
