**State:** PUBLIC_WORKING_OFFLINE_CANARY. Dependency-free HTML, no provider adapter, no runtime CoOrbWare, no actual remote receiver, no account exit.

## Five-minute first use

Download [index.html](index.html) and open it in a browser. Its example text is synthetic. Click **Preview next**, then **Accept in this field** or **Reject**, and test **Undo last acceptance**. Toggle Glance, Relations, Time and Ambient to see projections of the same evidence/authority boundary.

Only text in the page's own demo editor is read. Suggestions are selected from fixed local heuristics and appear ahead of the caret. No global keyboard hook, network, background worker, storage, external message, clipboard upload, password manager, model call, OS wallpaper or mouse remapping occurs.

**Ambient safety:** Ambient is an in-browser projection, **not** an installed Windows wallpaper or screensaver. Selecting it hides the entire editor, receipt panel and detailed trail from the rendered view, so raw draft content is not displayed on the ambient surface. The draft still exists privately in page memory until Reset or tab close, and true locked-screen/bystander acceptance has not been tested.

**RAW source and CoReWis+:** preview does not change the draft. Accept inserts the proposal at the cursor in this field only. At most eight pre-acceptance draft snapshots remain in page memory so Undo can recover exact prior text. Reset or close erases them. The **Prepare local receipt** button displays only event counts and authority limits, never raw draft content.

**CoMould+ / G_d / strange clay:** Interpretive, symbolic and unconventional ideas may suggest candidate tests; they do not become claims of supernatural or physical proof. CoQuanta+ means a typed relational packet, not literal quantum physics.
