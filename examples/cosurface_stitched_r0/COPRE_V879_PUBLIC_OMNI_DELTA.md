## CoSeed / CoPath ability contract
`DISCOVER → PIN → VERIFY → SCOPE → TRAVERSE → CHALLENGE → DELTA → LAND → RECEIVER-READBACK → ACCEPT/HELD`

- **Discover:** fetch public registry with reproducible path and version. If unavailable: HELD.
- **Pin/verify:** check commit revision and exact returned file bytes/digest, not merely link text.
- **Scope:** exclude private/restricted sources from outward traversal, projection and publishing.
- **Traverse:** include both outgoing source relations and incoming references, showing orientation.
- **Challenge:** preserve contradictions, missing coverage and held unknowns, including old ideas with no current use.
- **Delta:** elected bounded authorized reversible work with one unique WorkID and revision, no duplicate side effect.
- **Land:** produce exact public-safe source commit and clear event receipt.
- **Receiver readback:** a different authorized actor fetches the exact object independently and commits durable ACK.
- **Accept/HELD:** only promote after actual receiver verification. Other fronts are not auto-synchronized.

**CoCoverage+**: track explicit counts in scope, held sources, stale links, unqualified receivers, and semantic review debt; never extrapolate to unseen total historical work.
