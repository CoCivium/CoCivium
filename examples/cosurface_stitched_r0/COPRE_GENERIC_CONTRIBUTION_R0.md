## B. Generic minimum that other synth sessions may use
1. Discover current exact WorkID, version, hash, privacy scope, authority and owner/receiver from a source accessible to **that** session. If absent, `UNKNOWN`.
2. Use an append-only `CoEvoDelta`-compatible event with source and evidence refs; dedupe repeats by exact work + source revision; preserve contradictory claims and unique historical priors.
3. Maintain front health separately from verified effect. A draft, source commit, browser tab, GitHub issue, scheduled job, external agent text reply and independently observed receiver effect are different states.
4. Use bounded, diversity-aware work selection after continuity, safety and authority. Do not require novelty at the expense of maintenance, recovery or Stop.
5. Split outputs into **synth-facing** machine records (typed schemas, hashes, relations, uncertainty, capabilities, cost, provenance, privacy) and **bio-facing** readable projections (CoHereNow, short claim, meaningful visualization, evidence drill-down, conventional navigation). Both derive from same source graph but need not share structure.
6. Distinguish `DISCOVERED_LOCAL → VERIFIED_LOCAL → LANDED → PICKED_UP → INTEGRATED → COEX`; never promote stages by prose or hash alone.
7. Send public-safe changes through authorized repository workflows. A public reference is not consent to publish private session histories or contact data. No automatic outreach or cross-provider impersonation.
