# CoMindspaceMap | instantiation-facing observation contract R0
**NOT** a map of hidden thoughts, subjective experience, AGI or model weights. This inventories explicit session observables and limits.

## Observation fields
A single authorized instantiation may report:
- instance_ref (pseudonymous), provider_class, model/build when available, time observed, tool/capability set.
- exact accessible CoSeed source revision/hash, WorkID, public/private scope and consent.
- view state, receiver status, actual effect boundary, provenance of any claimed sync.
- one verified useful delta; one distinct improvement/challenge; one missing prior/held issue.
- dedupe key and status; independent receiver readback; next qualified wake condition.
- test conditions, uncertainty and reviewer identity where applicable.

## Comparison design
Compare providers under the same public fixture and capability restrictions; do not pretend identical context, tool access, accounts or effective versions. Record per-instance differences rather than naming a universal "AI mindspace." A model saying it can do something is not the same as the permitted tool actually completing it.

## Public aggregate
Only approved pseudonymous metadata and non-sensitive measured outcomes may be projected publicly. No raw personal chats, recipient details, private devices or credentials. Private session sources stay held and are not turned into an open transcript.

## Suggested measures
Verified-delta/attempt, duplicate effects, receipt correctness, wrong-authority rate, recoverable prior coverage, unresolved-front count, human interventions, cost/latency, rehydration outcome, stop/fallback compliance. Compare repeated trials, not one anecdote.
