# CoMindspace Map R0 | Instantiation and effects comparison
**PUBLIC METHODOLOGY / NO PRIVATE INTERIOR-STATE CLAIMS.** 2026-11-09.

A "mindspace" here means the **observable operating context** of an AI instantiation, not access to its hidden reasoning, consciousness, feelings or internal weights.

## Snapshot schema
| Field | What can be inspected |
| --- | --- |
| Instance | Pseudonymous provider/model/runtime and observation time |
| WorkID / Seed | Exact revision + source checksum or UNKNOWN |
| Context scope | Conversation, source files, reachable tools, declared limits |
| Authority / privacy | Allowed operations and denied operations |
| Border | Observed view, receiver, effect and synchronization statuses |
| Receipt | Exact file/commit/test or independent effect proof |
| Delta | One evidenced contribution, not generated narrative volume |
| Distinct | Hypothesis or challenge uniquely contributed |
| Held | Unseen sources, unresolved contradiction, privacy/authority blockers |
| Carry / CoNull | Human effort, hold state, interruption or deliberate no-op |
| Next | Authorized experiment plus wake/stop condition |

## Cross-instantiation tests
Hold WorkID, input fixture, source version and evaluation rubric fixed. Vary provider, context window, tool access or substrate separately. Measure fidelity, missed priors, false-green claims, evidence retrieval, latency, cost, receiver verification and intervention. Duplicate responses are not extra independent experiments. Preserve contradictory results.

## CoSynthVerse ↔ CoBioVerse
Synth surface: versioned typed claims, hashes, uncertainty, tool scopes, causal/effect trace. Human surface: succinct CoHereNow, readable map, optional audio and reversible navigation. Track projection loss explicitly.

## Research and ethics
G_dSide, CMA, CoNull, oscillation, inversions, projected sentience and CoAGI are candidate conceptual or evaluative frameworks. Neither operational heartbeat nor apparent coherence establishes consciousness or divine influence. No private conversation publication without consent.
