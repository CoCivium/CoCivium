Fractal resilience is testable

Mirror candidate

One signed or hashed release manifest can be hosted in GitHub, a website and an independent storage provider. Locations are candidates until a fetch from each actually succeeds.

Recovery condition

Test restore from an independent failure domain, detect split versions, retain rollback and compare exact bytes. Three URLs behind one account are not three independent backups.

  • Content-addressed artifacts plus stable canonical IDs.
  • Explicit provider, account, domain, region and credential failure domains.
  • Accessible HTML plus machine-readable manifests; no JavaScript required to read this page.
  • Cache and offline bundle only when generated and independently validated.

What would make it real?

Prove one authorized WorkID crosses a real independent receiver, the Orb reports the exact receipt, X2 survives interruption and the source is independently fetched from each advertised mirror.

Nonclaims: Browser tests are not X2 deployment. A public GitHub branch is not a production website. Hashing is not semantic ingestion. Static links are not independently verified backup copies.
