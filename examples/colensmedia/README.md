## Current engineering coverage

`manifest.json` is the source of the demonstration. `build.py` deterministically regenerates `index.html`. `tests/test_living_media.py` asserts source preservation, scope limits, exact HTML parity, negative states, no unproven scientific causal links and bounded future evolution.

From the repository root:

```sh
python3 examples/colensmedia/build.py --check --check-donors
python3 -m unittest discover -s examples/colensmedia/tests -p 'test_*.py' -v
```

`--check-donors` compares the four public donor files to the **pinned Git blob SHA-1** values. Any material source change causes HOLD rather than an invisible semantic update. Git source hashes prove *identity of bytes* in that repository snapshot, not whether the source claim is true. All design/spec/code/diagrams are eligible for the same technique, but this does **not** establish universal CoAll deployment.

## Evolution cadence

**Check can be daily. Evolution should happen only on evidence or useful semantic change.** The read-only CI workflow may run at most one daily scheduled check when GitHub schedules it, and on relevant source edits. It neither rewrites docs nor uploads media, remaps devices or sends messages. A changed donor SHA fails the job pending deliberate, source-bound review; old versions remain referencable. Actual schedule execution requires its own Actions run receipt.

No actual rights declaration, legal adoption, public outreach, coercive enforcement, autonomous desktop control, Planck-scale measurement, newly discovered physical energy/aura, verified G_d mathematical relation, CoStead landing, receiver ACK or CoEx is claimed. A next *human-value* gate is a consenting outsider's first-use source-comprehension test. An *X2* gate remains independent device connection, native mouse input canary and current CoOrb display proof.
