## The idea

**Instant imagination. Honest construction.** A magical workshop is a memorable interface metaphor, not a mechanism that bypasses evidence. Children can explore a fictional game, organizers an imagined park, and philosophers or theologians a voluntary reflective circle. Every lens maps to the SAME lifecycle and status boundaries.

`WISH -> MAP -> MAKE -> TRY -> GATE -> GO -> SEEN -> GROW`

| Human word | Operational distinction | May it imply a real-world effect? |
| --- | --- | --- |
| Wish | Intent, purpose, question | No |
| Map | Plan, dependencies, alternatives | No |
| Make | Private candidate, simulated artifact | No |
| Try | Bounded test and negative controls, not actual user acceptance | No |
| Gate | Privacy, rights, consent, source currentness, effect approval | Hold, never pre-authorize |
| Go | Actual externally authorized effect with actor and target | Only with a separate real effect receipt |
| Seen | Receiver-origin exact readback, distinct from author report | Not assumed from publication |
| Grow | Actual human usefulness, dissent, correction, exit, recovery | Must be separately measured |

The extra child-friendly mnemonic is **Poof != Proof**. CoPoof+ is a private playful preview; CoProof+ is evidence and cannot arise from animation or a funny word. A forecast may precompute but cannot create a right to send, publish, spend, enroll or change terms.

## One local demonstration

`index.html` is a static, offline file: no login, network calls, credentials, tracking, real participants or external effects. It has three fictional projects:

1. **Moon Garden game** (CoPlay): toy world/ethical-rule choices create a local scene.
2. **Everyone's park** (GroupBuild): a proposal intentionally held for real stakeholders and privacy/consent review.
3. **Big Questions circle** (Civ2+): plural philosophical and theological inquiry, without any institutional or religious authority claim.

One can switch among Play, Build, Big Questions and Stewardship explanation styles without changing the underlying stage or rights. The button that says **Poof! Make a private preview** modifies only the displayed browser scene. It does not save, send, publish or operate a game server.

## Reproduce

- Open `index.html` in a desktop or phone browser as a local file. Interactive controls require JavaScript; static copy remains available with JavaScript off.
- `python -B test_magic_workshop.py` executes 28 deterministic Python structural/permission-honesty checks, no external calls.
- `python -O -B test_magic_workshop.py` checks that the suite does not depend on disabled Python assertions.
- `node qa_browser_r0.cjs [directory]` optionally uses Puppeteer. It checks eight stages, four explanation lenses, no horizontal overflow, selected-stage narration, a no-effect Poof build, and no JS/network errors across widths 390/768/1440. It produces local QA JSON and three screenshots. No browser installation step is triggered by this README.
