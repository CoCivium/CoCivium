λ versus β: two different growth questions

Temporal exponential rate, λ: does the same measured useful value grow multiplicatively per comparable time window?

λ ≈ Δln(V) / Δt;   doubling time = ln(2) / λ

Scale exponent, β: how does qualified output vary with a measured scale variable such as independently active participants?

V ≈ aN^β;   β ≈ Δln(V) / Δln(N)

Both currently unqualified. A β fitted against system size is not a λ fitted against elapsed time. At least four comparable qualified observations and uncertainty/cost review are required even for a candidate fit.
