# CoMetabolism / CoObject Heartbeat R0A

**State:** PUBLIC_SAFE_SYNTHETIC_SHADOW_ONLY. A small test of the *existing* CoFractal Energetic Metabolism R0 first-proof requirement, not a new global bus, a deployed daemon, a sentient entity, or a physical energy source.

## Three distinct clocks

1. **Object/source pulse:** a source/version or relation materially changed. This is not proof that a process is running.
2. **Runtime heartbeat:** a scoped, observed lease is recent. Expiry yields `LEASE_STALE_RUNTIME_UNKNOWN`, not a declaration that the source work is dead.
3. **Verified return:** an independent receiver reports a useful outcome. Neither a source pulse nor a process heartbeat establishes this. The R0A canary has no such real-world return.

The same eligible interface may describe a software view, research publication, relation-gap, dormant nonphysical hypothesis, active process lease, or restricted source. An object's *addressability* is independent of its activity. Wake actions are merely read-only proposals; a receiver and distinct authority would be required for real effects.

## Reproduction

From repository root:

```sh
cd examples/cometabolism_heartbeat_r0a
python3 -B -m unittest -v test_beat.py
python3 -B beat.py --fixture fixture.json
```

Only the Python standard library. No network libraries, threads, timers, OS hooks, agent spawning, credentials, physical hardware I/O, sends, mailbox calls or perpetual event loops. The local `--output` flag uses exclusive creation, refusing overwrites. All time fields are synthetic logical ticks.

The six unlike synthetic objects are: reported X2-like foreground pressure (NOT live X2 telemetry); an updated publication; a missing receiver acknowledgment gap; a dormant symbolic hypothesis; an expired process lease; and a private source that the public-only compiler must reject. Four qualified proposals compete for two slots in a four-unit budget with a two-unit untouched reserve. The synthetic result selects an inspection proposal and a receipt-verification proposal. All other eligible proposals remain discoverable, not falsely executed.

## Controls

- Public-only typed source, explicit READ_ONLY scope, synthetic evidence class; every privacy or effect mismatch is held.
- Exact event-ID replay dedupe; conflicting revisions under the same event ID make that event ID wholly ineligible rather than silently choosing one.
- One candidate per object per wave; parent budget ceiling, reserve floor, width cap, Turtle depth/round cap (2 each), verified STOP.
- New-source-hash requirement and no material-change suppression.
- Symbolic/unknown/nonphysical meaning can prompt examination, not valid watts.
- Expired leases never generate life/health claims. Unknown remains unknown.
- Stable digest and sort-independent result; historical source objects remain immutable.
- No artificial improvement metric, no global adoption claim, no automatic receiver acknowledgment or self-mutation.

## Evidence ceiling

36/36 isolated `unittest` cases pass in the local Python runtime. The fixture and code are original synthetic source; no actual provider/OS/energy/performance measurement, X2 device execution, scheduled heartbeat, independent cross-device receiver, real user-value return, public server deployment, or CoEx has been established.

The next meaningful proof is *one rights-cleared real work object* with exact source revision, one actual authorized local observer, one receiver-produced acknowledgment, and the cost/benefit compared with a no-new-worker baseline. Avoid a resident process unless it beats the baseline and preserves user responsiveness.
