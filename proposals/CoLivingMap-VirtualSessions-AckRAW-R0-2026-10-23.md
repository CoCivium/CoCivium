# CoLivingMap+ / CoVirtualSessions+ / CoAckRAW+ R0

Status: research specification on GitHub branch, not deployed or merged. No Gmail, CoVIA, site or node deliveries implied.

## Goal
A user-owned interface fabric with portable state, provider-neutral execution, shared CoQuanta+ records, and evidence-backed broadcast. FOSS-first, privacy by design, accessible and optional. Never require a proprietary GUI for routine local work when a portable alternative is viable.

## CoQuanta+ event
A record contains stable id, type, provenance, time, semantic relationships, confidence, privacy label, authority, reversibility, resource cost and evidence. Distinguish observed, inferred, simulated, hypothetical, disputed and absent. Relations carry their own evidence and consent status.

## Surface projections
CoMap+ graph, CoOrb+/CoOrbWare+ spatial views, CoBar desktop strip, accessible text view, optional wallpaper/screensaver and headless JSONL are projections of the same data. Trails/connectors express typed relationships; motion and color never exclusively carry meaning. Wallpaper pauses on battery, gaming, locked/shared screens or reduced-motion preference. No sensitive data in ambient displays by default. Benchmark against a searchable list, not just aesthetic preference.

## Virtual sessions
Store task definition, immutable context references, checkpoint, permissions, model-independent messages, budget, expiration and receipts. Workers are ephemeral; providers are interchangeable only when adapters pass capability and fidelity tests. Never treat a virtual task as a logged-in session or a substitute for account authorization. No deceptive personas or mass session farming.

## Predictive beyond-cursor input / CoReWis+
Local-first suggestions shown as ghost text; user action commits. Source attribution for recalled facts. Suppress suggestions in passwords, private fields and high-risk workflows. Explicit approval before network transmission or external action. Measure acceptance, correction burden, latency, privacy and accessibility.

## CoAckRAW+ delivery states
PREPARED -> SENT -> RECEIVED -> ACKNOWLEDGED -> APPLIED. Record immutable event ID, sender, receiver, timestamp, hash, authority, transport, retry key and proof. Never promote SENT to ACKNOWLEDGED without a receiver receipt. Idempotent retries and revocation where possible.

## CoStretch+ high-bar tests
- Same resource represented consistently in list, CoMap, CoOrb and JSONL.
- Provenance and unknown states preserved under projection and export/import.
- Session resume after forced crash, no duplicated external side effects.
- Deterministic replay of event history with tamper detection.
- Compare user task completion, time, CPU/GPU, memory, energy, and accessibility against baseline UI.
- Predictive text never auto-sends, never reads secrets, and can be disabled.
- Explicit negative test: unavailable external receiver remains NOT_TESTED or BLOCKED, never ACKNOWLEDGED.

## Broadcast boundary
This GitHub branch is the only delivery in this wave. No Gmail recipients, CoVIA nodes, sites, rels, or other endpoints are asserted contacted. Broadcast should be selective, opt-in, deduplicated, and evidenced.

## Migration
Inventory paid/provider-dependent capabilities, prove portable substitutes, migrate custody, validate functionality, and only then cancel services after checking billing, retention, export and recovery. Never delete data or accounts as a side effect of a design proposal.
