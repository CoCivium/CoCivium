# Contributing to CoCivium

CoCivium is currently a **public R&D / pre-launch** project. Contributions are welcome, but the project intentionally distinguishes proposals, evidence, integration, and release.

## Good contributions

- corrections with sources/provenance;
- small reversible code improvements;
- accessibility fixes;
- test fixtures and adversarial cases;
- security/privacy improvements;
- documentation that reduces ambiguity;
- machine-readable twins;
- open-source donor comparisons;
- explicit contradiction/failure reports;
- alternative implementations that preserve interoperability.

## Pull-request posture

Prefer one bounded change with:

1. purpose;
2. source/provenance;
3. affected surfaces;
4. tests/evidence;
5. rollback or reversibility;
6. license/attribution notes for borrowed material;
7. explicit nonclaims.

Do not treat acceptance of a PR as endorsement of broader philosophical, scientific, political, or product claims.

## Borrowed/open-source material

Do not paste third-party code merely because it is public.

Bind the exact upstream source, commit, license, notices, and transformation. Prefer an adapter or pattern reference when that preserves optionality with less dependency.

## AI-assisted work

AI assistance is allowed. Preserve human responsibility for submitted changes and disclose material third-party/code provenance. AI output is not a source license.
