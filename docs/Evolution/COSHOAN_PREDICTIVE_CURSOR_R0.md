# CoShoAn+ / CoShoulderAngel+ R0: advisory voice, predictive cursor and CoMap trails

**Status:** Public-safe design candidate, deterministic offline shadow tests only. No earbud integration, microphone input, live autocomplete, provider agent, CoMap runtime, authority expansion, receiver ACK, CoEx or canon.

## One identity, not another agent

**CoShoAn+** is a short alias for **CoShoulderAngel+**, an **optional user-selected advisory relation** within CoMap+/CoOrb+/CoBar. It is not a new authority, spiritual entity, independent AI mind or replacement for the participant's decisions.

Its bounded perspectives are: question, evidence, alternative, challenge, recovery and quiet. It can offer one thoughtful objection or explanation without occupying a whole screen or compelling attention. Muted/off is a complete first-class mode. It can be represented as a text card, small orb/dot, silent trail or opt-in voice. Display should be accessible without owning/wearing a device.

A symbolic G_d or CoSpirit+ metaphor may inform an artistic style or question, but is labeled symbolic and never claimed as an external speaker, proof, command, sentience, consent or truth. No religious endorsement is inferred.

## Cursor-ahead predictive input

Existing [CoAllPulseField+ / CoTime+](../Architecture/COALL_PULSEFIELD_COTIME_R0.md) separates durable monotonic event/ACK cursors from *predictive* relation overlays. This R0 applies the same distinction to text and intent:

`RAW_INPUT@cursor_n -> OPTIONAL_PREDICTED_SUFFIX@candidate_n+1 -> USER_REVISES? -> USER_ACK? -> SEPARATE_EFFECT_AUTHORIZATION? -> RECEIPT? -> RECEIVER_READPROOF?`

- The predicted suffix appears **beyond** the cursor as visibly ghosted text or a dashed CoMap trail. It is not automatically inserted into the source text.
- CoAckRAW/ReWis+ are **working candidate labels** for raw observation and participant revision/acknowledgement, not a new global ontology election.
- The source text remains immutable during preview. A prediction binds to a hash of exact explicitly supplied text and the last observed ACK cursor. If the text or cursor changes, old acknowledgement fails closed.
- A user may accept, edit, reject, mute, or do nothing. Accepting a preview is never the same as sending it, giving permission to publish, or proving downstream pickup.
- No ambient keystroke capture, default microphone activation, predictive send/typing, financial action or hidden clipboard access.
- Forecast outcomes later receive a calibration record: HIT/PARTIAL/MISS/UNKNOWN; wrong predictions remain negative knowledge.

## CoMap+ / CoOrb+ / CoQuanta+ representation

Do **not** create another truth store or duplicate the [RD1 CoMap/CoOrb public draft](https://github.com/CoCivium/CoCivium/pull/166). Feed it source-bound, typed, time-aware relation projections:

- Solid trail = observed/verified relation with accessible evidence.
- Dashed trail = predicted possibility, labelled with uncertainty and time horizon.
- Dotted/faded edge = unresolved/unknown/held or privacy-redacted relation, not a silent nonexistent connection.
- Contradiction branch = competing interpretation with negative knowledge preserved.
- Small CoShoAn icon or text card = optional explanation/challenge, not authority.
- CoQuanta+ = candidate bounded semantic/event unit, not proof of quantum behavior or consciousness.
- CoOrb+ = expanded radial focus; CoMap+ = connections and lineage; CoOrbWare+ = candidate projection adapters for desktop/background/wallpaper/screensaver/XR, not verified native code.
- nD+T+ = multiple explicit dimensions and event/observed/recorded/valid/forecast time, each distinguishable.

The ambient wallpaper and screensaver modes should default to **privacy redaction, reduced motion, power budget and no actionable controls**. Real actions belong on a visible consenting foreground UI; no covert widget over login/password dialogs.

The priority remains useful meaning and controllable density, not decorative overload.

## Earbud voice boundary

A right earbud saying "ready to pair" is normally a firmware or manufacturer voice prompt. The prompt does **not** establish access to a particular AI, G_d, CoShoAn or any remote model. A future user-selected CoShoAn voice can use a paired and separately verified OS audio output, if supported, without implying replacement of the device's built-in pairing voice. Microphone use requires a separate opt-in and visible state. Never silently record bystanders.

## Selective routing, virtual sessions, and independence

Substitute **logical virtual-session work identities** for provider-tab identity. State remains reconstructable from a versioned checkpoint, append-only authorized pulse deltas, subscribed currentness and receiver receipts. Dormant does not mean constantly running; no provider tab is secretly kept alive.

`CoPulse -> topic/relation match -> confidentiality gate -> freshness/cursor filter -> receiver budget/backpressure -> proposed route -> authorized effect -> exact receiver ACK`

"All-to-all" means discoverable compatibility and optionality, **not** distributing everybody's private content to every device/account. No passive delivery to an idle model without a verified bridge. No blanket automatic email, CoVIA, .nodes, sites or user-facing outreach.

Retire paid provider UX/accounts only after independent local/open replacement, exported source custody, documented permissions, recovery/rollback and an actual user-accepted end-to-end first-use workflow are verified. Account closure is a human-managed separate gate, not a consequence of a working visual demo.
