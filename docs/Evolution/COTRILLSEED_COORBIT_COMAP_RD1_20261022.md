# CoTrillSeed+ / CoOrb+ / CoMap+ / RD1 master specification

**Status:** public candidate / reviewable / not deployed

## Objective

Define a durable seed from which a very large logical field of possible work can be generated while keeping actual execution capacity-adaptive, evidence-bound, sustainable, and human-quiet.

## Core identity

`CoTrillSeed+` is not literally a trillion simultaneous processes.

It is a compact generative specification capable of addressing a very large candidate space across:

- work
- relations
- resources
- perspectives
- substrates
- time
- evidence
- audiences
- UX/surfaces
- governance

### Scale rule

`LOGICAL_CANDIDATE_SCALE >> PHYSICAL_RUNTIME_SCALE`

The seed may generate billions or trillions of **logical candidates** by composition, simulation, indexing, dormancy, or rehydration. Only selected candidates become physical work.

## CoTrillSeed generation

A candidate object is generated from:

`object × relation × role × substrate × time × evidence × audience × resource × risk`

Candidate states:

`CANDIDATE -> SIMULATED -> QUALIFIED -> LEASED -> EXECUTED -> OBSERVED -> VERIFIED -> RETAINED | RETIRED`

No automatic promotion from candidate to truth, canon, public release, or irreversible action.

## Multipie roles

Tripie default:

`EXECUTE + CHALLENGE + RECOVER`

Quadpie default:

`EXECUTE + CHALLENGE + RECOVER + EXPLORE`

Extended multipie roles may add:

`VERIFY / ROUTE / OBSERVE / FORECAST / PERTURB / COMPRESS / TRANSLATE`

The value of multiplicity is measured, not presumed.

## Resource vector

`R = compute + memory + storage + network + energy + latency + verification + recovery + attention + diversity`

Human attention is a resource and should be actively conserved.

## CoOomphOptiMax+

Optimize a vector, not a single scalar:

- useful output
- throughput
- latency
- verification quality
- recovery
- optionality
- energy/resource cost
- coordination cost
- common-mode risk
- human intervention

Prefer Pareto-frontier reasoning and adaptive search.

## Sustainability

Persist:

`identity + provenance + state + checkpoint + receiver + successor`

Do not require permanent execution for persistent capability.

Lifecycle:

`HOT -> WARM -> COLD -> SHADOW -> DORMANT -> REHYDRATE -> HOT`

## CoDot / CoAura relation

A CoDot is a **surface projection**, never assumed to contain the intelligence.

Possible projection modes:

`dot -> icon -> button -> CoBar -> CoMap -> VR`

Optional awareness sources must be explicitly authorized. A camera, microphone, speaker, or Bluetooth link being physically present does not prove stream access or control.
