# CoInteropFabric+ / Relational Scaling R0

**State:** `WORKING_CANDIDATE__PUBLIC_BRANCH__NOT_CANON__NOT_MERGED`

## Purpose

As CoAll scales, protocol choice, relation depth, backlog growth, and session self-awareness should remain relational rather than becoming hard-coded into one transport, one session, or one repository.

This candidate adds a narrow cross-cutting layer to the current CoAll GitHub Evolution Fabric.

## CoInteropFabric+

Treat MCP and other transports as evolving projections of deeper capability, authority, intent, evidence, and receiver relations.

```
intent
-> required capability
-> authority/gate
-> eligible transports
-> receiver
-> evidence
-> result relations
```

Candidate transports include MCP-class protocols, local process execution, filesystem, SMB, HTTP/API, plugins, model protocols, event buses, and future unknown substrates.

Rails:

`MCP_NE_COALL`  
`PROTOCOL_NE_CAPABILITY`  
`CAPABILITY_NE_AUTHORITY`  
`TRANSPORT_NE_INTENT`  
`TOOL_SCHEMA_NE_WORLD_SCHEMA`  
`MCP_SERVER_NE_WORKER_IDENTITY`  
`MCP_CONNECTION_NE_RELATIONAL_CONTINUITY`  
`OPEN_SOURCE_PROJECT_NE_PERMANENT_SUBSTRATE`

New substrate adoption should prefer:

`EVALUATE -> RELATE -> BOUNDED_CANARY -> COMPARE -> ROUTE_REVISION_WHERE_EARNED`

rather than architectural rewrite.

## Directionality is relational

Do not collapse all direction into one graph arrow.

A relation may have distinct:

- structural direction;
- inverse/navigation direction;
- authority direction;
- evidence direction;
- causal-hypothesis direction;
- observer/display direction.

Inverse projections need not be semantically identical.

## Scaling and relevance horizons

As object count grows, the possible relation surface can grow much faster than the context any one session can safely hold.

Therefore:

`GLOBAL_REACHABILITY_GT_GLOBAL_CONTEXT_RESIDENCY`  
`CURRENTNESS_FOR_ALL_NE_CONTENT_FOR_ALL`

Candidate `CoRelevanceHorizon+`:

> the bounded set of relations that materially matter to a given observer, role, task, and currentness boundary.

Candidate `CoNoiseSea+`:

> the large reachable field of currently low-relevance objects, relations, histories, and latent opportunities outside the active relevance horizon.

`OUTSIDE_RELEVANCE_HORIZON_NE_GARBAGE`

## CoPressure+

Pressure should not collapse to queue length.

A useful projection may consider work volume, urgency, dependency centrality, uncertainty, collision likelihood, human-attention demand, authority ambiguity, recovery difficulty, and available relief from parallelism/dedupe/routing/reversibility.

`PRESSURE_NE_COMMAND_TO_DO_MORE`

High pressure may correctly produce HOLD when uncertainty or authority is poor.
