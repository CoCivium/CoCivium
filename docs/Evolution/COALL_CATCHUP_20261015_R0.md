## What changed conceptually

### 1. Hourly -> event-first
Hourly work remains useful as reconciliation/fallback. It should not be the
primary control-plane clock where event-driven wake is available.

### 2. Redundancy -> TriPie
Protect critical work through Active / Shadow / independently restorable
Recovery roles rather than blindly duplicating active processes.

### 3. Armada -> renewable logical frontier
Represent a vast possibility space but materialize only bounded useful work.
Worker count is not progress.

### 4. CoVid -> reusable media/research system
Treat video as human media plus machine-readable/provenance/challenge/
accessibility surfaces with explicit reconstruction and projection-loss tests.

### 5. Catch-up -> optionality recovery
Historical and session-local ideas should be searched, deduped, related and
re-elected by present value instead of replayed wholesale.
