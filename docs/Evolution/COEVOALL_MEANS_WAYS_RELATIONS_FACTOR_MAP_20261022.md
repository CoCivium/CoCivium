# CoEvoAll+ Means / Ways / Relations Factor Map — 2026-10-22

**Status:** PUBLIC-SAFE CANDIDATE / DRAFT / NOT CANON

## Purpose

Refactor the growing CoCivium relational vocabulary into reusable primitives and composed patterns so that new terms do not create unnecessary architectural duplication.

## Core principle

A term is useful when it names a reusable relation, state, operation, testable pattern, or boundary.

Otherwise treat it as:
- an example;
- a composition;
- a rendering;
- a metaphor;
- a candidate;
- or a temporary label.

NAME != CANON.

## Six primary lenses

### CoObject
What exists, is referenced, is observed, or is proposed.

### CoRelation
How objects, states, observers, causes, contexts, resources, and receivers connect.

### CoProcess
What changes, executes, migrates, verifies, recovers, or repeats.

### CoResource
What enables work: compute, storage, network, energy, time, attention, evidence, diversity, recovery, optionality.

### CoSurface
How state is rendered: text, audio, visual, desktop, mobile, VR, CoDot, CoBar, CoMap, API, artifact.

### CoTrust
What is known about authority, provenance, currentness, evidence, consent, delivery, and uncertainty.

Everything else should compose over these when practical.

## CoLev+ test

Measure:

EXPECTED_USEFUL_EFFECT
/
(resource + coordination + risk + human attention)

A high-leverage change may be:
- one repair yielding many recoveries;
- one artifact yielding many safe projections;
- one capability yielding many safe instantiations;
- one bottleneck removal improving many work paths;
- one explanatory model reducing repeated confusion.

## CoHistorical / Co-Or / CME

Historical reconstructions should be source-grounded, plural, and explicitly synthetic.

Co-Or Theory is a candidate research/visualization framework inspired by field thinking, thought experiments, space-time, observers, oscillations, and changing relational structure.

CME remains a candidate stable name for a persistent field of collective questions, meaning, perspectives, and inquiry.

Neither implies literal access to deceased minds or metaphysical certainty.
