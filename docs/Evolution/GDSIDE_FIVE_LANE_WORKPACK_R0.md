## Independent lanes

### Lane 1: CoPriMath / CoMeasure
Define relational primitives and typed signatures; propose CoValueUnit and currency-equivalent valuation with time horizon, provenance, uncertainty and explicit non-monetizable rights. Output: schema, example, counterexample, dimensional checks. Keep existing math distinct from new conjectures.

### Lane 2: CoChallenge
Produce adversarial examples where G_dSide loses to demand/supply/hybrid; inspect circularity, biased objective selection, unpriced harms, authority confusion, and acronym collisions. Output: independent falsifiers and test cases, not agreement.

### Lane 3: CoRuntime / GS-Loop
Build executable replay test: 10 duplicate assent events -> 1 WorkID and 0 redundant status tasks; crash-before-commit, crash-after-commit, stale lease, duplicate effect, independent readback, machine restart. Output: executable tests and machine-readable receipts. Isolated synthetic PASS is not X2 deployment.

### Lane 4: CoUX / CoOrb
Create visible single-Seed/single-Orb/gauge/thumb/time projection of durable WorkID and evidence status. Demonstrate renderer restart and Break Glass native recovery; do not use static mockup as proof of runtime.

### Lane 5: CoReGroup / CoPublish
Review outputs from lanes 1-4, check SHA/commit and test receipts, reconcile contradictory results, reject duplicate work, and publish an explicit release matrix (PROPOSED / TESTED_IN_ISOLATION / VERIFIED_IN_RUNTIME / PUBLICLY_DEPLOYED). No blanket ACK or canon promotion.
