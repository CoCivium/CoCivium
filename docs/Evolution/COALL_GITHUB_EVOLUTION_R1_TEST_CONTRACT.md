# CoAll GitHub Evolution R1 validation contract

This check exists so the Evolution Fabric is not merely persuasive prose.

The validator fails closed when the R1 branch loses required domain families, repository-role bindings, receiver-relative subscription tiers, highlight provenance, CoEvoDelta required fields, or core nonclaim rails.

## Checked invariants

- at least 18 typed evolution domains with unique IDs;
- each domain has labels, relation types, candidate repository homes, and a valid mutation class;
- HOT/WARM/DIGEST/SLEEP subscriptions remain explicit;
- observed repository count matches the stored rows and key repositories remain addressable;
- highlight candidates keep source references and typed relations;
- the existing CoEvoDelta schema retains its minimum proof/routing fields;
- R1 prose retains the key authority/currentness/noncanon rails;
- Evolution README keeps the primary navigation pointers.

## Nonclaims

A passing workflow does **not** prove:

- semantic truth of every relation;
- currentness beyond the observation boundary encoded by each object;
- repository-role permanence;
- downstream session pickup;
- merge approval;
- canon;
- runtime activation;
- public release readiness for every referenced object;
- authority transfer.
