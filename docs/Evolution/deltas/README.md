# CoEvoDelta examples and receipts

This directory contains bounded session-to-shared-field contribution objects.

Each JSON object should conform to the current CoEvoDelta schema and retain explicit source references, mutation class, authority ceiling, confidentiality, tests, risks, wake conditions, and next receiver.

These objects are contribution envelopes, not canon votes.
