# CoVid+ Recursive Media / AI-Readable Publication R0

**State:** `PUBLIC_SAFE_CANDIDATE_ARCHITECTURE__NOT_PUBLICATION_OR_RUNTIME_ADOPTION`

## Lead

CoVid+ treats a video as more than a rendered stream.

A useful CoVid publication may simultaneously be:

- compelling human-facing media;
- an explicit AI-readable semantic substrate;
- a provenance-bearing research artifact;
- an accessibility surface;
- a challenge / contribution interface;
- a remixable archive;
- a public-safe CoAll onramp.

The long-term test is not "did we make one attractive video?" but whether the
publication system is reusable, inspectable, reconstructable, challengeable and
portable.

## Historical lineage

The September 2026 CoVids bootstrap proposed multiple competing architectures:

1. narrated documentary + sidecars;
2. visible AI-readable cue-frame film;
3. interactive web-video / machine-twin hybrid;
4. short-form episodic or chaptered fragments;
5. open local-renderable artifact;
6. other architectures discovered through challenge.

No hidden or subliminal instruction path is desired. AI-facing semantics should
be visible/auditable where practical and duplicated in explicit machine-readable
sidecars.

## Capability ecology

### Source / research
topic discovery; source qualification; claim/counterclaim atlas; timeline;
prior-art recovery; uncertainty; rights/license review; provenance.

### Story / editorial
thesis variants; narrative architectures; story beats; script/edit challenge;
humour/meme passes; receiver-relative edits; derivation lineage.

### Visual / audio
storyboards; shot plans; diagrams/glyphs; motion grammar; thumbnails; reduced
motion; narration; music/SFX provenance; audio description; pacing/silence.

### Semantic media
stable claim IDs; relation IDs; cue frames; frame manifests; WebVTT; chapters;
transcripts; AI Reader Capsule; machine twin; claim/relation graphs;
projection-loss receipts.

### Render / tooling
open-codec evaluation; FFmpeg recipes; Blender/Godot paths; local/offline render;
deterministic render manifests; reproducibility; archival masters; derivative
generation.

### Distribution / portability
web; Substack/article; video-host adapters; podcast/audio; shorts; downloadable
archives; mirrors; feeds/indexes; provider-independent serving; cold
reconstruction.

### Evaluation
human comprehension; AI reconstruction; accessibility; misinterpretation;
epistemic-status preservation; semantic loss; compression/sampling degradation;
prompt-injection resistance; future-machine parsability; receiver readproof.

## Publication loop

```text
publication candidate
 -> human / AI interpretation
 -> challenge / counterexample / accessibility finding
 -> source and evidence qualification
 -> relation update
 -> improved machine twin / sidecars
 -> successor publication candidate
```

No contribution auto-promotes to truth or canon.
