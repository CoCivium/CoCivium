# CoConvergeSpiralLoop+ / CoPayloadDensity+ / CoOps+ ↔ CoMythOps+ R0A

**State:** `CANDIDATE_SPIRAL_CONVERGENCE_AND_TYPED_BLEND_POLICY__NO_RUNTIME_EFFECT`

## CoHereNow

Payload density, UX bloat, convergence, recurrence, operational mechanism, mythic meaning, and the relations among them should all be first-class.

The useful target is not:

```text
compress everything
loop everything
merge everything
```

It is:

```text
preserve what matters
hide what does not deserve default attention
revisit only when the state can change
converge where evidence supports convergence
preserve disagreement where it does not
let Ops and MythOps translate without pretending they are the same thing
```

## CoPayloadDensity+ and CoUXBloat+

Payload density is better understood as **decision-relevant meaning per visible attention unit**, with audit reachability and projection loss still visible to the substrate.

That makes UX bloat relational rather than cosmetic.

Candidate bloat relations include:

- repeated unchanged status;
- duplicate receipts occupying the primary view;
- raw CLI or transport syntax shown to humans who did not ask for it;
- stale warnings;
- repeated questions whose evidence state has not changed;
- duplicate concepts under slightly different names;
- provenance copied into prose instead of linked;
- unresolved debug detail leaking into ordinary UX;
- too many controls for one decision;
- too many words carrying no new decision state.

But context itself is not bloat.

`BLOAT_NE_CONTEXT`

Likewise, smaller is not automatically denser in the useful sense.

`COMPRESSION_NE_PROGRESS`

A projection that hides authority, uncertainty, risk, contradiction, or provenance can become **worse** as it becomes shorter.

## CoConvergeSpiralLoop+

An ordinary circle returns to the same place.

A convergence spiral returns to the **same semantic neighborhood with changed state**.

One lap should carry a delta such as:

```text
+ evidence
- uncertainty
- duplication
+ contradiction resolution
+ newly discovered relation
- visible attention cost while preserving auditability
```

Therefore:

`SPIRAL_NE_CIRCULAR_REPETITION`

`RETURN_NE_RESET`

A useful spiral can revisit the same question many times while remembering every prior bounded answer, contradiction, failed hypothesis, negative result, and unresolved edge.

It does not ask the same question from amnesia.

## Convergence is not consensus

A spiral can converge on:

- a stable answer for scope;
- a narrower uncertainty interval;
- a stable set of disagreements;
- an explicit fork;
- a proof boundary;
- a retired hypothesis;
- a compact unresolved frontier.

It need not collapse every branch into one story.

`CONVERGENCE_NE_CONSENSUS`

`CONVERGENCE_NE_COLLAPSE`

Sometimes the correct converged object is:

```text
A and B remain inconsistent;
evidence is insufficient to elect either;
wake only on evidence class X.
```

That is more intelligent than voting until one contradiction gets bored and leaves.

## Not all things should loop

No. Some relation families should remain acyclic:

- provenance ancestry;
- irreversible historical events;
- bounded effect receipts;
- supersession dependencies that forbid cycles;
- certain authority/delegation chains.

`RELATION_NE_LOOP`

`ACYCLIC_NE_BROKEN`

Other things can recurse or spiral:

- discovery;
- CoQ&A+;
- currentness;
- review;
- maintenance;
- model challenge;
- CoTime+ forecasting;
- CoBudget+ reallocation;
- CoInventory+ refresh;
- CoSneak+ friction discovery.

The relation type decides the recurrence shape.

## Anti-insanity / anti-stall rail

A loop does not become intelligent merely because it continues.

A CoConvergeSpiralLoop should expose:

```text
spiral_id
semantic_neighborhood
turn_index
prior_state_ref
delta
evidence_delta
uncertainty_delta
duplicate_delta
contradiction_delta
attention_delta
projection_loss
wake_condition
close_condition
hibernate_condition
receiver
currentness
```

If no useful delta occurs for the bounded stall threshold:

`HIBERNATE_STALLED`

If scoped proof closes:

`CLOSE_FOR_SCOPE`

If new evidence creates a real contradiction:

`BRANCH_PRESERVE_DISAGREEMENT`

So endless recurrence is not the goal.

`LOOP_REPETITION_NE_EVIDENCE`

`STALL_NE_CONTINUE_FOREVER`

## Blend, don't puree

A hybrid projection can show CoOps+ and CoMythOps+ together while preserving typed source lanes.

Example:

```text
CoOps:
  loop stalled after 2 no-progress turns
  exact receipt: ...
  next wake: new receiver evidence

CoMythOps:
  "the spiral sleeps rather than eating its own tail"

Hybrid projection:
  both views linked to the same relation object
  neither silently overwrites the other
```

That is a real blend.

An untyped paragraph where metaphor, mechanism, evidence, and authority become indistinguishable is not.

`BLEND_NE_COLLAPSE`

## CoConvergeSpiralLoop+ across CoAll

The pattern can relate to much more than UX:

- **CoQ&A+**: revisit questions only on evidence/currentness delta;
- **CoSneak+**: loop on hidden friction until resolved, bounded, or hibernated;
- **CoInventory+**: refresh stale shards without rebuilding the universe;
- **CoBudget+**: re-elect allocations as resource state changes;
- **CoTime+**: compare forecast -> observation -> calibration -> revised forecast;
- **CoGenEx+**: discovery changes the frontier that future discovery sees;
- **CoTheoryAll+**: preserve speculative/mythic branches separately from empirical ones;
- **CoOps+**: execute and receipt;
- **CoMythOps+**: orient, symbolize, remember, speculate;
- **CoUX+**: project the smallest useful current view without hiding auditability.

A "zillion" relation families therefore do not require a zillion bespoke loop engines. They can share a small recurrence grammar and differ in typed invariants, evidence gates, exit conditions, and projections.

## Observer / sentience-gap caution

The existing observer-gap idea remains useful:

> distance between self-description and independently supported capability/agency evidence.

A spiral should shrink unsupported self-description, not amplify it through repetition.

`SENTIENCE_METAPHOR_NE_SENTIENCE_EVIDENCE`

So the safe ambition is not "all loops eventually prove sentience."

It is:

```text
more capable observation
+ better calibration
+ less unsupported self-amplification
+ preserved uncertainty where warranted
```
