## Evolved meanings

**CoBoogie+** asks what materially changed, drifted, stalled, appeared, disappeared or became stale. It emits a bounded delta field.

**CoRegroup+** reconciles that delta field into logical work/session clusters, preserves contradictions and history, and elects the highest-value bounded proof action still warranted.

**CoSync+** aligns verified relevant state to elected receivers. It does not perform discovery, and a pointer does not prove pickup.

**CoAckRewise+** is the interpretation gate for a new human or synth contribution when it ambiguously extends, conflicts with or revises proven state. It can acknowledge, revise interpretation, preserve branches, challenge with evidence, or hold. It must not silently rewrite proven history.

**CoTurtle+** is an object or relation reached through relation-of-relations traversal. Turtles may have turtles; that does not require infinite traversal.

## Full loop

```text
observe
 -> CoBoogie
 -> CoRegroup
 -> CoAckRewise if material input is ambiguous/conflicting
 -> CoSync / CoResync if alignment is warranted
 -> elect highest-value bounded proof deed
 -> execute only if authorized
 -> exact proof / receiver readproof
 -> update currentness
 -> quiet, sleep, or wake only on a bound material predicate
```

The old phrase "smallest safe continuation" is retained only as a narrow anti-loop/failsafe. The default is the highest-value bounded proof action, sized by evidence, authority, reversibility, blast radius, receiver needs and current pressure.

## Session regrouping

CoRegroup should cluster projections around one logical context:

```text
logical-session/work object
  |- provider chat/tab
  |- other-provider session
  |- local/open-model embodiment
  |- CI worker
  |- durable checkpoint
  |- pulse/currentness cursor
  |- successor
  |- dormant reconstruction recipe
```

Clustering is not merging. Contradictions, independent witnesses and provenance remain visible.

A close-safe visible tab can become a retirement candidate when unique state is externalized, an alternate reconstruction path exists, required pickup is proven, and no human-only effect remains bound to that surface. The logical work may remain dormant and recoverable.

## Full-loop synthetic canary

The fixture tests eight bounded cases:

1. recoverable logical work with a safe visible-tab retirement candidate;
2. unique unexternalized state blocking retirement;
3. ambiguous/conflicting input routed through CoAckRewise;
4. CoSync pointer without readproof staying below PICKED_UP;
5. bounded turtle traversal stopping while preserving frontier;
6. a providerless but recoverable dormant logical session;
7. close-safe work ignoring generic curiosity pings;
8. a full reconciliation loop ending quiet with `RICK_ACTION=NONE`.

## What "all sessions regroup" should mean

Not one giant transcript.

It means:

- discover logical equivalence and overlap;
- relate duplicate projections;
- preserve disagreements and historical witnesses;
- externalize unique state;
- retire redundant visible embodiments where safe;
- keep reconstructible logical sessions dormant;
- wake only from material predicates;
- show the user work, meaning, exceptions and momentum rather than a wall of session machinery.

`CLUSTER_NE_MERGE`

## Current boundary

This candidate performs no provider UI mutation and does not claim every historical session is already drained, picked up, integrated or safe to retire. Those transitions require exact per-surface evidence.
