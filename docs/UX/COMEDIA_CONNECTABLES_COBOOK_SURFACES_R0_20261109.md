## The new invariant: CoMediaSemanticTwin+
Every meaningful rich-media element should be able to point to stable source, concept, event, claim and path IDs. Text/box-line diagrams, photographs, SVG art, videos, sound, animation, game spaces, cultural narratives and accessible transcriptions are **projections** of a relational model, not mutually exclusive information stores.

An image can **ILLUSTRATE** a concept. A film can **NARRATE** a timeline. An audio theme can **SIGNAL** a transition. A cultural narrative can **INTERPRET** an idea. A diagram can **EXPLAIN** a dependency. None of those relations means the media itself proves a claim, accurately translates another culture or carries a receiver ACK. Each transform requires a source/rights/projection-loss record.

## Visual ↔ diagram ↔ narration ↔ culture
The canonical transferable layer is a typed relation graph (nodes, edges, time, policy, evidence, provenance), with media scene/segment markers where meaningful. Each chapter/scene/graph node can offer:
- ordinary text and accessible visual/audio description
- stable `work_id`, `media_id`, `concept_id`, `claim_id`, `scene_id` and optional timecode
- source/author/license/privacy/currentness state
- typed relations and reverse traversal
- explicit cultural/translation context and divergent interpretations
- hypothesis labels (especially G_dSide, sacred/metaphysical or quantum analogies), falsifiers where empirical
- a downgrade path (interactive → static SVG → plain HTML → text/JSON).

## Constellation first, not uniform aesthetics
The attached design should be a **visual north star**, not a mandatory style for every screen. Safety, accessibility, low-power mode, professional context and cultural differences warrant distinct surface skins. Offer a quiet/pale/low-motion/plain mode and allow personally preferred aesthetics without altering claim identities.

## What to measure
Public comprehensibility, time-to-first-value, retrieval of evidence from media, bidirectional path success, missing alt/transcripts, accessibility regressions, representation coverage, provenance completeness, consent success and *real* receiver time-to-readproof. Not visual excitement alone.
