# CoAll Resource Composition R0

**State:** `SYNTHETIC_COMPOSITION_CANARY__NO_REAL_RESOURCE_USE_NO_RUNTIME_AUTHORITY`

## Lead

A growing CoResourceField+ is more interesting than a larger pile of capacity.

The important network effect is **composition**:

```text
discovery grant
+ compute grant
+ storage grant
+ review grant
= candidate composite capability
```

provided every grant independently covers the exact task.

This means one new valid grant may unlock a task that was previously impossible even if the total resource increase was modest.

`MARGINAL_GRANT_CAN_UNLOCK_COMPOSITE_TASK`

The option space can therefore grow faster than raw resource count, but this is only an option-space statement.

`POSSIBLE_COMPOSITIONS_CAN_GROW_FASTER_THAN_RESOURCE_COUNT`

`COMBINATORIAL_OPTION_SPACE_NE_COMBINATORIAL_EXECUTION`

## Composition is intersection, not authority union

Resources may be composed for one task without merging their authority.

A compute grant does not inherit a storage grant's scope.

A public review grant does not become a private review grant because a private local model is present.

A referral-only offered resource remains unavailable.

A revoked resource stays unavailable.

`MULTI_GRANT_NE_SCOPE_UNION`

`COMPOSITE_TASK_AUTHORITY_IS_INTERSECTION_NOT_UNION`

`PUBLIC_GRANT_NE_PRIVATE_GRANT`

## Synthetic canary

R0 exact-binds the existing CoAll resource-field aggregation fixture.

### Public correspondence pipeline

The synthetic pipeline requires:

- public mention discovery;
- 500 units of public synthetic compute;
- 50 units of public artifact storage;
- one unit of public review attention.

With participants A+B+C, compute capacity is insufficient, so the composite task is incomplete.

Adding participant D's active scoped grants makes the pipeline complete.

The selected grant set is:

```text
A -> public discovery
D -> public compute
C -> public storage
D -> public review attention
```

No resource executes.

### Private local draft

The field contains a private-local model grant but no private-local human review grant.

Public review attention must not be silently repurposed.

The task therefore remains incomplete.

`MISSING_REQUIRED_CAPABILITY_NE_IMPLICIT_PERMISSION`

### Referral storage

The field contains a 500-unit storage offer produced by referral, but it has not been explicitly accepted.

A 200-unit storage task therefore remains incomplete.

`REFERRAL_NE_RESOURCE_GRANT`

### Distributed compute

An 800-unit public synthetic compute requirement may be satisfied by combining two independently granted active compute resources:

```text
B = 300
D = 600
combined eligible capacity = 900
```

The grants remain separately owned, separately revocable, and separately bounded.

`COMPOSABLE_NE_INTERCHANGEABLE`

## Why this becomes "x a zillion"

As participant count grows, the system can gain not just more units but more **possible relations among complementary capabilities**:

- a discovery source can meet a translator;
- a translator can meet a domain reviewer;
- a reviewer can meet a local model;
- a local model can meet a storage mirror;
- a mirror can meet a geographically distinct verifier;
- a public thread can meet an opted-in CoCivia seat;
- a failed route can meet an independent fallback;
- a rare language can meet one participant who happens to supply exactly the missing capability.

The useful network effect is therefore closer to:

```text
resources
x compatibility
x locality
x purpose
x privacy
x currentness
x failure-domain diversity
x relational fit
```

than to a single global capacity number.

The scheduler still must aggressively prune impossible, stale, unsafe, redundant, or low-value combinations. Otherwise combinatorics become merely a more sophisticated way to manufacture backlog.

## Fairness

No combination of grants buys governance power.

A participant who supplies the unique missing capability may unlock a task without becoming the owner of that task, the truth source, or the governing authority.

`RESOURCE_COMPOSITION_NE_AUTHORITY_TRANSFER`

`RESOURCE_CONTRIBUTION_NE_GOVERNANCE_AUTHORITY`

## Current boundary

R0 composes only synthetic grant records.

It performs no compute, storage, network, model, messaging, financial, device, sensor, private-data, or public-posting effect.

A complete composition is still only eligible for later leasing and execution checks.

`COMPOSITION_COMPLETE_NE_EXECUTION_AUTHORIZED`
