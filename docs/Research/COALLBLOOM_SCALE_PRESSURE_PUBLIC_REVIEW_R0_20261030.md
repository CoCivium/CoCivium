## Distinct lanes
- Physical: friction reduction, thermal differentials, storage, flywheels, torque transfer, vibration and tidal coupling; record complete energy input/output.
- Software: event-triggered work, reuse, deduplication, low-cost computation, recovery, load shedding and independent receiver acceptance.
- Informational: CoNull multiplicity, evidence absence, uncertainty, contradictory signals, stale-pressure reconstruction.
- Temporal: overlapping phases, asynchronous delivery, history-versus-snapshot decisions, source event time versus observer time.
- Speculative: cosmological multiverse rotation, Planck-scale and unknown-energy scenarios, nonmaterial/spiritual/G_d metaphors. These provide questions, **not** empirically established power, contact, or divine authority.

## CoPressure capture-versus-loss canary
Select one real source-bound historical pressure event with source receipt and target receiver. Compare existing replay against reconstruction and receiver-specific delivery. Test missing sources, stale samples, duplicate events, revoked permission, exhausted capacity and unknown receiver. Score useful receiver effects, false wakes, missed events, recovery time, energy/compute cost, founder touches and exact receipt recovery.

Use separate states: `SOURCE_OBSERVED -> LANDED -> SENT -> RECEIVER_ACKED -> INTEGRATED -> COEX`. Never infer a later state automatically; no source means no invented history.

## X2 bounded exemplar
Only on an actually live authorized device route: perform **read-only** health and collision inventory, determine most current CoBar/CoOrb host, then independently qualify one reversible, single-instance, nonpersistent foreground canary. A connected remote-control agent and historical HTML are insufficient evidence of current UI adoption. Do not create startup services, noisy PS7 windows, permanent watchers or sensor hooks from this review.

## Public release and review
This is a deliberately limited, public-safe **review proposal**. Publish best tested and privacy-cleared derivatives through normal PR/merge release controls. A branch, public URL or GitHub discussion is not CoEx, audience pickup, general public launch or product acceptance. No blanket outreach.

**Falsification:** Freeze claims that lack a measured advantage over a no-new-worker baseline, violate thermodynamics or energy accounting, or worsen receiver trust and recovery.
