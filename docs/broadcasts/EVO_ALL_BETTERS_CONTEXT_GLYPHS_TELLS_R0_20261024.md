## CoGlyph+ | Symbols with readable labels, not secret UI

| Symbol | Plain meaning | Boundary |
|---|---|---|
| > | measured greater-than comparison | State units and scope |
| → | next step | Arrow is not an effect receipt |
| ↔ | two-way/inverse relation | Does not prove inverse causation |
| ≠ | difference | Unknown is not automatically false |
| ⊂ | within a declared scope | Membership gives no authority |
| ⊕ | combine permitted resources | Rights remain bounded |
| ⊗ | blocked or incompatible | Explain without leaking secrets |
| Δ | evidence-backed change | Bind prior and successor |
| ◇ | candidate or shadow preview | Proposal is not execution |
| ✓ | scoped PASS | Static proof is not user adoption |
| ✕ | scoped FAIL | Keep reproducible failures |
| ? | HELD / UNKNOWN | Name the missing evidence |
| ⟳ | replay/recover/revise | Undo requires surviving source |
| ∅ | empty bounded domain | Not universal absence |
| ∞ | open-ended logical frontier | Not infinite compute or tokens |

Textual names, accessible labels, reduced-motion and plain-text fallbacks are mandatory when these symbols carry meaning; color, art, vibration and spatial projections remain optional.

## One contextual gesture; many possible relations

**Explicit input → qualify selected object, privacy, app and authority → one local proposal → optional More → deliberate effect → actual receiver receipt → undo/stop/sleep.**

- Writing: ◇ suggest an optional prior or alternative; never globally capture or automatically type.
- Media: ◇ preview exact file identity, size, hash, media metadata and relevant safe destinations; never silently upload.
- CoMap: Δ surface a change, ↔ explore an inverse claim, ? expose an unknown without fabricating absence.
- Fleet: ◇ propose one limited helper with budget, lease and recovery pointer; no massive active spawn.
- Payment/password/private/unknown: ⊗ blocked by default; no capture of content or metadata.

CoInBetween may detect coarse pauses inside an explicitly enabled local editor. A gap is timing, not consent, cognition, identity, attention or a behavioral biometric. No global key logging, hidden clipboard history, high-resolution typing-profile storage, or covert agent fanout.

## CoTell/CoTel/CoTele + histor: working relations, not six new products

- **CoTrail+ / histor:** source-linked event, decision, challenge, effect, receipt, revision, negative witness and successor.
- **CoTel+ / event:** observer-, time-, unit- and evidence-bound measurement, not an imagined signal.
- **CoTell+ / explanation:** reader-relative, attributed account of what happened, alternatives, uncertainty and next proof.
- **CoTele+ / transport:** a specific authorized subscription, route, receiver and deduplicated readproof. Discoverable is not delivered.
- **CoInv+:** scoped contrast/counterexample or inverse relation, with open-world absence/negation rules.

These are provisional CoLex aliases. Each object retains ID, source hash, observed/valid time, privacy, authority, evidence class, recipient/currentness state, reduction loss and recovery pointer. CoMap/CoOrb/rich media render the same object; images do not create new physics, authority or history.
