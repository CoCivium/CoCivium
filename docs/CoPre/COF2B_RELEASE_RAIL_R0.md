## Site release states
1. CONTENT_CANDIDATE: domain-specific promise, source-backed blocks, relevant CoGlyph relationships, and provenance.
2. REVIEWABLE_SOURCE: static HTML and machine-readable contract; noindex if not authorized for indexing; no forms or mail links claiming verified delivery.

4. PUBLISHED_VERIFIED: external URL + deployment log + screenshot + functional readback. If any missing, PUBLIC_HOLD.
5. FEEDBACK_LOOP: feedback captured with consent and delivery receipt; editorial triage, correction history, revalidation before release.
