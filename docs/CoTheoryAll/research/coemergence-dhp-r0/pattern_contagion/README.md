## Core distinction

**Pattern propagation** is the movement or reuse of an identifiable representation, method, behavior or relation across a typed network and time. **Pattern contagion** is an optional descriptive lens for cascading adoption or copying. Neither word is evidence that transmission is causal, beneficial, independent or ethically acceptable.

- A fact can spread and become more accessible.
- An error can spread and become *more entrenched*.
- Ten copies from one common source are **one source family**, not ten independent confirmations.
- Independent replications can challenge a pattern; popularity cannot certify it.
- Retraction, damping, consent, non-observation, immunity or declining adoption can be desirable outcomes.

The existing CoWaveRelation contract already covers amplitude, direction, attenuation, media, interference, noise, provenance and time. CoSpeedo requires stable comparable measures and independent benefit evidence, while CoOomph is a bounded *candidate* effort-allocation layer; it cannot infer authority from velocity. CoObject/OVP supports bounded source and dependency closure, not unlimited copying.

## Four time directions, four epistemic kinds

| View | Input -> output | What it **does not** mean |
|---|---|---|
| Forward | Earlier seeds + edges + assumptions -> **synthetic** possible diffusion / an independently evaluated forecast if later real observations exist | A forecast of real people from a toy network |
| Retrotrace | Later observed node -> possible upstream paths and missing predecessors | Proved cause; retrocausation |
| Backcast | Desired later state -> hypothetical upstream levers and dependency paths | Future knowledge, reverse time travel, permission to intervene |
| Counterfactual | Same starting conditions with altered links -> model-dependent delta | Real-world causal effect without design/identification |

CoTime+ maintains observation, validity, forecast and revision clocks separately. **CoTume+ is unresolved**: search of selected repository contents did not identify an established definition. Preserve it as an alias/meaning candidate, not an automatic replacement for CoTime, CoTune or a verified new primitive.

## Candidate family registry, not automatic new CoTerms

Five **subfamilies** attach to existing CoWaveRelation / CoTime / CoChallenge / CoObject / CoSpeedo / CoOomph. Each name is `CANDIDATE_DEFINITION_REQUIRED` pending CoLex collision check and actual measured usefulness. See `term_candidates.json` for meanings, falsifiers, and destination links.

1. **Spread and topology**: paths, thresholds, shared origins, branching and attenuation.
2. **Temporal inference**: forward projections, ancestor candidate tracing, backcasting, change-point and counterfactual comparisons.
3. **Integrity and anti-contagion**: false consensus, error cascades, dissent propagation, safeguards, revocation and requalification.
4. **Value and pacing**: information gain versus harm/latency/attention, receiver pressure and the anti-Goodhart counter-needle.
5. **Cross-substrate and serendipity**: source-typed representation transfer, cross-scale translation losses, CoObject/OVP closure and unexpected question generation.

### CoSpeedo+ adapter candidate

Expose **separate** needles (never one universal 'contagion goodness' score):

- **Activity trail:** synthetic activation count / real, receiver-attested transmissions (distinct data classes).
- **Independent confirmation:** verified source families and independently replicated meaningful effects; `null` when unknown.
- **Benefit trail:** qualified receiver benefit against baseline and total human/compute cost; `null` when unknown.
- **Counter-needle:** errors, copy correlation, rights conflicts, stale edges, dissent, retractions, harms, and uncertainty.
- **Time:** observed time, effective time, projection horizon, expiry and forecast-calibration windows.
- **Control:** stop/rollback/wake conditions, with shadow-only experiments until authorized.

Do not synthesize needle motion from record counts, and never turn `null` into zero or green. A published page with a moving dial is not live monitoring. Match the existing [CoSpeedo+ proof contract](https://github.com/CoCivium/CoCivium/blob/main/docs/Architecture/COSPEEDO_EXPONENTIAL_PROOF_AND_RECURRENCE_INTERNALIZATION_R0_20261026.md).

### CoOomph+ adapter candidate

High propagation volume should **not** automatically raise compute, budgets, notifications, or influence. Only consider a bounded material burst when independent evidence suggests better receiver outcomes, budgeted costs and attention, low enough proof debt, and *separately authenticated authority*. Otherwise QUIESCE, REVIEW, DAMPEN or SLEEP. This respects the existing [CoOomph / CoBenefit contract](https://github.com/CoCivium/CoCivium/blob/main/docs/Operations/COPARTICIPANT_EDGE_EVOLUTION_R0.md).

### CoPriMath / CoObject / OVP reuse

A candidate pattern relation is a **typed source-bound edge**, not executable instructions. Its source, scope, provenance, observed time, forecast time, rights, authority, uncertainty, projection loss, successors and challenges stay inspectable. Cross-domain / cross-medium translation requires a loss ledger, not an assumed equivalence. An OVP cannot be promoted solely because many nodes copied its name. Tie this to the [CoObject/OVP draft PR #446](https://github.com/CoCivium/CoCivium/pull/446) and [CoQuestionDrive draft PR #445](https://github.com/CoCivium/CoCivium/pull/445), while keeping source vs runtime qualification distinct.

## Executable fixture

```sh

python3 pattern_contagion_r0.py fixture.json
```

- Source input and output: `fixture.json` and `sample_results.json`, generated for this fixed fixture.
- Inputs accept no effect authority. Edges must be typed as **candidates**, not verified causes.
- Simulated exposure permission can block propagation to a node; it is not real consent.
- Damping / noise is deliberately bounded, seeded and deterministic across input ordering. The physical or social process is **not** calibrated by this test.
- A blocked directed edge reduces the toy's synthetic activation count from 4 to 3; it does not demonstrate real causal leverage.
- Reverse reachability makes possible-ancestor and planning-lever candidates only.
- The test harness reports **25 source-level tests**. True independent receiver adoption, robust statistical forecasting, calibration across future windows, usefulness and effects are `NOT_OBSERVED`.

## Prior art and challenge

This is not a claim to have invented diffusion theory. Relevant mature comparators: network diffusion / independent cascade / threshold models, epidemiological and social contagion modeling, information cascades, influence-maximization studies, stochastic processes, causal graphs, Bayesian evidence and time-series prediction. A serious model must examine their assumptions and compare with simpler random/no-spread/last-observation baselines using held-out prospective evidence. Prior-art review by a domain expert remains unperformed.

## First real proof gate

Choose a **consented, non-sensitive, no-automatic-contact** workflow, e.g. passage of a single source-cited research pattern between independent reviewers. Freeze the source version; tag shared-source families; keep independent receiver readproof; preregister a falsifiable forecast; measure actual usefulness and correction rate versus strong ordinary documentation. Preserve the non-propagation/no-change baseline. Only then decide if a CoSpeedo source adapter is warranted, and continue to require real operational authorization for any effects.
