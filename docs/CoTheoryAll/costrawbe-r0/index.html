Challenge before belief

How this should try to fail

  1. Define “not quantum in itself” operationally, not poetically.
  2. Construct competing fundamental-versus-projection models.
  3. Derive observations that would discriminate between them.
  4. State falsifiers and assumption-sensitive outcomes.
  5. Relate the result to established quantum foundations rather than merely renaming them.
  6. Preserve contradictory and minority interpretations.
