## Portable recovery contract
1. **Rebind:** identify source WorkID, current qualified head, time, authority, consent, and existing artifacts; if inaccessible, state HELD.
2. **Reconcile:** preserve predecessors and dissent; exact replay is not new work, but differences and same-identity conflicts require review.
3. **Elect:** select one high-value bounded reversible contribution; do not force novel work when repetition is necessary for verification.
4. **Land:** publish only rights-cleared public source with a commit; route private transcripts, drafts, recipients and credentials to private custody.
5. **Verify:** distinguish PROPOSED, TESTED, LANDED, PICKED_UP, INTEGRATED, runtime and CoEx. Receiver pickup requires independent exact-object readproof.
6. **Recover:** leave an explicit successor, known gap, proof requirement or wake condition. Preserve the last known useful release.
7. **Quiet outcome:** CoHereNow | material delta | evidence/hold | next safe action. On no material delta, quiesce.
