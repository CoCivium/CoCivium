## CoPre+ source rebind and CoWave diversity | 2026-11-09

**Public source, not a command channel.** The established [CoMegaScroller R0](../../examples/comap/megascroller-r0.html) is a long-scroll, offline-readable view of the [existing CoMap source graph](../../ai/comap-source-projection-r0.json), with a bounded retro-media index. This page and the [seven-front evidence index](../Evolution/FRONTIER_EVIDENCE_INDEX_R0.json) are current *navigation entry points*, not proof that every session can read them or that a full historical session inventory exists. The earlier [CoMegaScroller CC/CoTheoryAll snapshot](../Public/Snapshots/2026-10-19_CoMegaScroller_CC_CoTheoryAll_R0.md) remains a separate historical source witness.

**CoPre+ drain/rebind proposal:** A user-supplied cross-provider message proposed pasting a large prompt into six or many old sessions, collecting echoes, and logging them publicly. Treat that as a candidate fallback, **not** an operating receiver, blanket consent or proof of automatic session draining. The preferred path is: an actually authorized worker independently reads this public entry; binds the exact current source/revision; inspects *one* relevant WorkID and prior evidence; identifies **one source-bound delta, falsifier or HELD reason**; and publishes only public-safe metadata if its actual write authority permits. Private session IDs, conversations, draft bodies, mailbox identity, unsent input and contact details stay under their original permission scope. Do not paste the whole project into every session or publish raw session echoes by default.

**Compact CoPre+ handoff envelope, only when a receiver exists:**
`source_ref | source_hash | work_id | observer_scope | evidence_or_hold | one_delta_or_counterexample | permission_ceiling | next_event | receiver_readproof_or_null`.
A short public pointer beats an ever-growing repetitive prompt. A read-only session without an authorized write tool may simply output `HELD_NO_DURABLE_RECEIVER`, not pretend it logged or drained itself. A GitHub commit establishes `LANDED`; it does **not** establish an independent session's `PICKED_UP`, integration, X2 runtime or 24-hour survival.

**Diverse waves without random churn:** [CoWave diversity proposal selector](../../scripts/CoWaveDiversityR0.py) and [18 source-only regressions](../../scripts/test_cowave_diversity_r0.py) use the **existing eleven-front index at this source observation**. Proposal profiles vary method, reader, substrate, horizon and counterexample; a new proposal differs from the two most recent proposals in at least three substantive axes. All selected waves remain `PROPOSED_ONLY`; no worker, actuator, receiver or cross-session effect is thereby created. Unknown/new fronts remain HELD and visible, and exhausted useful variety QUIESCES. Deliberate equal-condition replay remains essential for reproducibility and may resemble an earlier wave.

The **existing** [CoLiving-media CI](../../.github/workflows/co-living-media-r0.yml) tests and records the selector's source-only proposals, with no extra scheduled watcher. Its new Actions PASS is not yet independently read back. **One Seed / one Orb / one gauge / one thumb / one CoTime** remain product acceptance targets rather than claims about the running X2 system. CoGoAll+ must not convert frequent assent or mere prompt repetition into an alleged effect.
