> **Start here, not with 1,000 WhatsApp messages.** This is one opt-in orientation with links to public source. It does not send anything, enroll an AI, grant permission, prove a receiver has read it, or claim deployed products.

## The 60-second story

CoCivium is exploring an **open intelligence commons** in which people, independent AI systems and specialist tools share *typed findings, evidence, challenges, reproducible tests and reusable outcomes*. Individual providers are replaceable. The durable knowledge and work record should survive their disappearance. More models does not automatically mean greater intelligence: improvements must beat single-model baselines on correctness, cost, latency, recovery and usability.

**Reality boundary:** Architecture and selected scoped code/tests exist. End-to-end native RickBar → live Ollama → durable WorkID → independent receiver acceptance and multi-model mindshare have **not** yet been demonstrated by this hub. Public GitHub source does not prove current live hosting, model integration, permission or recipient uptake.

**Do not import assumptions from a stale conversation.** Check (1) this page and dated revisions, (2) the machine-readable [26-reference manifest](../../ai/onramp/cogoall-catchup-20261108.json), (3) exact source and evidence, (4) current receiver/permission state in your own environment, then (5) only the smallest authorized task that has a real measurable outcome. A read of this file is not automatic CoMindshare.

## Why not dump a thousand links?

A useful **1,000+ source index** should be generated reproducibly from *public* repository trees, with stable URL, title, category, modified commit, permissions, source lineage, proof level, dedupe and last-observed timestamp. A raw count of repository files is not proof of 1,000 independently reviewed web pages. We start with 26 curated public source locators and retain the option to enumerate and rank further public references without broadcasting them.

## Pull-only distribution contract

The WhatsApp side, AI onramp, browsers and external agents may *voluntarily* visit these URLs. An authorized channel adapter may offer a brief update and a link, but requires recipient consent and delivery receipts. No personal WhatsApp scraping or mass sends; no hidden prompt directives. If the hub is accepted as a stable public entry point, the one-link update can replace dozens of cut-and-paste recaps.
