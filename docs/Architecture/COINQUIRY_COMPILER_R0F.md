## Purpose

CoSneak+ can detect hidden friction. CoQ&A+ can preserve living questions. GTRAIL+ can trace currentness, evidence and successors. The missing layer is a compiler that turns a useful question into a bounded proof deed.

```text
signal / question
-> dedupe by downstream decision
-> hard eligibility gates
-> Pareto proof frontier
-> one bounded next proof
-> receipt
-> calibration
-> retire / reopen / branch
```

This is deliberately narrower than generating more ontology.

## Hard gates

A question cannot become an executable next proof merely because it sounds important.

R0F requires:

- named receiver;
- bounded probe;
- evidence surface available;
- no unresolved authority conflict;
- not already resolved for scope;
- negative evidence defined;
- stop or retirement condition defined.

Questions that fail these gates remain questions. They do not become background compute.

`OPEN_NE_ACTIVE_COMPUTE`

## Priority without one magic score

Eligible questions are compared on:

- retirement leverage;
- dependency reduction;
- human-attention reduction;
- false-completion detection;
- proof cost.

A question is removed only when another eligible question is no worse on all five and strictly better on at least one.

The survivors form a Pareto frontier.

`PARETO_FRONTIER_NE_GLOBAL_OPTIMUM`

The fixture's local tie-break is transparent:

1. lowest proof cost;
2. highest false-completion detection;
3. stable ID only if still tied.

That elects the next bounded proof for this fixture, not the most important truth in CoAll.

## Compiled frontier

The fixture tests existing questions concerning:

- PASS claims without receiver pickup;
- human relay / refresh / manual dependency;
- false failure-domain diversity;
- emission outrunning receiver capacity;
- recurring deeds that could move to local/open workers;
- capability masquerading as authority;
- the meta-question asking which proof retires the most questions.

The meta-question is intentionally not executable because it lacks its own bounded probe.

## Nonclaims

It does not turn question priority into truth priority.
