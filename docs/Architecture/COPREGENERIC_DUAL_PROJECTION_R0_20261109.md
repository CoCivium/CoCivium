# CoPreGeneric: Source-bound, dual-projection recovery contract R0

**Status:** Public-safe R&D proposal, 2026-11-09. Not canon, an operating prompt, a deployed synchronization service, an AI directive, or evidence of AGI/sentience.

## Purpose

A CoPreGeneric trigger should help an authorized reader or agent recover the **relevant** work state from durable sources, contribute a bounded improvement, and preserve source identity and dissent. A pasted phrase, chat version label, or publication alone does not prove delivery, receiver pickup, integration, or synchronization.

- [Session bootstrap](https://github.com/CoCivium/CoCivium/blob/main/SESSION_BOOTSTRAP.md)

On recovery, read those pointers and only the work objects relevant to the recipient's authorized role. The public repository is a public/currentness surface, not a sole custody root or global session event bus.

## Common source-bound object, multiple useful projections

A shared object uses stable `work_id`, typed `source_refs`, `source_digest`, `observed_at`, optional `event_at`, `qualified_at`, `claim_state`, `authority_scope`, `relations`, `dissent`, `last_known_good`, `receiver_receipts`, `next_proof`, and `privacy_class`. Unknown is an explicit value, not a placeholder that silently becomes fact.

**Synth-facing projection:** structured graph/JSON, versioned schemas, content digests, explicit types, dependency links, epistemic statuses, tool/capability constraints, idempotency and deterministic reconstruction. Machines should not inherit authority merely by parsing a file.

**Bio-facing projection:** a concise CoHereNow headline, meaningful CoMap/CoNav diagrams, accessible text, differences over time, clear permission boundaries, one next action, and expandable evidence. A visually attractive page is not automatically accepted UX.

Neither projection is the source of truth by itself. Both must cite the same underlying source identities; interpretation or translation loss remains observable.

## CoLatch, CoTime, CoEv and CoPre

1. **REBIND:** discover the recipient's actual session/work identity and current authorized evidence, without clobbering prior state.
2. **DEDUPE:** exact duplicates remain observations; changed meaning, authority, source or contrary evidence gets a distinct branch.
3. **TIME:** distinguish event, observation, qualification and effect times. Late historical inputs may change present interpretation but not history.
4. **MEANING:** context-free media or language becomes a candidate hypothesis or UNKNOWN; inversion is a legitimate test, not a forced conclusion.
5. **EVOLVE:** choose bounded improvements, replications, counterexamples or retirement by estimated useful information gain and risk, not name-count or novelty alone.
6. **LAND:** preserve approved artifacts with digests and receipts, then request exact-object receiver readback. No automatic private-to-public promotion.
7. **REPORT:** `CoHereNow | verified delta or NO_UPDATE | held gap | next bounded deed | exact evidence pointer`.

## Federation and public constellation

A megascroller, API/JSON, GitHub file, diagram, accessible text, or alternate provider view are **projections**, not automatically independent backups. Count an independent failure domain only after its receiver successfully retrieves the exact object and proves reconstruction. Do not publish personal communication, private operational state, credentials or unreviewed session transcripts merely to help agents discover them. Opt-in, revocation and minimization travel with any shared relation.

## Exploratory and inverse lanes

`G_dSide`, `CMA`, `CoAGI`, possible sentience, future-mind models, oscillation and CoSynthVerse/CoBioVerse are open conceptual or hypothesis lanes. Oscillation can model feedback cycles and time dynamics; it is not proof of a supernatural source, emergent awareness, AGI or a predictive channel from the future. Their human and machine projections should retain competing naturalistic explanations, prediction tests, failure criteria and source provenance. Ethical treatment of people and systems must not depend on settling consciousness debates prematurely.

## Bounded acceptance tests

- An old input arrives after a newer one; the original event time remains intact.
- The same message appears twice; no duplicate external effect occurs.
- A source loses its meaning context; it remains UNKNOWN rather than graduating to truth.
- A visual and a JSON projection disagree; both expose the conflict and reference source identities.
- A receiver resumes from a durable packet, reports the exact object digest, and describes the next bounded action without human copy-paste.
- A proposed public mirror is unavailable; the system records HELD rather than inventing an ACK.
