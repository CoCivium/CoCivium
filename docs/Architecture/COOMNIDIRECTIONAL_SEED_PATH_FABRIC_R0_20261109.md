# CoOmniDirectional+ | CoSeed / CoPath / CoFront / CoEcho / CoTime | R0
**Date:** 2026-11-09
**State:** PUBLIC DESIGN CONTRACT; NOT UNIVERSAL SYNC, RECEIVER PICKUP, CANON, COEX, OR RUNTIME
**Scope:** Public-safe, reversible, machine-readable fan-in for CoBookCiv2+, CoMap+, CoBraid+, CoCircuit+, CoNav+, CoG_dSide+ exploration and future fronts.

## Problem
A public source, a GitHub comment, a conceptual link, a consumed record, and an independently verified downstream integration are different events. One-way broadcasting leaves orphaned artifacts and stranded discoveries. This contract permits multiple directional traversals over one source-bound relation fabric without mistaking ideas for effects.

## Shared record (minimum)
- work_id and immutable source locator; content digest where possible
- observed_at, event_time, ingested_at, and uncertainty of time ordering
- source rights/publication class: PUBLIC_SAFE | PRIVATE | UNKNOWN | RESTRICTED
- epistemic class: OBSERVED | TESTED | HYPOTHESIS | SPECULATION | REFUTED | UNKNOWN
- semantic review state and coverage scope
- CoSeed identifiers (why potentially valuable)
- CoPath identifiers (possible next work, dependency, reverse prerequisite)
- typed relations: DERIVED_FROM, SUPPORTS, CHALLENGES, CONTRADICTS, DEPENDS_ON, INVERTS, PRECEDES, SUPERSEDES, RELATED_TO, PROPOSES_TEST, RECEIVED_BY
- audience and projection eligibility (book, accessible list, map, circuit, temporal braid, game, structured JSON)
- exact receiver ID and readproof only if actually observed
- claims ledger: who asserted which transition, with evidence pointer and timestamp
- inverse/retropredictive queries as labeled search hypotheses, never asserted historical events

## Omnidirectional queries
1. Forward: source -> seed -> path -> experiment -> verified product.
2. Backward: claimed result -> required evidence -> source and authority.
3. Temporal: before/after/as-of snapshots; conflicting timestamps retained.
4. Across fronts: find compatible projection/receiver by typed capabilities and permission.
5. Inverse: seek countermodels, missing causes, alternative interpretations.
6. Retro-predictive: ask which earlier unindexed records might illuminate today's gap, then search actual available inventories.
7. Cross-scale: chapter -> section -> concept -> artifact -> context bundle, and back.
8. Human/AI: same open records, with different accessible projections; no hidden agent instructions or automatic privilege escalation.
9. G_dSide: speculative and metaphysical questions explicitly tagged; factual evidence and spiritual interpretation never silently conflated.
10. Recovery: reconstruct a useful edition from versioned immutable bundles, even with some mirrors absent.

## Intake and delivery gates
DISCOVERED_LOCAL -> VERIFIED_LOCAL -> LANDED -> PICKED_UP -> INTEGRATED -> COEX.
Each transition requires its own evidence. Hashing is not semantic ingestion; publishing a coordination record is not receiver pickup; GitHub availability is not website deployment. Unknown and private records never default to public. Make no claim of exhaustive historical coverage.

## Human-facing first
One comprehensible CoBookCiv2+ megascroller or accessible list, with CoMap/CoCircuit/CoBraid overlays and evidence drill-down. Plain HTML must remain useful without JS. CoTerms may be surfaced with ordinary-language translations. Maintain source-relative deep links and clear exit/export.

## Research-wave novelty and invariants
Wave fingerprints cover audience, source set, hypothesis, method, representation, artifact, test, and failure mode. Prefer substantial novelty across waves; explicitly permit reproducibility, regression and emergency recovery. Preserve existing MVPs. Many read-only challengers, one elected actuator per collision domain. Quiescence is acceptable; invented always-on activity is not.

## Minimum demonstrator acceptance
- One verified public-safe source, one CoSeed and one CoPath, each with exact source back-links.
- Navigation in at least two directions, with a contradiction or dependency edge.
- A plain human-readable projection plus a documented machine-readable projection.
- A second reader retrieves the exact source and seed/path objects, with readproof.
- Public/private boundary test, broken-link/orphan test, and content hash verification.
- Later-than-24-hour survival requires a genuinely later independent re-read; tests run now cannot prove it.
