## CoPre R0 roles

**CoPreFooter:** per-wave human projection of the current source-bound next deed. **CoPrePack:** exact machine packet that owns lineage, source, constraints, verification and recovery. **CoPreWave:** one versioned transition under a stable WorkID. **CoPreOffload:** a *proposal* to delegate one role to a named eligible local/CI/provider helper only when a real adapter with verified readback/permissions exists. **CoPreColdStart:** reconstruct a successor from the pack and source, then compare its independent understanding and authority against pinned contract. These are role definitions, not claims that new services are running.

The NEXT footer is **semantically changed on a material wave**, not randomly paraphrased every response. Same WorkID + same exact source revision + same delta produces QUIESCENT rather than creating artificial advancement. Each material successor gets `sequence` + `parent_pack_sha256` + new `pack_sha256`, preserving predecessor and correction lineage. Human-readable text is derived from the pack, never treated as its hash.

```text
CoHereNow | bounded evidence state
NEXT | one elected deed, its exact completion test and stop/wake condition
CoPre+ | WorkID · sequence · purpose · source revision · delta
        | exact receiver + authority ceiling · collision domain
        | next_deed · falsifier/verification · budget
        | expiry/stop · bound wake · predecessor hash · recovery pointer
        | pack hash · delivery/ACK/integration: UNKNOWN until independent proof
```

## Proposed durable cycle, with failure points visible

`SOURCE/WORKID -> RESTORE STATE -> READ HEAD/RECEIVER CURSOR -> CoIndex LOOKUP -> DEDUPE/CoPatternGate -> ELECT NEXT -> CoPrePACK -> AUTHORITY/RISK/PRIVACY CHECK -> LEASE ONE ACTUATOR -> CHECKPOINT -> EXECUTE IF AUTHORIZED -> SELF-CHECK -> INDEPENDENT RECEIVER READPROOF -> ATOMIC COMMIT -> SCORE -> COMPACT / OFFLOAD OR DORMANT -> WAKE ONLY ON BOUND DELTA`.

This is a target integration graph. Present R0 implements only the **read-only pack compiler**, not worker leasing, scheduling, local Ollama calls, provider tab mutation, effect execution, or automated offload. Private inputs remain private; this public compiler refuses nonpublic packets.

## Package size and CoPrePack+

- **P0:** NEXT footer only, when existing durable source suffices.
- **P1:** embedded JSON CoPrePack with source and exact semantic context.
- **P2:** file-backed, hash-pinned source/executable fixture in existing elected custody.
- **P3:** content-addressed dependency manifest/CoTurtles graph, distinct public/private partitions.
- **P4:** streaming or distributed work graph with bounded windows, fencing leases, retry/idempotence, receiver-specific checkpoints and independent failure domains.

P2-P4 inherit the existing CoPayload ladder; do not introduce a competing packaging protocol. Offload a *bounded task*, not a permanent autonomous entity, and do not put confidential data into public branch artifacts.

## CoIndex adequacy test

A search hit is only discovery, not semantic integration. CoIndex is deficient if a **fresh, exact eligible object** is known to exist but cannot be found by its WorkID, role, precursor term, stable source, current version, receiver, blocker, or successor pointer within a defined latency/coverage budget. Test the index against both current-head direct reads and qualified historical recall. Detect search-index lag, duplicated aliases, orphaned `NEXT`, wrong head, false latest, dead pointers, and access-denied cases; report recall@k, stale-pointer rate, time-to-qualified-source, receiver pickup and human relay. Fix missing indexes and transition adapters before multiplying search or prompt layers.

## Human / synth / provider boundaries

- A session is a **worker embodiment**, not the custody root or an inexhaustible scheduled process.
- An automation is a trigger, not a source of authorization or a direct channel into every ChatGPT, Meta AI, WhatsApp, Claude or local-provider session.
- Headless virtual work is only independent of the human when it has concrete permissions, device/substrate, source, durable state and a provable receiver effect.
- Generic assent, time passing, another session's unrelated progress, new token budget, or idle compute is **not** a material wake.
- When X2/offline observer or private custody is unavailable, continue only safe public/read-only review work and leave the affected effect HELD.
- G_dSide can challenge possible futures and harmful dependencies; it never supplies evidence, leases, consent or operational authority.

## R0 executable boundary

[CoPreContinuationR0.py](../../scripts/CoPreContinuationR0.py) deterministically compiles one public, source-current, read-only material delta into an immutable-hash CoPrePack candidate. Missing required fields, stale predecessor, generic wake, unverified source, private scope, effect class, oversized budget or mismatched WorkID become HOLD; nonmaterial/repeated deltas become QUIESCENT. It cannot call another session or automatically send the pack. Its synthetic test includes packet stability, bounded budget, no-op, stale/collision, privacy/effect hold and legitimate two-wave succession.

`python3 -B scripts/CoPreContinuationR0.py --selftest`

CI execution is separate from source presence. The acceptance sequence is: 1) source test green, 2) current-main compatible, 3) one consenting separate receiver reads exact CoPrePack hash and reconstructs intended task with zero Rick relay, 4) repeat across a 24h independent failure-domain interruption, 5) prove a real bounded next deed and useful outcome, 6) only then propose provider/session-specific implementation. No blanket universal claim.

**CoBreath:** `DEFINED_NE_EXECUTED | NEXT_NE_COMMAND | PACK_NE_PICKUP | AUTOMATION_RUN_NE_ORIGINAL_SESSION_WAKE | SOURCE_TEST_NE_AUTONOMY | VIRTUAL_NE_INDEPENDENT_HOST | MORE_PROMPTS_NE_MORE_PROGRESS | DIFFERENT_WAVE_NE_DIFFERENT_WORDING_ONLY | UNKNOWN_NE_ACK`.
