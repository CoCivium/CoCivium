# CoETSignalFinder+ / CoG_dHypothesisFinder+ R0

**State:** PUBLIC_ARCHITECTURE_CANDIDATE__NO_ET_DETECTION__NO_GD_MEASUREMENT  
**Observed:** 2026-10-24

## Purpose

Create two related but non-conflated discovery lanes:

1. **CoETSignalFinder+** — ingest public astronomical / technosignature-relevant data and rank anomalies or candidate follow-ups.
2. **CoG_dHypothesisFinder+** — generate, compare and falsify explicit mathematical / relational hypotheses associated with G_d-style ideas.

Neither lane may promote an anomaly, story, model consensus, symbolic resonance or unexplained result into ET detection, metaphysical proof or a new physical field.

## Existing CoAll typing

Retain:
- astronomical data: OBSERVED / MEASURED when source supports it;
- ET: ET_EMPIRICAL_HYPOTHESIS until detection evidence exists;
- G_d / metaphysical propositions: METAPHYSICAL_HYPOTHESIS until a reproducible discriminating definition/test exists;
- mythic/symbolic lanes: MYTHIC / METAPHOR;
- unexplained anomaly: UNKNOWN / HYPOTHESIS, not cause.

## CoETSignalFinder+

Candidate public source classes:

- Breakthrough Listen Open Data Archive;
- NASA Exoplanet Archive TAP/API/bulk data;
- TESS/Kepler/K2 candidate and host-star data through NASA archive services;
- public SETI/technosignature research results and methods;
- other public astronomical archives only after source qualification.

Candidate pipeline:

```
SOURCE
-> CURRENTNESS / PROVENANCE
-> NORMALIZE
-> QUALITY FILTER
-> BASELINE
-> ANOMALY CANDIDATE
-> ORDINARY EXPLANATIONS
-> INDEPENDENT DATA / REPEATABILITY
-> FOLLOW-UP PRIORITY
-> RECEIPT
```

Candidate anomaly dimensions may include:
- spectral / temporal outliers;
- unusual repetition or drift;
- target/sky-position coincidence;
- cross-instrument recurrence;
- catalog mismatch;
- unexpected engineered-looking structure hypotheses;
- observation gaps that warrant follow-up.

No anomaly is a detection.

## Detection escalation

Before any ET-detection language:

1. instrumental / software / clock / metadata error checks;
2. terrestrial interference / local contamination checks where relevant;
3. astrophysical ordinary explanations;
4. independent instrument / observer confirmation where feasible;
5. source and timing provenance;
6. explicit uncertainty;
7. qualified scientific review;
8. communication consistent with recognized SETI detection principles.

`ET_HYPOTHESIS_NE_ET_DETECTION`
`ANOMALY_NE_CAUSE`

## CoG_dHypothesisFinder+

Purpose: search the design/theory space for explicit candidate G_d definitions that can survive comparison against simpler alternatives.

Candidate schema:

```
hypothesis_id
definition
units_or_dimensionless_status
inputs
domain
predicted_relation
baseline
counterexample_search
falsifier
measurement_or_simulation_plan
source_refs
status
```

Candidate modes:
- graph distance / relational distance;
- observer-relative distance;
- information / description distance;
- causal distance;
- temporal distance;
- semantic distance;
- energetic/resource distance;
- composite multi-objective metric;
- purely symbolic/metaphorical interpretation.

The finder should aggressively search for:
- trivial equivalence to existing measures;
- undefined units;
- circular definitions;
- non-identifiability;
- counterexamples;
- regime dependence;
- observer dependence;
- Goodhart failure;
- lack of discriminating prediction.

A G_d candidate only graduates scientifically if it makes a reproducible prediction or discrimination that simpler baselines do not.

`GD_HYPOTHESIS_NE_MEASURED_FIELD`
`USEFUL_METAPHOR_NE_PHYSICAL_QUANTITY`
