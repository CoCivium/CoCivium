## Thesis

CoAll does not need a literal zillion named terms. It needs a compact grammar capable of generating, testing, composing, retiring, and reusing zillions of candidate relations lazily.

`LAZY_GENERATION_BEATS_EAGER_ONTOLOGY`
`CANDIDATE_NE_COTERM`

## Base lifecycle

`Discover -> Qualify -> Relate -> Resource -> Experiment -> Produce -> Verify -> Preserve -> Extend -> Recombine`

## Zillion grammar

Generate candidate relations as:

`DOMAIN x OPERATOR x RECEIVER x TIME x SCALE x SUBSTRATE x EVIDENCE x AUTHORITY x PRIVACY x REVERSIBILITY x CURRENTNESS x RISK x COST x FAILURE_DOMAIN x FUTURE_BRANCH`

Then add second-order axes:

`MOTIVE x VALUE_VECTOR x MAINTENANCE_MODE x DECAY_MODE x WAKE_MODE x RETURN_MODE x DISSENT_MODE x CREDIT_MODE x ACCESS_MODE x PUBLICATION_MODE x MEDIA_MODE x RECOVERY_MODE x SUCCESSION_MODE x QUESTION_LENS x MODEL_CLASS x OBSERVER_CLASS`

Do not materialize the full Cartesian product.

## Higher-order operators

### CoCompose+
Combine compatible relations into a larger reusable pattern.

### CoFactor+
Extract repeated structure into a smaller shared primitive.

### CoLift+
Move a useful relation to a higher scale while preserving its conditions.

### CoGround+
Force a high-level claim back into source/evidence/receiver-specific detail.

### CoProject+
Render one source relation differently for different receivers without changing source truth.

### CoTranslate+
Move across language, medium, substrate, model, or discipline with a loss ledger.

### CoCompress+
Reduce active complexity while preserving recoverable pointers and distinctions.

### CoExpand+
Rehydrate detail from compressed context when a receiver or test needs it.

### CoStress+
Apply bounded adversarial pressure to expose fragility.

### CoAnneal+
Reduce accumulated local-optimum lock-in through controlled exploration and reselection.

### CoReseed+
Reintroduce dormant high-option-value material when conditions change.

### CoMetabolize+
Turn failures, obsolete branches, negative results, and retired assets into reusable feedstock.

### CoPluralize+
Preserve multiple viable interpretations or implementations where convergence is premature.

### CoConverge+
Collapse only when evidence, coordination value, and receiver need justify narrowing.

## Selection

Each generated candidate should score on a vector, not one scalar:

`information_gain + receiver_value + proof_gain + recovery_gain + optionality + reuse + independence + comprehension + fairness - risk - cost - maintenance_debt - proof_debt - coercion - lockin`

Selection pipeline:

`ADDRESSABLE_ALL -> CONTEXT_FILTER -> TOP_20 -> FIRST_RING_8 -> EFFECT_1`

## Naming discipline

Mint a new CoTerm only if the candidate operation is:
1. semantically distinct;
2. repeatedly useful;
3. not already covered by an existing family;
4. testable;
5. likely to reduce rather than increase cognitive load.

`MORE_NAMES_NE_MORE_CAPABILITY`
