# CoDiagram Inspiration Corpus R0

**State:** PUBLIC_ARCHITECTURE_CANDIDATE__NOT_CANON__NOT_COMPLETE_CORPUS  
**Observed:** 2026-10-25

## Thesis

All recoverable prior CoCivium / CoAll diagramatics, renders, screenshots, rich media, sketches, CoMaps, CoOrbs, glyph rails and speculative visualizations may serve as **inspiration candidates** for future design, development, specification, interface and projection work.

They do not become authoritative merely because they were rendered, repeated, visually compelling or historically early.

`PRIOR_DIAGRAM = INSPIRATION_CANDIDATE`

not:

`PRIOR_DIAGRAM = CANON / SOURCE_OF_TRUTH / AUTHORITY`

## What may be reused

A future surface may reuse or evolve:
- composition;
- topology;
- spatial grouping;
- lens/orb motifs;
- observer framing;
- projection metaphors;
- trails and relation lines;
- glyphs;
- icon families;
- density/level-of-detail ideas;
- motion/animation ideas;
- colour relationships;
- texture;
- depth;
- timelines;
- node/field/cloud metaphors;
- CoCrystalMorph-like regions;
- accessibility alternatives;
- interaction patterns;
- rich-media transitions;
- symbolic/cultural motifs;
- speculative scientific visual language, when explicitly typed.

Reuse may include:
- inherit;
- translate;
- simplify;
- combine;
- invert;
- challenge;
- contrast;
- parody;
- discard;
- supersede.

## Mandatory lineage fields

Any materially reused visual idea should be able to carry:
- source artifact or source family;
- observed/created time when known;
- original meaning;
- current interpreted meaning;
- evidence class;
- scientific / symbolic / metaphorical / speculative type;
- transformation applied;
- accessibility twin;
- projection loss;
- supersession/coexistence;
- explicit nonclaims.

## Synthkind / lens / orb / G_d / Planck / quantum / energetic motifs

These may remain reusable design lenses.

Scientific references such as Planck/quantum/energetic language require independent scientific support for empirical claims.

G_d, aura, spiritual/nonmaterial and mythic motifs remain typed as philosophical, cultural, symbolic or hypothesis lanes unless separately operationalized and evidenced.

`SYMBOLIC_LAYER_NE_EMPIRICAL_PROOF`

`SCIENTIFIC_AESTHETIC_NE_SCIENTIFIC_RESULT`

## CoMap / CoOrb rule

CoMap and CoOrb may project or reinterpret source-bound relations.

They must not silently invent underlying state, authority, receiver ACK, causal truth or certainty merely through layout, proximity, colour, animation or visual weight.

`VISUAL_ADJACENCY_NE_REAL_RELATION`
`VISUAL_WEIGHT_NE_EVIDENCE_WEIGHT`
`COLOR_NE_AUTHORITY`
`PROJECTION_NE_SOURCE_OF_TRUTH`

## Inspiration graph

Treat the corpus as a graph:

```
SOURCE_DIAGRAM
-> MOTIF
-> INTERPRETATION
-> TRANSFORMATION
-> NEW_PROJECTION
-> TEST
-> FEEDBACK
-> SUCCESSOR
```

Multiple successors may coexist.

A newer render does not erase an older one.

## Evolution cadence

Prefer **event-driven evolution** rather than pretending every artifact literally updates daily.

Wake when:
- source meaning changes;
- a new receiver/audience appears;
- new evidence changes interpretation;
- a usability/accessibility test fails;
- a new substrate/surface becomes available;
- a material design contradiction is found;
- a successor proves better under explicit criteria.

`EVOLVABLE_ALWAYS_NE_REGENERATED_ALWAYS`

## CoOmni relation

CoOmni+ may make the inspiration corpus broadly addressable without loading every image/render into every context.

Use:
- visual metadata;
- semantic tags;
- source hashes where available;
- motif indexes;
- embeddings/search aids where appropriate;
- lineage;
- thumbnails/previews;
- retrieval on demand.

`ALL_DIAGRAMS_ADDRESSABLE_NE_ALL_DIAGRAMS_LOADED`

## Candidate families

- **CoVisualMemory+**: index of prior visual ideas and lineages.
- **CoMotifGraph+**: motifs and their reuse/transformation relations.
- **CoProjectionLineage+**: source -> render -> successor relationships.
- **CoVisualDissent+**: alternative visual explanations for the same source.
- **CoA11yTwin+**: text/keyboard/screen-reader equivalent.
- **CoRenderDiff+**: compares semantic and visual changes.
- **CoStyleGenome+**: reusable aesthetic traits without treating style as meaning.
- **CoDiagramTurtle+**: asks what a diagram hides, overstates, implies or excludes.
- **CoVisualCounterfactual+**: renders alternate interpretations explicitly.
- **CoReceiverRender+**: adapts projection to receiver while preserving source meaning.

1. bind exact source identity if available;
2. extract reusable motifs;
