## CoBloom Basin

A **CoBloom Basin** is a bounded candidate region where multiple related meanings/models can coexist long enough to be compared without premature collapse.

Each basin records:
- source set;
- primitives;
- relation types;
- observer assumptions;
- evidence class;
- translation losses;
- contradictions;
- null model;
- falsifiers;
- receiver/use case;
- cost / maintenance burden;
- wake / sleep rules;
- promotion / retirement criteria.

Basins may split, merge, overlap, or dissolve.

`BASIN_NE_CONSENSUS`

## Inversions / turtles / permutations

### Inversion
`INVERT` changes direction, premise, dependency or framing to expose hidden assumptions.

### Turtle
`TURTLE` recursively challenges the current candidate and the machinery that generated it.

### Permutation
`PERMUTE` reorders or remaps compatible components to search for materially distinct structures.

### Combination
`COMPOSE / HYBRIDIZE / SMOOSH` combine candidates while preserving lineage, contradiction and translation loss.

### Alternative generation
`ELSE / ORTHOGONAL / OBLIQUE / NULL` search outside binary oppositions.

None of these imply promotion.

`COMBINATORIAL_NOVELTY_NE_EPISTEMIC_GAIN`

## Selection / promotion

Candidate path:

`BLOOM -> CLUSTER -> DEDUPE -> QUALIFY -> COMPARE -> CHALLENGE -> TEST -> RECEIVE -> RETURN -> PROMOTE / PARK / SPLIT / RETIRE / RESEED`

Promotion requires:
- semantic distinctness;
- provenance;
- evidence appropriate to claim class;
- falsifier / counterexample path;
- receiver value;
- authority / privacy safety;
- manageable maintenance cost;
- no simpler existing family covering the same operation.

## G_d / angels / ET / ultimate-boundary lanes

These remain typed hypothesis / philosophical / mythic lanes unless independent evidence supports stronger claims.

Possible useful roles:
- generate questions;
- preserve alternative ontologies;
- compare theological / philosophical traditions;
- model attractors or ultimate-boundary concepts;
- explore meaning and value;
- generate counterfactuals;
- surface assumptions in naturalistic models.

They cannot:
- grant execution authority;
- override evidence;
- convert resonance into causation;
- turn symbolism into contact evidence;
- become true by repetition or prominence.
