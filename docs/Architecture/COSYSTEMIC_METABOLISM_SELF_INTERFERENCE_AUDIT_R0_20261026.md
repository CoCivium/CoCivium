## Short answer

Some prior CoCivium / CoAll work is likely under-maintained, some intentionally dormant, some stale, some duplicated, some blocked, some superseded, some orphaned, and some should be allowed to die. Do not collapse all of these into one fading state.

## Primary state classes

- ACTIVE_REGENERATIVE: receives current evidence, receiver use, return learning, maintenance, and successor pressure.
- DORMANT_WITH_WAKE: preserved cheaply until a meaningful trigger occurs.
- LATENT: potentially useful but not currently connected to a receiver, proof path, or active need.
- STRANDED: useful asset exists but cannot currently reach the need because of access, routing, authority, format, provider, or currentness constraints.
- STALE: claims or projections have aged beyond their supported currentness window.
- DUPLICATED: parallel sessions or artifacts repeat similar work without sufficient fan-in.
- SATURATED: additional effort yields diminishing return until a bottleneck elsewhere changes.
- BLOCKED: known dependency, authority, receiver, proof, or substrate gate prevents next effect.
- SUPERSEDED: a better current successor exists.
- RETIRED: intentional stop because continuing has negative expected value.
- ORPHANED: no active receiver, maintainer, wake rule, or currentness owner.
- SELF_INTERFERING: multiple valid efforts consume shared attention/resources or create contradictory projections faster than reconciliation can absorb them.

## Likely self-interference modes

1. Core-over-edge bias: internal architecture evolves faster than public/receiver projection.
2. Fan-out without fan-in: many sessions generate candidates but reconciliation capacity lags.
3. Vocabulary inflation: naming expands faster than tested operational distinctness.
4. Repeated rediscovery: prior recipes, failures, and proofs are not retrieved before new work begins.
5. Currentness starvation: useful objects persist without requalification and become ambiguous.
6. Receiver starvation: objects exist without a specific receiver/use-case path.
7. Maintenance debt: artifacts accumulate dependencies, stale links, outdated assumptions, and unclear successors.
8. Proof debt: claims outpace receipts and independent verification.
9. Attention capture by novelty: new branches crowd out finishing, retirement, and recovery work.
10. Synchronized failure: apparent resources share the same provider, account, machine, or semantic assumption.
11. Over-amplification of noise: repeated slogans, terms, or outputs increase activity but not useful signal.
12. Under-damping: weak negative feedback allows low-value branches to persist.
13. Over-damping: too-conservative gating suppresses safe reversible experimentation.
14. No reseed path: dormant assets cannot wake cheaply from compact durable state.
15. No return gain: edge feedback does not materially alter core selection.
16. No retirement metabolism: stale branches remain cognitively active after their value is gone.
