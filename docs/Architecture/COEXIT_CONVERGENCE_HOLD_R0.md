## Individual session retirement

A particular provider tab may still become close-safe for a bounded scope when all six conditions are proven:

1. unique scope state externalized;
2. elected durable destination proven;
3. exact receiver readproof proven;
4. reconstruction for scope proven;
5. unfinished effect obligations absent or transferred;
6. an alternative admissible execution route exists.

That does **not** make the account delete-safe.

Sources: https://help.openai.com/en/articles/8798634-managing-data-sharing-and-privacy-in-chatgpt-business and https://help.openai.com/en/articles/7260999-exporting-your-chatgpt-history-and-data

`PROVIDER_IS_HOME` -> reject. `LOCAL_MODEL_IS_NEW_SINGLE_HOME` -> also reject.

- **Non-model fallback:** essential identity, archival reading, WorkID queue, checkpoint/restore, deterministic search, rights/consent and basic CoBar UI must work without **any** paid or local inference service.
- **Optional hosted specialist:** bounded, licensed, authorized and budgeted provider adapters only when measured added value exceeds failure/cost/privacy risk. Account quotas are **admission inputs**, never an identity or custody root.

Avoid treating open weights, an API-compatible HTTP route or a passing unit test as real task capability.

An allowance report should record **source observer, UTC event time, plan/model/task class, exact provider response (sanitized), remaining/reset indication when available, alternate local capability, elapsed block, user lost minutes and successful substitute**.
