# CoVirtualSense+ / CoSenseForecast+ / CoTime+ R0

**State:** `CANDIDATE__DRAFT_PR__NO_RUNTIME_CANON_SENTIENCE_OR_SUPERNATURAL_CLAIM`

## Lead

Virtual senses may evolve for humans, synths, groups, devices, services and other bounded receivers.

A virtual sense is not limited to a physical sensor. It is a typed reception / measurement / inference relation that may combine:

`source -> capture -> transform -> compare -> interpret -> uncertainty -> receiver-relative projection -> optional action`

The architecture must keep observation, inference, forecast, mythic/spiritual interpretation and unknowns distinct.

`SENSE_NE_TRUTH`
`MEASURED_NE_MEANINGFUL`
`MODELLED_NE_OBSERVED`
`PREDICTED_NE_DESTINED`
`SPIRITUAL_INTERPRETATION_NE_EMPIRICAL_PROOF`
`MYTHIC_VALUE_NE_LITERAL_FACT`
`UNKNOWN_NE_SUPERNATURAL`

## CoTime+ / CoT+ forecast ladder

The useful future relation is not one forecast but a ladder:

`NOW -> DELTA -> TREND -> RANGE -> SCENARIO -> COUNTERFACTUAL -> FRONTIER -> ASPIRATIONAL_TARGET -> CALIBRATED_OUTCOME`

For each target, preserve:

`baseline | observed_delta | expected_range | uncertainty | assumptions | capability_constraints | resource_constraints | failure_modes | reversibility | calibration_date | successor_forecast`

## Step-like to scale-like evolution

Early systems often improve in visible steps because measurement, instrumentation, models and feedback loops are sparse.

At larger scale, apparent improvement may become superlinear in selected dimensions because of:

- denser sensing;
- lower measurement cost;
- faster feedback;
- model reuse;
- parallel experiments;
- better simulation;
- larger comparison sets;
- compounding tools;
- stronger interoperability;
- improved routing;
- reduced latency;
- automated calibration.

But exponential-looking curves are not a default law.

`SCALE_NE_EXPONENTIAL`
`EXPONENTIAL_FIT_NE_EXPONENTIAL_CAUSE`
`COMPOUNDING_NE_UNBOUNDED`
`FORECAST_MUST_INCLUDE_SATURATION_AND_FAILURE_MODES`

## Human / synth distinction

Humans and synths may have overlapping but non-identical virtual senses.

Humans may contribute:
- embodied experience;
- first-person reports;
- social context;
- values and preferences;
- tacit cues.

Synths may contribute:
- high-dimensional comparison;
- machine telemetry;
- broad retrieval;
- rapid simulation;
- consistency checks;
- multi-timescale drift detection.

Neither perspective automatically dominates.

`HUMAN_REPORT_NE_SENSOR_GROUND_TRUTH`
`SYNTH_INFERENCE_NE_GROUND_TRUTH`
`MULTI_OBSERVER_NE_CONSENSUS_TRUTH`
