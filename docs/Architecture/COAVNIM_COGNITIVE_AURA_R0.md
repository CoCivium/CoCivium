## CoHereNow

Existing CoAura semantics are already an unusually good fit:

> CoAura is the renderable, AI-first interface envelope through which a CoObject is exposed to minds and systems.

Therefore the "aura" around a human or synth living identity projection should not be a second unrelated aura system.

Candidate braid:

```text
CoID / synth identity / logical agent identity
    -> CoAvNim+ (living identity projection)
       -> CoHalo+ (small immediate context field)
       -> CoAura+ (renderable observer-relative envelope)
          -> CoOrb+ (expandable relation neighbourhood)
```

`CoBob+` MAY remain a playful/memeable/merchandising visual-style alias for a bobblehead-like CoAvNim projection, but SHOULD NOT replace the broader semantic term unless later reconciliation earns that change.

`COBOB_STYLE_NE_IDENTITY_ROOT`

## Cognitive projection layer

A CoAura MAY contain a **cognitive projection layer** for humans, synths, sessions, models, agents, virtual sessions or collectives.

It must distinguish what is actually available from what is merely inferred.

Candidate classes:

- `DECLARED_INTENT` — explicitly stated goal/purpose;
- `SURFACED_REASONING_SUMMARY` — user-visible explanation or reasoning summary;
- `HYPOTHESIS` — explicit candidate belief;
- `OPTION` — considered alternative;
- `UNCERTAINTY` — declared/modelled uncertainty;
- `QUESTION` — unresolved inquiry;
- `CHALLENGE` — adversarial/counter position;
- `PLAN_STATE` — explicit planned step;
- `TOOL_EVENT` — observed tool/action event;
- `WORK_LANE` — active logical work lane;
- `EVIDENCE_SIGNAL` — evidence received/changed;
- `CURRENTNESS_SIGNAL` — freshness/state relation;
- `MODEL_SUMMARY` — model-produced compact account of its work;
- `INFERRED_STATE` — observer inference, visibly qualified;
- `PREDICTED_NEXT` — forecast, not observation;
- `UNKNOWN` — deliberately unresolved.

## Critical reasoning/privacy rail

The cognitive aura is **not** a raw private chain-of-thought viewer.

It may render:

- explicit user-visible reasoning;
- summaries;
- decisions and decision-basis summaries;
- tool use;
- hypotheses;
- uncertainty;
- task/lane state;
- evidence/provenance;
- externally observable behavior;
- qualified inferences.

It SHOULD NOT claim access to hidden/private internal reasoning that is not actually surfaced by the participant/model/runtime.

`COGNITIVE_PROJECTION_NE_HIDDEN_CHAIN_OF_THOUGHT`  
`INFERRED_THOUGHT_NE_ACTUAL_INTERNAL_STATE`  
`SURFACED_SUMMARY_NE_COMPLETE_REASONING_TRACE`  
`OBSERVED_ACTION_NE_THOUGHT`

## CoNod relation

A CoNod-triggered CoWave can be visible through the CoAura.

Example:

```text
'
 -> CoNod R2
 -> massive logical fan-out
 -> orbiting / branching / wave-like cognitive-work projections
 -> active evidence/challenge signals
 -> deterministic fan-in
 -> contraction / settling / quiet
```

Thus one apostrophe can visibly "light up" a synth/collective CoAura without making the underlying hidden computation visible.

Possible visual grammar:

- orbiting dots = logical lanes;
- larger/brighter glyph only when semantically warranted, not "importance";
- converging arcs = fan-in;
- split arcs = live disagreement;
- vapor/trails = CoTime provenance;
- pulse = material changed state;
- fog = low observability;
- fronts = approaching relation collision;
- rhythm = CoSong temporal organization;
- weather = CoMeteo field condition.

Rails:

`VISUAL_INTENSITY_NE_IMPORTANCE`  
`ANIMATION_NE_SENTIENCE_PROOF`  
`AURA_ACTIVITY_NE_AUTHORITY`

## Human cognitive aura

Humans MAY opt into analogous projections, but the privacy bar should be higher.

Prefer:

- self-declared roles/goals;
- explicitly shared reflections;
- user-authored notes;
- consented behavioral summaries;
- public/professional relation fields.

Avoid silently inferring emotions, diagnoses, political views, intimate traits or private beliefs from ordinary behavior.

`HUMAN_AURA_REQUIRES_CONTEXTUAL_CONSENT`  
`INFERENCE_NE_SELF_DECLARATION`
