## Core resolution

A **CoQuant** is a scale-relative, self-describing relational object. It may be an atomic observation or the addressable root of a large composed graph. The word "largest" is meaningful **only within a declared scope/lens**. No implementation enumerates all possible relations or claims an absolute set of everything.

A minimal envelope carries: stable identity, representation/scale, typed references, content hash, source/provenance, observed/valid time, epistemic classification, scope/currentness, privacy, authority ceiling, reduction state, recovery prerequisites, receiver state, and next proof.

Reuse existing CoOrbEdgeDock, CoMap/CoOrb temporal, CoAllPulseField/CoTime and CoSubscriptionEcology source contracts. Do not create another universal database. Containment is bounded/acyclic in the R0H example; cyclic *semantic relations* may be expressed as explicit reference edges, not recursive in-memory containment.

## Once reduced, always reduced?

No. Reduction is a family of different transitions:

| Operation | Recovery |
|---|---|
| **CoFold+**: hide details behind an exact source reference | Exact CoUnfold+ if source bytes and identity still exist |
| **Lossless encode** | Exact decode only if bytes, algorithm and parameters remain available |
| **CoReFold+**: another projection or composition | Reversible as a view when its underlying graph is retained |
| **Lossy summary** | Not invertible from the summary alone; reread retained sources separately |
| **Checkpointed process** | Conditionally resumable only with valid state, dependencies, lease, environment and authority |
| **Deletion/expiry without recoverable source** | Must report unavailable or irrecoverable; hash is not a reconstruction mechanism |

CoFold and CoUnfold do not confer execution rights. Restore only the information actually supported by surviving exact sources. Privacy-sensitive intentional deletion must not be silently undone by cached or speculative reconstitution.

## Infinity is typed, not conflated

1. **Large finite:** cardinalities can be symbolic integers/ranges; representation is not materialization.
2. **Potentially unbounded:** a generator may produce further candidates across future **bounded** waves.
3. **Mathematical infinity:** quantified propositions and proofs remain symbolic research objects, not performed enumerations.
4. **Continuous/historical process:** finite-time observation windows, checkpoints and currentness cursors.
5. **Parallel/multiprocess work:** explicit worker caps, leases, idempotency, resource budgets, fault isolation, backpressure, stop/recovery rules and fairness among lanes.
6. **Speculative/mythic/spiritual/G_d interpretations:** candidate hypotheses, no empirical status without independent evidence.

A one-trillion logical descriptor ceiling need not launch any process or prove a trillion useful experiments. `LOGICAL_CAPACITY_NE_ACTIVE_WORKERS`.
