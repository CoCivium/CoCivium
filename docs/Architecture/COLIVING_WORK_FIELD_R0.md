## Lead

The weekly "top 100" is a projection, not the work substrate.

The substrate is a living relational field containing tasks, anti-tasks, proof deeds, dependencies, blockers, suppressors, triggers, timing windows, drift risk, dormant options, retired objects, non-material states, and virtual-session liveness.

TOP100_NE_WORK_SUBSTRATE

## Liveness joins the work field

Each work object can relate to a virtual-session state: RECOVERABLE, WAKEABLE, MATERIALIZED, BLOCKED, DORMANT, or RETIRED.

A work object can therefore remain live while its visible provider tab is gone. A reconstruction deed may outrank waking the old tab.

## Tray / CoBar / CoAlive projection

The tray icon and local CoBar are projections with their own currentness TTL. They are not the liveness root.

If a tray icon says DEAD but the virtual session is WAKEABLE and the tray projection is stale, the UI should show both facts: projection stale, session wakeable.

If a fresh icon says LIVE but the durable virtual-session truth is BLOCKED, the session remains blocked.
