- physical / nonphysical;
- material / nonmaterial;
- space / non-space;
- object / relation;
- presence / absence;
- core / edge;
- stable / unstable;
- local / nonlocal;
- known / unknown;
- causal / acausal;
- observer / observed

are typed candidates, projections, or hypotheses rather than compulsory universal primitives.

`OPPOSITE_OF_LEGACY_NE_FREE_OF_LEGACY`

- default UI conventions;
- incumbent provider APIs;
- familiar organization charts;
- centralized identity;
- one-score optimization;
- newest-wins versioning;
- hidden dependency;
- convenience-driven lock-in;
- jargon becoming doctrine;
- automation copying inherited assumptions.

Countermeasures:
- explicit alternative-generation step;
- mandatory null / inverse / else lens for high-impact design;
- periodic dependency and capture audit;
- multiple substrate implementations;
- edge-origin challenge path;

- historical lineage and anti-meaning registry;
- cultural rituals that reward challenge, not loyalty to terminology.
