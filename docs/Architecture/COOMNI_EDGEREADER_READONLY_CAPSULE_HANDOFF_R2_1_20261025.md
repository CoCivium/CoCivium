## Receiver acceptance gate

1. Independently obtain exact archive bytes from a trusted, authorized carrier.
2. Verify archive SHA-256 against an out-of-band trusted value. Reject any changed member, conflicting source index, private source disclosure, or implicit role/authority elevation.
3. Reconstruct one selected finite context packet and preserve contradictory/counterexample evidence and edition pins.
4. Produce **receiver-origin readproof**: actual obtained hash, observed destination, method, reader perspective, accepted/rejected scope, errors and receiver disposition. A sender test never signs for a receiver.
5. Separately qualify rights, accessibility, privacy, usefulness and currentness before an editor publishes or distributes.
6. Require new scoped permission before posting, emailing, installing, paying, changing account state, enrolling subscribers or invoking external tools.
