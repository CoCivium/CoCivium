# CoMindSeed / CoBind+ | Golden Braid and CoTheoryAll relational routing R0

## One decision

Bind at the **nearest qualified, stable source/evidence/authority boundary** appropriate to a receiver and use. Rebind only with a material new source, permission, context, falsifier or validity change. Never rebind a frozen historical witness merely to make today's narrative tidier.

This proposal adds a **read-only routing candidate** to the existing Golden Braid and CoTheoryAll rather than another global control plane. The precise machine companion is [the CoMindSeed routing manifest](../../ai/research/comindseed-cobind-golden-braid-cotheoryall-r0-20261110.json).

## Decision procedure

1. **Recover** prior WorkID, original source bytes or exact source pointer, source time and negative/unknown coverage; privacy/consent first.
2. **Type** relationship as observation, hypothesis, symbolic interpretation, prediction, counterfactual or unknown. A physical claim needs a discriminating experiment; a philosophical interpretation does not become physical evidence by gaining a name.
3. **Screen hard gates**: scope, confidentiality, issuer, exact identity, clock consistency, authority and receiver. If a gate fails, HOLD; a high numerical score may not bypass it.
4. **Compare candidate homes** by provenance, semantic fit, time integrity, recoverability, receiver usefulness, risk and costs. The router uses a deliberately bounded reproducible heuristic, not an omniscient optimum.
5. **Preserve alternatives** and losing paths. Inverse search permits discovery but cannot assert reciprocal causality or permission.
6. **Challenge** with different observer/boundary partitions, null/else/orthogonal models, ordinary explanations, and predeclared failure cases. Independent sources matter more than independent-sounding model agreement.
7. **Propose** a new relation in a separate change set. Only an authorized, collision-checked merger may change selected state; receiver readproof is an independent gate. Stable CoMVP heads remain intact.

## Across all time directions

- **Retro:** explore ancestor links, unknown predecessors and past warnings; any new interpretation is an annotation now, never retroactive mutation of then.
- **Now:** bind the last qualified head and its observed receiver state, with separate event_at, observed_at, recorded_at, qualified_at, landed_at and receiver_read_at when supported.
- **Future:** issue a frozen prediction or imagined branch today; later compare outcomes and mark HIT/PARTIAL/MISS/UNRESOLVED without rewriting the forecast.
- **Inverse:** reverse search direction and vary perspective, boundary or causal model. Do not imply physical influence backward through time.
- **Cross-scale:** work object -> prodlet -> session -> device -> team -> federation; recheck permission and evidence at every scale transition.
- **Unobserved:** keep intentional silence, incomplete scans, private data, contradictions and unresolved status visible to authorized receivers without manufacturing public counts.

## CoMindSeed candidate hypothesis ecology

**H0 observational-equivalence:** indistinguishable observations cannot distinguish two descriptions under stated controls. Find a new permitted observable or delimit the equivalence.

**H1 boundary and quantum:** compare a conventional quantum model to a specified rival substrate/projection model under interference and Bell-type correlations. Bounded discreteness alone is insufficient.

**H2 functional observer:** distinguish boundaries, feedback, integrated processing, retained information, self-modeling, reports and task performance. Perturb mechanisms and measure change.

**H3 phenomenal uncertainty:** no source-only routing program can infer subjective experience. Competing theories, biological data, behavioral studies and ethical uncertainty must remain separately typed.

**H4 All/Nothing/G_d:** philosophical and symbolic interpretations may inspire candidate questions; they do not establish external divine agency or physical causality.

## Bounded executable proof

Run with trusted Python 3 source in a reviewed checkout:

    python3 -m unittest discover -s tests -p "test_cobind_candidate_router_r0.py" -v

The standard-library [router](../../scripts/CoBindCandidateRouterR0.py) accepts JSON with claim and anchors, rejects unsupported bindings, ranks only eligible candidates, and returns CANDIDATE_BIND_NOT_EXECUTED. No network, model call, file modification, action execution, real permission grant, synthetic consciousness score, automatic session synchronization or broad front scan is performed.

Synthetic tests cover unsourced observations, immutable event dates, private data, wrong work identities, forecast issued_at, counterfactuals, inverse-only lookup, unsupported physics/sentience promotion, metric bounds and candidate ranking. A passing test establishes **source-only logic**, not that the heuristic is globally optimal or that a user has benefited.

## CoLockStep / CoMVP gate

No production replacement here. Keep existing selected Golden Braid, CoTheoryAll, CoTime and rickBar heads unchanged. The first receiver-grade test should have a consenting independent receiver:

- recover one exact existing source from its WorkID;
- inspect retrospective, current, inverse and possible-future bindings without false merges;
- compare at least one null alternative and one sourced counterexample;
- give a source digest, understood meaning, selected next action, and distinct receiver readproof;
- repeat after interruption and demonstrate clean rollback.

Do not call the existing branch/source candidate C3 until real receiver use is demonstrated.
