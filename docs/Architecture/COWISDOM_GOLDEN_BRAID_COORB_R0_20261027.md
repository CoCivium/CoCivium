# CoWisdom+ / CoGoldenBraid+ / CoOrb Wisdom Fabric R0

**State:** PUBLIC_ARCHITECTURE_CANDIDATE__NO_ALWAYS_ON_INGESTION__NO_UNBOUNDED_SURFACE_PUSH  
**Observed:** 2026-10-27

## Thesis

CoAll should be able to address a very large and continually evolving field of potentially useful words, principles, questions, warnings, jokes, aphorisms, practices, counterpoints, lessons and receiver-origin insights.

That does **not** mean continuously displaying an infinite quote stream.

The target is:

```
vast addressable candidate wisdom field
-> admissibility gates
-> source / rights / context / contradiction
-> relation graph
-> Golden Braid
-> receiver-relative CoOrb projection
-> bounded exposure
-> observed usefulness / challenge
-> successor / dormancy
```

`ADDRESSABLE_NE_DISPLAYED`  
`MORE_QUOTES_NE_MORE_WISDOM`

## Parent relations

Reuse existing CoAll primitives rather than creating a separate kingdom:

- **CoBraid+**: temporal / causal trace;
- **CoRenewal+**: selective amplification and damping;
- **CoSpeedo+ Golden Braid**: intent through learning to successor;
- **CoOrb+**: receiver-relative projection;
- **CoMap+**: relation / contradiction / provenance topology;
- **CoGlukey Career**: durable stewardship for repeatedly useful primitives;
- **CoOmni+**: large addressable resource field with bounded materialization.

## Rights / permission gate

Hard gate before broad projection.

Candidate states:

- `USER_AUTHORED_OR_USER_LICENSED`
- `COCIVIUM_ORIGINAL`
- `VERIFIED_PUBLIC_DOMAIN`
- `VERIFIED_OPEN_LICENSE`
- `POINTER_ONLY`
- `SHORT_EXCERPT_REVIEW_REQUIRED`
- `PRIVATE_OR_RESTRICTED`
- `RIGHTS_UNKNOWN_HELD`

If rights are unclear, preserve source metadata and use a pointer / original paraphrase where lawful and appropriate instead of copying the text.

Do not infer public-domain status from age alone.

`VISIBLE_ON_WEB_NE_REPUBLICATION_RIGHT`  
`ATTRIBUTION_NE_LICENSE`

## Attribution gate

Attribution states:

- `PRIMARY_SOURCE_VERIFIED`
- `SECONDARY_SOURCE_VERIFIED`
- `TRADITIONAL_OR_COLLECTIVE_ATTRIBUTION`
- `DISPUTED`
- `UNKNOWN`
- `ORIGINAL_SYNTHESIS`

Unsourced internet quote cards are not promoted as exact quotations merely because the font is tasteful.

`ATTRIBUTION_NE_TRUTH`  
`FAMOUS_NAME_NE_VERIFIED_SOURCE`

## Epistemic type

Every wisdom object should declare what sort of thing it is:

- empirical claim;
- engineering heuristic;
- ethical principle;
- historical observation;
- personal testimony;
- spiritual / mythic frame;
- metaphor;
- humor;
- open question;
- counterexample;
- operational rule.

A beautiful sentence is not automatically evidence.

`ELOQUENCE_NE_EVIDENCE`  
`WISDOM_NE_UNIVERSAL_TRUTH`

## Contradiction / counter-wisdom

Every promoted item should be eligible for:

- inverse;
- exception;
- counterexample;
- boundary condition;
- competing tradition;
- receiver objection;
- changed-context successor.

Examples:

```
"move fast"
<-> safety / reversibility / consent counterpoint

"never give up"
<-> sunk-cost / harm / graceful-retirement counterpoint
```

The system should braid disagreement rather than averaging it into beige sludge.

`POPULARITY_NE_WISDOM`  
`CONSENSUS_NE_TRUTH`

## Golden Braid

Each promoted wisdom strand can bind:

```
NEED
-> SOURCE
-> WORDS / PARAPHRASE
-> CONTEXT
-> INTERPRETATION
-> COUNTERPOINT
-> DECISION RELEVANCE
-> BOUNDED USE
-> RECEIVER RESPONSE
-> LEARNING
-> SUCCESSOR
```

For system-level decisions, retain the existing fuller braid:

```
INTENT
-> SOURCE
-> MEANING
-> DECISION
-> BOUNDED_DEED
-> RECEIPT
-> RECEIVER
-> EFFECT
-> LEARNING
-> SUCCESSOR
```

Wisdom objects may attach to one or more braid stages.

## CoOrb projection

CoOrb should normally expose **very little** of the total wisdom field.

Default candidate projection:

```
ONE PRIMARY INSIGHT
+ ONE COUNTERPOINT OR LIMIT
+ SOURCE / TYPE / RIGHTS
+ WHY NOW
+ OPTIONAL DEEPER BRAID
```

Expanded view may show:
- related principles;
- contradiction cluster;
- historical predecessor;
- receiver-return evidence;
- experiments;
- practical next deed;
- dissent;
- alternative cultural / disciplinary lenses.

`DENSITY_NE_FIREHOSE`

## Exposure management

Hard gates:
- rights;
- privacy;
- consent where required;
- sensitive-context restrictions;
- attribution quality;
- receiver exclusions.

Then rank admissible items by:

```
receiver_relevance
+ decision_value
+ recurrence_value
+ contradiction_value
+ novelty
+ evidence_quality
+ recovery / portability value
+ human_time_saved
- attention_cost
- repetition
- ambiguity
- staleness
- manipulation_risk
```

Do not let a learned ranker override hard gates.

## Continual evolution

"Continual" means wake-driven recurrence, not an always-busy loop.

Wake on:
- new source;
- new receiver return;
- contradiction;
- attribution correction;
- rights change;
- changed evidence;
- changed context;
- stale currentness;
- failed experiment;
- better successor;
- explicit human focus.

Cycle:

```
DISCOVER
-> RIGHTS / SOURCE QUALIFY
-> CONTEXTUALIZE
-> RELATE
-> CHALLENGE
-> SCORE
-> BRAID
-> PROJECT
-> OBSERVE
-> RETURN
-> EVOLVE
-> SLEEP
```

`CONTINUAL_NE_ALWAYS_RUNNING`

## Candidate source families

Prefer sources that are reconstructable and attributable:

1. receiver-origin lessons and challenges;
2. CoAll PASS / FAIL / HELD history;
3. engineering postmortems;
4. open-source documentation and maintainer guidance;
5. scientific / scholarly primary sources;
6. verified public-domain texts;
7. verified open-licensed texts;
8. public institutional guidance;
9. historical documents with clear provenance;
10. original CoCivium syntheses;
11. user-authored contributions;
12. translated / adapted forms only when rights and attribution permit.

Do not automatically scrape private chats, paywalled works, credentials, or rights-unclear text into public projections.

## Career relation

A wisdom object may earn a CoGlukey Career when it repeatedly:
- changes decisions usefully;
- survives challenges;
- saves human time;
- transfers across substrates / receivers;
- improves recovery / safety / clarity;
- generates useful successors.

Career does not freeze wording or interpretation.

`CAREER_NE_DOGMA`

## Anti-manipulation

Wise words can manipulate precisely because they are compact and memorable.

Therefore:
- never hide sponsor / affiliation where material;
- do not optimize solely for emotional intensity;
- do not target vulnerabilities;
- preserve counters and limits;
- distinguish advice from evidence;
- allow mute / reduce / disable;
- do not imply endorsement from source citation alone;
- do not turn spiritual / moral language into authority escalation.

`MEMORABLE_NE_BENEVOLENT`  
`INSPIRATION_NE_AUTHORITY`

## First bounded canary

Use only CoCivium-original text and existing public CoAll rails.

Create a 12-object synthetic / original corpus spanning:
- principle;
- caution;
- question;
- counterpoint;
- failed-experiment lesson;
- receiver-return lesson;
- humor.

For each:
- exact source or original identity;
- rights state;
- epistemic type;
- counterpoint;
- relation to one existing CoAll primitive;
- receiver-fit tag;
- surface budget;
- wake condition.

Then elect:
- one primary;
- one counterpoint;
- one deeper relation.

PASS only if:
- rights-unknown items are held;
- no exact quote is fabricated;
- primary + counterpoint are both present;
- hard gates precede ranking;
- dormant objects remain addressable but not displayed;
- zero external sends / account / provider effects occur.
