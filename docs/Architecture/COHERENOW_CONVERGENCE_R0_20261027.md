# CoHereNow+ Convergence Projection R0

**State:** BOUNDED_SYNTHETIC_CONVERGENCE_CANARY__NO_SESSION_MUTATION__NOT_RUNTIME  
**Observed:** 2026-10-27

## Why this exists

A large desktop can show several useful sessions that independently converge on the same operating grammar while still forcing the human to reconcile them visually.

The desired UX is not to delete or flatten those sessions. It is to project one compact shared frontier while preserving every source as drill-down evidence.

```
many session surfaces
-> source-bind
-> compatibility gate
-> relation/action overlap
-> disagreements preserved
-> one CoHereNow front
-> one bounded next action
```

`CONVERGENCE_NE_MERGE_OF_TRUTH`  
`SHARED_FRONT_NE_SOURCE_DELETION`

## Source evidence boundary

The motivating observation was a user-supplied X2 screenshot showing several simultaneously visible work surfaces with overlapping themes.

The screenshot itself is not committed here and is not treated as machine-read runtime evidence.

The executable canary uses synthetic public-safe front descriptors only.

`SCREENSHOT_NE_MACHINE_STATE`

## Compatibility gate

Fronts may converge only when all of these agree:

- shared goal identity;
- confidentiality class;
- authority ceiling;
- no destructive collision;
- sufficient overlap in declared action operators.

Similarity of wording alone is insufficient.

`SIMILAR_LANGUAGE_NE_SAME_WORK`

## Action grammar

The synthetic fixture uses a shared operating grammar:

```
DISCOVER
-> PRESERVE_LINEAGE
-> RECONCILE_RELATIONS
-> EXPOSE_GAPS
-> RUN_BOUNDED_EXPERIMENT
-> VERIFY_RECEIPT
-> PRESERVE_AND_RECOMBINE
```

Each source may retain its own specialty, evidence and unresolved questions.

## CoHereNow projection

The compact projection should expose:

- one shared goal;
- source-front count;
- shared invariants;
- preserved divergences;
- current bounded state;
- one elected next safe action;
- evidence pointers;
- uncertainty;
- source drill-down.

It should not expose every provider/session detail unless needed.

`USER_VISIBLE_COMPRESSION_NE_BACKEND_COLLAPSE`

## Convergence does not destroy plurality

The projection may collapse navigation burden without collapsing epistemic diversity.

Examples of preserved divergence:

- UX projection vs coordination proof;
- local runtime vs public source;
- synthetic proof vs independent receiver evidence;
- observed vs predicted;
- current vs stale.

`FRONTIER_COMPACTION_NE_LOSSLESS_TOTALITY`

## Session relation

Three visible session panes may yield one shared user-visible front.

That does not mean the sessions are identical, merged, closed or canonically superseded.

`SESSION_COUNT_NE_FRONT_COUNT`

## First bounded canary

The fixture contains three synthetic fronts with:

- one shared goal;
- compatible PUBLIC confidentiality;
- identical low authority ceiling;
- six shared action operators;
- distinct specialty fields;
- distinct source references;
- one common reversible next action.

PASS requires:

1. one convergence group;
2. all three source lineages retained;
3. shared action operators computed by intersection;
4. specialty divergences preserved;
5. one common next action elected;
6. zero external effects;
7. no source marked deleted, merged-away or superseded.
