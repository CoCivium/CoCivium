## Why Q40 now

This is not a philosophical preference for local computing.

It is a dependency-reduction proof.

The larger CoAll direction is already moving away from:

- manual ChatGPT tab survival;
- provider-hosted recurring work;
- one-provider memory/control assumptions;
- user-as-transport continuity.

Q40 asks whether one **real recurring advisory deed** can move onto a proven local/open worker while retaining:

- exact input identity;
- exact output contract;
- authority ceiling;
- quality comparison;
- currentness;
- receipt;
- fallback/recovery path.

If yes, that removes one recurring provider dependency.

If no, the exact blocker becomes evidence rather than another slogan about open source.
