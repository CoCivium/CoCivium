## Prime concern

CoAll must not infer exponential progress from a growing count of artifacts, terms, commits, agents, tasks, or candidate relations.

`MORE_ARTIFACTS_NE_EXPONENTIAL_USEFULNESS`

## Exponential proof gate

A claim of exponential or superlinear improvement requires a comparable time series over at least several windows with:
- stable metric definition;
- stable unit of work;
- baseline;
- uncertainty / missing-data handling;
- independent or reproducible measurement;
- explicit confounders;
- receiver-side usefulness where relevant;
- cost / energy / human-time normalization.

Candidate measured families:
- closure yield per hour;
- verified useful effects per human relay;
- receiver comprehension per artifact;
- independent recovery rate;
- currentness latency;
- mean time from source delta to public-safe successor;
- task success per unit compute / money / attention;
- percentage of work surviving restart / absence;
- percentage of recurring work internalized;
- percentage of material deltas generated without Rick;
- edge-origin return incorporated into core;
- recovery domains independently replayable.

## Turtle / recursive acceleration

CoTurtle∞+ should not mean recursion depth or repeated self-reference.

Measure:
`TURTLE_GAIN = improvement_in_next_cycle_capability / cost_of_current_cycle`

Potential compounding exists only if useful next-cycle capability repeatedly improves faster than the cost and debt it creates.

`RECURSION_NE_COMPOUNDING`
`SELF_REFERENCE_NE_ACCELERATION`

## Atomic debt versus closure

Track:
`CoAtomicDebt = useful work stranded as isolated concepts/scripts/tests/files/handoffs`

`CoClosureYield = work reaching a real receiver, surviving recovery, and producing a verified useful result`

Primary pressure:
`CLOSURE_YIELD_GROWTH > ATOMIC_DEBT_GROWTH`

## Recurrence internalization

Every recurring task should be classified:
1. INTERNAL_PRODUCTIZED;
2. EXTERNAL_BUT_JUSTIFIED;
3. TEMPORARY_BRIDGE;
4. HUMAN_GATED;
5. REDUNDANT;
6. STALE;
7. RETIRE.

For each recurrence record:
- trigger;
- owner;
- substrate;
- dependency;
- authority;
- cost;
- failure mode;
- wake condition;
- output / receipt;
- receiver;
- successor internal capability;
- retirement criterion.

`RECURRING_TASK_NE_PRODUCTIZED_CAPABILITY`

## Internalization ratio

`INTERNALIZATION_RATIO = productized_recurring_capabilities / all_material_recurring_needs`

Also track:
`EXTERNAL_DEPENDENCY_COUNT`
`SINGLE_PROVIDER_RECURRENCE_COUNT`
`HUMAN_RELAY_RECURRENCE_COUNT`
`NO_RECEIVER_RECURRENCE_COUNT`

Target direction:
- internalization ratio up;
- unjustified external dependency down;
- human relay down;
- stale recurrence down;
- verified receiver effect up.

## X2 exemplar

X2 should be treated as a proof surface, not a ceremonial flagship.

Minimum exemplar criteria:
- observer reachable or independently recoverable;
- CoBar/CoOrb currentness truthful;
- restart recovery proven;
- bounded local task can execute without Rick relay;
- source-to-receipt path preserved;
- stale state visibly marked;
- no fake-green health;
- local and remote observer disagreement exposed;
- one unfamiliar user can complete a useful task.

`X2_EXEMPLAR_NE_X2_SPECIAL_CASE`

- rising atomic debt;
