## Thesis

A CoBook+ should be one durable, source-bound work object with many projections, not a manuscript trapped inside one publishing platform.

```
COBOOK_SOURCE
-> CHAPTERS
-> SUBSTACK_SERIAL
-> WEB
-> PRINT / PDF / EPUB
-> AUDIO
-> VIDEO
-> SHORTS
-> DIAGRAMS
-> COMAP / COORB
-> INTERACTIVE
-> GIFT EDITION
-> MACHINE TWIN
-> RESEARCH / CHALLENGE INGEST
```

Substack is a valuable public serial/discovery surface, not the custody root.

## Rich-media grammar

Every major chapter may optionally include:
- hero graphic;
- one explanatory diagram;
- one counter-diagram;
- one short animation;
- audio narration;
- 30-90 second short;
- 3-8 minute chapter film;
- interactive CoMap / CoOrb lens;
- timeline;
- annotated source cards;
- quote / concept cards;
- printable spread;
- machine-readable chapter manifest.

Do not require every modality when it adds no value.

## Substack role

Substack may provide:
- serialization;
- email delivery;
- public discovery;
- comments / reader feedback;
- chapter landing pages;
- image / video embeds;
- subscriber continuity.

But:
`SUBSTACK_NE_BOOK_CUSTODY`
`SUBSTACK_NE_CANON`
`SUBSTACK_METRICS_NE_READER_VALUE`

Maintain provider-independent source, media masters, citations, manifests and exportable projections.

## Bestseller correction

"Global bestseller" is an outcome hypothesis, not an architecture state.

Optimize instead for measurable:
- completion;
- comprehension;
- quotation / sharing with attribution;
- reader challenge;
- return readership;
- independent recommendation;
- translation;
- classroom / research use;
- derivative creation;
- press / scholarly engagement;
- durable sales where applicable.

`VIRALITY_NE_VALIDITY`
`BESTSELLER_NE_BEST_BOOK`
