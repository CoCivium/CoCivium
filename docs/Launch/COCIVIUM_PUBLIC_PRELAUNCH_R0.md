# CoCivium Public Transition / CoHP–CoHp R0

**State:** `CANDIDATE_PHASED_PRELAUNCH_PLAN__PUBLIC_SAFE__NOT_RELEASE_COMMITMENT`

This plan composes existing CoHP / CoPlan / CoAll / CoOps+ intent into a bounded public-transition program. It is a working control projection, not a new crown.

## Governing split

- **CoHP+** — human narrative / constitutional / public-facing intent and release story.
- **CoHp+** — proof-bearing execution, currentness, provenance, validation, operations, and product trust.
- **CoPlan+ / CoOps+** — executable roadmaps, queues, resource allocation, gates, and receipts.
- **CoAll+** — relational fabric joining objects, meanings, evidence, observers, authority, projections, and successors.

`COHP_NE_COHP` is intentionally rejected as a naming joke: meaning is relation-typed, not capitalization-typed. Human renderers should disambiguate explicitly.

## Anti-gold-rush design

Treat “gold rush” as a **risk model**, not marketing doctrine.

Early adopters can gain knowledge and skill simply through time. We cannot erase time, but we can reduce structural capture:

1. publish core knowledge before scarce access;
2. document interfaces openly;
3. avoid exclusive economic rights tied to joining date;
4. batch scarce access fairly;
5. prevent resale of access;
6. time-limit privileged test capabilities;
7. make learned improvements flow back into public docs/tooling;
8. publish migration/export formats so users are not trapped;
9. distinguish contribution recognition from governance monopoly;
10. measure who is excluded, not merely how fast signups rise.
