## CoHereNow

CoCivium intends to become an accessible, creative **commons**: people and AI systems should be able to discover, question, learn from, reuse, improve and build upon rights-cleared material. The [human-first GitHub profile](../../README.md) has been simplified while the former long-form public README remains recoverable in [its exact historical archive](../Archive/README_PUBLIC_PROFILE_BEFORE_HUMAN_FIRST_20261111.md).

**Freedom, not chaos:** “Free for all” means broad voluntary access, participation, forking, attribution where required and meaningful exit. It does not waive the privacy, safety, copyright or consent rights of third parties. “CoOwm+” names a shared-stewardship research direction, **not** an enacted legal status or proof that copyright holders have surrendered ownership.

**All interested authorized sessions, contributors, local workers and external assistants:** Review and challenge this direction *when encountered through a relevant, permitted currentness path*. Propose one bounded improvement with a primary source, contradiction/falsifier and rights scope. No reader is auto-subscribed, instructed to bypass access controls or granted authority to publish. Generic delegation is **not** a privacy waiver, rights transfer or all-session acknowledgment.

## The elected release path

`IDENTIFY -> CUSTODY_READPROOF -> RIGHTS/PRIVACY/SECURITY REVIEW -> PUBLIC-SAFE DERIVATIVE -> HUMAN + MACHINE PRESENTATION -> PUBLICATION_RECEIPT -> INDEPENDENT_READBACK -> CORRECTIONS / SUCCESSORS`

| Surface | Role | Limits |
| --- | --- | --- |
| **CoStead / independent encrypted private custody** | Preserve exact originals, hashes, version lineage, rollback, provenance, protected private material and independently tested restore paths | Seeing a share through X2 is **not** independent NAS receiver pickup, and a backup is not a proven restore |
| **CoGateway** | Classification and rights-aware transformation: sensitive data isolation, redaction, provenance and public-safe projection | Gateway presence is **not** verified processing or safe release approval |
| **Public GitHub / static sites / playable experiences** | Source, responsive human front door, accessible games, videos and stories, actual public demos, machine-readable index and correction path | Discoverability is **not** endorsement, verified uptake, runtime or search ranking |
| **CoCommons federation** | Independent mirrors, upstream source IDs, public corrections, independent reproducibility, voluntary community forks and participation | Federated copies are **not** automatically identical, authoritative or permanently available |
| **Substack, media and other editorial channels** | Selected rights-cleared essays, illustration, audiovisual context and links to exact sources | Secondary editorial destinations are not the sole archive; no auto-posting |

Do not bulk import private repositories into public code, public AI chats, public ciphertext stores or an unaudited indexing pipeline. Preserve exact private Git history in private custody; **never assume the current working tree is the full disclosure history**. Prefer public-safe summaries/derived content rather than unrestricted raw private history. Preserve rollback and rights provenance; do not delete private originals merely because a public projection exists.

## License and contributor treatment

Current [CoCivium code license](../../LICENSE) is **GPLv3**. Its copyleft permissions and obligations remain in effect; this advisory **does not relicense it**. Free access does not erase copyright, contributor rights, trademarks or third-party license conditions.

For *new and rights-cleared* non-code art, essays, learning material, datasets and assets, evaluate the fit of **CC BY 4.0**, **CC BY-SA 4.0**, **CC0** or another suitable instrument, in that order of domain and rights needs, not as a blanket conversion. Software normally uses an OSI-approved software license, not a CC license. CC0 dedication is a consequential rightsholder decision, not something the existence of a repository authorizes. A release card must identify the actual license and source-level exceptions, not promise that “everything” has one license.

**No exclusive crown** is a governance and portability goal. Actual anti-capture requires independently preservable copies, right-to-fork, contributor credit, transparent decisions, accessible formats, open interoperability and clear stewardship authority. A manifesto alone does not undo existing legal ownership.

Pre-release notices should be concise, truthful and **per experience**, progressively retired only after verified product-readiness gates; long-term open research need not pretend every prototype is a production service. [Existing free-publication commons policy](../Architecture/COFREE_EVOLVING_PUBLICATION_COMMONS_R0_20261026.md) and [publication lifecycle](../Architecture/COPUBLICATION_METABOLISM_R0_20261025.md) remain primary prior art.
