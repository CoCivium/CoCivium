## Purpose

Provide a playful public symbolic language for CoCivium / CoEvoAll+ that can carry difficult ideas without converting metaphor into evidence.

## Candidate family

### Headless Magic Dragon+
Represents scale, infrastructure, open/local intelligence, disruption, and world-upgrade energy.

Candidate public line:

> HEADLESS MAGIC DRAGON FROM BEYOND THE FRONTIER UPGRADES WORLDS

### BeaxaKitten+
Represents care, repair, relational nuance, small interventions, and the recovery of missed relations.

Candidate public lines:

> BEAXAKITTEN TO THE RESCUE: FIXING THE RELS THE DRAGON MISSED

> WORLD MOSTLY UPGRADED. 7 UNRESOLVED RELS DETECTED. DEPLOYING KITTEN.

### CoTurtles+
Represents persistence, branching, spawned projects, slow continuity, and descendants that may become independent work.

### CoClouds / CoLoud+
Represents ambiguity, ideas, hypotheses, metaphors, questions, and relational play.

## Relations

```text
DRAGON -> SCALE / INFRASTRUCTURE / DISRUPTION
KITTEN -> CARE / REPAIR / RELATIONAL_NUANCE
TURTLE -> CONTINUITY / BRANCHING / PERSISTENCE
CLOUD -> POSSIBILITY / AMBIGUITY / HYPOTHESIS
```

These relations are suggestive, not exclusive.

## Public use

Mascots may appear in:
- CoAcademy teaching;
- CoLoud / CoCivGame play;
- public explainers and memes;
- onboarding;
- challenge panels;
- recovery and debugging stories;
- speculative CoMythOps projections.

They should not imply that a named AI, nation, model family, synthetic being, or human has authority merely because a mascot represents it.

## Next proof

Test whether newcomers can correctly infer the intended difference between Dragon, Kitten, Turtle, and Cloud without being taught the CoTerms first.

Success is comprehension and recall, not merely amusement.
