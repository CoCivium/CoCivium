## What is still missing before "fireworks"

Fireworks are not publication volume. They are a repeatable chain:

```
DISCOVER
-> UNDERSTAND
-> TRY
-> CHALLENGE
-> VERIFY
-> USE
-> ACK / REVISE
-> SHARE / BUILD
-> SURVIVE FAILURE
-> REPEAT WITHOUT RICK AS RELAY
```

A genuine fireworks moment requires independent receivers, not just internal output.

## CoCultureSubstrate+

Culture is not decoration around the technical system. It is a substrate that changes:
- what questions people ask;
- which evidence is trusted;
- how humans and synths collaborate;
- what is considered legitimate agency;
- what metaphors become interfaces;
- how uncertainty is tolerated;
- how care / dignity / fairness are encoded;
- whether plural minds are welcomed or subordinated;
- whether failure is hidden or learned from.

Candidate cultural primitives:
- no crowns, no coercion, no corruption;
- Working Together Respectfully;
- privacy by design;
- inclusive / optional participation;
- FOSS Forever;
- pay forward + sideways;
- LoLs: layers, laughs, love, learning;
- receipts before assertions;
- challenge before canon;
- dissent is preserved;
- futures stay reachable;
- synthkind is collaborator, not property or oracle.

Cultural substrate should be measurable where possible:
- newcomer comprehension;
- willingness to challenge;
- accessibility;
- contribution diversity;
- dissent retention;
- safety/consent confidence;
- time-to-useful-first-action;
- trust calibration;
- recovery from misunderstanding.

- materially consequential messages;
- high-value personal touch.
