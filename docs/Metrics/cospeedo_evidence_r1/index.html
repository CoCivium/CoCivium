Why not fit an exponential now?

For a positive, stable benefit series, a descriptive log rate could use r = (ln(V_end) - ln(V_start)) / Δt, with a doubling time only if r > 0. But the result is meaningless without comparable definitions, receiver-origin effects, measured costs, uncertainty and alternative trend checks. Artifact counts and isolated test PASS records do not qualify.
