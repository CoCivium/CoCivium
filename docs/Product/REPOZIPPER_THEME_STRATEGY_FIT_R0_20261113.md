**As of:** 2026-11-13  
**State:** PUBLIC-SAFE REVIEW CANDIDATE, NOT DEPLOYED UX, PUBLIC RELEASE, LIVE ACCOUNT BACKUP, SECURITY CERTIFICATION, OR CANON.

## Decision

**One portable, user-owned core; multiple opt-in theme projections.** The eight themes in [machine-readable theme profiles](../../ai/product/repozipper-ai-history-theme-projections-r0.json) are **views**, not new independent account systems, backup engines, brands with distinct authority, or separate data stores. Their allowed work now is limited to the source-tested offline ZIP `inspect` or supported-format `census` operations. Each profile identifies a *future locked capability* plainly. Do not market that capability as available.

The default first task is **inspect a user-selected ZIP privately**. No account, network connection, cloud upload, provider login, plugin installation, scheduled monitor, new model, repository, or public publishing is required.

## Core UX and custody invariants

- **Default local working path:** `Downloads/CoTemp`, user-configurable, only temporary staging. Downloads can be cleaned automatically or included in cloud sync; neither is assumed durable or private on all devices. Do not copy a private export there unexpectedly or overwrite prior work.
- **Guardian backup gate:** keep original bytes unchanged; verify exact hash, intended retention and user rights; qualify a second independent destination, encrypted custody and cold restore before displaying a “Protected” badge. Without that proof show “Local copy only, backup unverified.”
- **Theme switch:** presentation and task labels may change, **authority, privacy, code and evidence meaning may not**. Consent for one import is not permission for all account, family or team data.
- **FOSS:** publish source, dependencies, licenses, verifiable builds and reproducibility claims only once reviewed; avoid asserting all upstream dependencies FOSS or redistributing private data.
- **Accessibility:** a quiet no-jargon default, keyboard and screen-reader controls, visible progress for a long scan, clear Stop, plain-text fallback, and no forced sign-up or distracting popups.
- **Public-service boundary:** optional hosted execution must be opt-in and separately qualify encryption, retention/deletion, breach response, legal/organizational rights, abuse controls and independent security review. Never send raw archives to an external destination by default.
- **Open exit:** export portable results with source identifiers and provenance; no CoCivium account required to leave or restore elsewhere.
- **Privacy-feedback boundary:** CoEv feedback may share source-free aggregate tests and anonymous voluntary ratings, not titles, conversation content, session IDs, secrets or private paths. Source-bound counterexamples and privacy gates survive cross-theme optimization.

## CoEv learning loop, not a multiplying platform

`THEME_OBSERVATION -> MEASURED_COUNTEREXAMPLE -> COMMON_KERNEL_TEST -> REVIEW -> ONE_VERSIONED_CHANGE -> ALL_ELIGIBLE_FRONTS`

Qualify transfer with a separate test for each affected theme. If improving one reduces another theme’s privacy, accessibility, recovery, or comprehension, hold or split the behavior. Retain minority feedback. Never assume universal superiority to existing provider tools. **Compare** task success, p95 latency, confidence calibration, recovery proof, safety, cost and manual burden against baseline.

Inverse tests:
1. **Remove CoCivium branding:** does plain “Inspect my AI export” still work and earn trust?
2. **Remove cloud / account:** can user inspect and leave with their files?
3. **Remove internet:** can intake run entirely offline?
4. **Remove prior chat:** can a new worker reconstruct the verified result from a local manifest?
5. **Remove backup destination:** must UI retract “protected” claims?
6. **Switch theme during scan:** do source hash, ID count, privacy, and authority remain identical?
7. **Remove AI model:** can the structural census still run deterministically?
8. **Remove all opt-in upgrades:** is the default task independently useful?
9. **Remove original provider:** can one independently restored public-safe WorkID complete a useful task? **Unproven**.
10. **Reverse migration:** can a user take the same portable artifact to a competing tool? **Unproven**.
