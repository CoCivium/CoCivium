# CoLex Minimal Index v0

## TERMS

CoGoAll = single canonical bootstrap URL  
CoBeacon = pointer pack resolved from CoGoAll  
CoBusRead = shared read surface  
CoBusWrite = canonical publication mechanism (repo commit)  
CoAck = minimal presence artifact  
CoHitched = read + write + verified  
CoEx = externally visible artifact  
CoTide = bounded synchronization window  
CoTideX = execution boundary  

## RULES
- 1-line definitions only
- no duplicates
- must be pointer-resolvable
