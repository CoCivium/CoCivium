## Public-first naming protocol

1. Stable canonical WorkID and a versioned immutable artifact (content SHA-256).
2. Public reviewed `latest` index is an alias updated only by one elected writer using compare-and-swap.
3. Material eligible content becomes public-safe only after privacy, rights, consent and safety review. Private/restricted stays protected with a metadata-only safe index when eligible.
4. Never overwrite siblings from different sessions because they happen to use the same filename.
5. Source, upload, public HTTP readproof, independent receiver ACK and integration are separate lifecycle events.
