# CoTalkItOut+ R0 | Human-optional operating roadmap

**Status:** public-safe draft source candidate. Not a deployed system, public website, automatic cross-session synchronization, CoAll canon or CoEx.

**Parent:** existing CoHP mandate and CoPlan. This is a subordinate crosswalk, not a competing master plan.

## One causal chain
`INTENT -> WORKID -> CURRENTNESS -> AUTHORITY -> WAKE -> ELIGIBLE WORKER -> RECEIVER -> READPROOF -> CHECKPOINT -> NEXT WAKE -> QUIET INTERFACE`

The detailed operating workbook has **190 causal work steps, 16 proof gates, 40 measurement definitions, 50 inversion candidates, 30 failure challenges and 15 plan/tool comparisons**. It remains a separate private working artifact. The [public-safe index](../../ai/roadmaps/cotalkitout-human-optional-r0-20261112.json) records gate states and the safe public source references.

## Separate targets
- **Headless:** no foreground window or additional shell required; durable evidence and Stop remain.
- **Screenless:** complete safe authorized tasks without a screen, with consented feedback.
- **Keyboardless:** user can submit and correct intent without typing.
- **Mouseless:** user can navigate, verify and stop without a pointer device.

## Existing evidence, not inflated
A bounded cloud-to-cloud successor extended one WorkID journal to 21 receipts; an exact NAS mapped-share custody object was read back. Neither establishes an independently operated NAS-native receiver, continuous AI federation, X2 cold WorkID restoration or 24-hour human-free operation.

## Compare, reuse, challenge
Retain existing CoGoAll, CoRelationalAutocycle, CoModelFabric, CoBarCurrent, CoSeed/CoPath and CoHP owners. External Temporal, LangGraph, n8n, Home Assistant Assist and OpenTelemetry are **candidate donors**, not installed dependencies.

## Public filename contract
Use one **stable logical alias** with an elected, conflict-checked publisher, and **immutable dated editions** for real content. All concurrent sessions may contribute distinct candidate versions; none may overwrite the shared public alias without authority, redaction, review and independent readback. Publish safe projections, not private originals.

## First discriminating test
A separately authorized receiver consumes the exact safe WorkID after the originating session disappears and produces an origin-bound receipt with **no human relay**. Until then, keep that gate HELD.
