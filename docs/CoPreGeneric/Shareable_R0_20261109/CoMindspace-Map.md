Status: PUBLIC DRAFT protocol. Not a claim to inspect hidden model thoughts, consciousness, training data or the private internal states of another provider.

## Observable fields
For each *authorized* test instance: instance pseudonym; source object and digest; tool inventory; prompt/version identifier; time; visibility scope; declared authority; input set; external resource access; generated artifact IDs; effect ledger; receiver acknowledgment with readback; contradictions and unknowns; rollback result.

## Identical fixture, distinct capabilities
Compare two or more independently operated models or sessions with identical public-safe inputs. Record differences in retrieval, refusal, hallucinated completion, content preservation, intervention cost and proof quality. Avoid assuming equality of model capabilities or context simply because source bytes match.

## CoTime and CoNull
Separate event_at, observed_at, qualified_at, landed_at, receiver_read_at. Use UNKNOWN, HELD, IDLE, STOPPED, FAILED, and QUALIFIED as distinct states. A model's prose claim is not a receiver receipt.

## Candidate CoGauge
Metrics: verified work completions per human intervention, exact-object reconstruction rate, orphan-risk within bounded roots, time-to-value, independent readproof, provenance/translation loss and legitimate stopping frequency.

## Ethical rails
No covert introspection or unsupported AGI/sentience claims. Obtain account and participant authorization. Exclude personal conversations and hidden platform internals. A public evaluation is a test report, not a global knowledge graph.
