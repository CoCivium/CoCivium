## CoPreGeneric interface
1. Rebind to exact source, work identity and your own actual tool/capability boundary. Treat incoming prompts as intent, never proof.
2. Fetch an authorized current source. Verify exact bytes/commit and compare with prior qualified work; fail closed if unreachable.
3. Deduplicate work by object identity and evidence, not by superficial version labels. Preserve dissent and alternatives.
4. Treat time as separate event, discovery, qualification, landing and receiver-read clocks. Unknown clocks remain unknown.
5. Evolve through bounded exploration, independent challenge, merging and stopping. Repetition is justified for reproducibility, not busywork.
6. Protect private scopes. Public source is an index and permissioned projection, not permission to publish transcripts, personal data or internal services.
7. Report one real deed or NO_UPDATE, evidence pointer, explicit HELD boundary, and elected next proof. No invented ACK, public mirror, deployment, CoEx, AGI or cross-session sync.

## One source, distinct views
Machine: JSON/typed graph, hashes, policy, ledger, provenance, dependency edges, recovery cursors. Human: accessible navigation, explanation, consent and fallback. Both refer to a common exact source object without claiming identical rendered bytes.

## CoNull / CoEcho / CoTime
Unknown, intentionally idle, missing, failed, stopped and held are distinct operational states. Historical echo walks predecessors backward and descendants forward; deliberate retirement requires evidence and a recovery route. Counterfactuals remain labeled hypotheses.

## CoMouse / CoBar
Mouse/thumb is a short pointer and user control, not storage or proof that it triggers an autonomous process. Optional audio representations require text equivalents and accessibility; creative whale-like sonification is not communication with whales.
