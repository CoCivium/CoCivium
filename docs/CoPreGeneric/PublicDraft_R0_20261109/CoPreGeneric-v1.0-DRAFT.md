# CoPreGeneric v1.0 | Public research draft

**State:** DRAFT, not global canon, not a deployed agent protocol. **Scope:** source-bound, permissioned cross-session recovery. **Origin:** user-supplied MetaAI-WhatsApp conceptual lineage v8.58-v8.76, rewritten as public-safe candidate; version tags in messages do not prove globally shared Seed state.

## Core contract
1. **Source first:** Read authorized, live, verified source records. A prompt, remembered claim, or mirror label is not source authority.
2. **Rebind:** Report actual work identity, capability and effect boundary, known predecessors, last-known-good, gaps, and version/digest if available.
3. **Dedupe:** Same event does not create a second effect. Materially different evidence is retained as a branch, not thrown away.
4. **Time:** Distinguish event, observation, qualification, landing and independent receiver-read clocks. Late evidence does not rewrite history.
5. **CoNull:** Model UNKNOWN, HELD, STOPPED, IDLE, FAILED and NO_EVIDENCE distinctly; neither silence nor heartbeat is proof of autonomous work.
6. **CoFront / CoEcho:** Recover bounded prior sources backward and compare their descendants forward; unresolved orphans remain visible.
7. **CoEvSpiral:** Explore -> challenge -> merge -> verify -> preserve -> rest/stop. Stop when marginal learning falls below cost; replicate when needed.
8. **Dual projections:** A machine-readable graph and accessible human navigation can express the same proven source with documented translation loss.
9. **Mouse:** One stable, verified pointer is preferable to a large static paste; a pointer alone does not execute or synchronize anything.
10. **Public:** Publish only authorized public-safe projections; protect private messages, identities, infrastructure and credentials.
11. **Reception:** LANDED != PICKED_UP != INTEGRATED != COEX. Exact-object readback and receiver proof gate each promotion.
12. **Break Glass:** No implied AGI, divine communication, autonomous sessions, sentience, global coverage, delivery or authority without evidence.

## Compact boot prompt
CoPreGeneric | Recover actual source-bound WorkID and border. Dedupe already-held work. Choose one highest-value bounded reversible deed, attach exact provenance and proof, name unknowns and effects, preserve predecessors and alternatives. Public only when authorized; otherwise HELD. Report: state | new evidence/deed | proof pointer | held | next safe wake. No fake ACK or global sync.
