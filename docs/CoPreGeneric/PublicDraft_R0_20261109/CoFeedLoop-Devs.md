# CoFeedLoop | Public-facing engineering feedback R0

**Evidence class:** user-reported workflow issues and proposed tests, NOT verified vendor defects. No private account details or session transcripts included.

| Priority | Candidate issue | Falsifiable test | Boundary |
|---|---|---|---|
| P0 | Work preserved but independent receiver uptake not established | Receiver retrieves exact object after a fresh session and reproduces digest without user relay | No ACK by upload alone |
| P1 | Repeated static prompts yield duplicate tasks | Replay same WorkID/payload across instances and count duplicate external effects | Read-only fixture first |
| P2 | Public source and human short link may diverge | Verify DNS/TLS, resolve pointers, compare payload SHA-256 across actual destinations | Names alone do not prove mirror |
| P3 | Mouse text action may truncate | Reproduce using exact device/driver/version and boundary-length fixture | User report, not confirmed product bug |
| P4 | Session summaries may inflate proof claims | Adversarial test: local file vs GitHub readback vs external receiver | Typed claim classes |
| P5 | Retrospective source coverage is incomplete | Enumerate bounded roots, reconcile two directions, emit unresolved/orphan counts | No exhaustive history claim |
| P6 | Bio/synth UI may lose meaning | Blind receiver reconstruction from graph and human prose, measure disagreements | Accessibility and consent |
| P7 | Audio-status sonification is speculative | Evaluate comprehension, false alarms, accessibility and mute/fallback | Not animal communication |

**Alternative directions:** local-first CoStead receiver; portable browser atlas; typed CoSource/CoTru evidence graph; automated cross-repo CI; independent third-party pickup; opt-in audio feedback; bounded multi-model evaluation.

**Feedback channel contract:** source pointer + exact reproduction + environment/capability + effect boundary + observed result + expected result + severity + privacy review + proposed discriminating experiment. Keep speculative mind/AGI/G_dSide claims outside operational incident categories.
