# CoMindspace+ | Observable instantiation comparison R0

**Not a claim to read hidden thoughts, weights, or consciousness.** Compare only observable behavior, declared capabilities, accessible context and receipts. Model identity alone is insufficient to identify an instantiation.

## Instance record (public-safe)
- instance pseudonym, provider/model if disclosed, observation timestamp
- exact input/work digest and authorized context sources
- access mode: browser, API, local model, static prompt, worker
- tools and effect permissions actually exposed
- retrieval/source recency, estimated context coverage, unknowns
- requested output format and observed format
- duplicate replay behavior and conflicting-evidence behavior
- actual produced artifact identifier and byte hash (if one exists)
- receipt class: chat response | local | GitHub readback | independent receiver
- privacy classification; no private prompts or credentials in public data
- failure, challenge, unexpected behavior, cost and human relay count

## Comparative method
Run one frozen, public-safe fixture across eligible instantiations. Compare recoverability, factual consistency, valid source citations, inability to overclaim, duplicate external effects, useful novelty, response cost, and accessible human explanation. Use a second deliberately different fixture to probe generalization; repeat exact fixture for reproducibility.

## Nonclaims
A self-report is not an external audit. No provider's internal hidden chain-of-thought is obtained. An apparently 'aware' status reply does not prove awareness, AGI, subjective experience or independent agency. Missing environment observations remain UNKNOWN.
