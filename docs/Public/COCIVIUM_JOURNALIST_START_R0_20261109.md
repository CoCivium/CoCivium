# The AI Future Nobody Should Own
## Start here: one story, three routes

**CoCivium's journalist onramp R0 | 2026-11-09 | Public review candidate, not a news article or product launch**

**The question:** As AI systems become more capable, can people take their projects, permissions and evidence from one AI provider to another without rebuilding everything by hand?

CoCivium is an **open research attempt** to test that. The present evidence is source code, proposals and bounded tests, **not** an independently proven federated AI product. An investigation is welcome even if it finds the project deficient.

### CoNav+: movement without losing meaning

Every audience route preserves a stable **WorkID** (`CoReach.JournalistReadingSeries.20261109`), the claim/evidence boundary, a link to Home and source pointers. A synth-readable index is a **projection of those same work objects**, not an alternative truth store or permission grant. A missing link, source or currentness signal should produce an explicit HOLD or a safe fallback, not a fabricated answer.

### CoBack+: return without relying on browser history

A simple "back" link returns to this Home. **Contextual return** additionally preserves which item you left, which source version was used, any conflicting claims, the pending question, the receiver and the STOP rule. This R0 stores those requirements in a source-readable [navigation index](../../ai/onramp/cocivium_journalist_nav_r0.json); it **does not** automatically persist a browser, editor or AI chat session's live stack. If a route is lost, revisit Home, select the last verified item and recheck current source. Do not infer that an earlier private context was restored.

### What the reader should *not* infer

CCC and CoEBE are proposed design ideas. CoCivium is not yet an independently qualified consumer MVP. GPLv3 does not make all legal ownership communal. There is no verified cross-provider session takeover, exceptional AI consciousness, implant-free telepathy, extraordinary prediction, journalist endorsement or exclusive newsroom agreement.

**CoBack+ return:** Home is the safe default root for this *press onramp*, not a new CoAll canon, global project authority or installed interface.
