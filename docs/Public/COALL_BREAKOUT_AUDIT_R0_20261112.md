## Part 3 | Five evidence-bound lessons

1. **Public URLs now exist, but usefulness is unproved.** Evidence: 11 CoAcademy page GETs and 37-object [inventory](COALL_BREAKOUT_INVENTORY.csv), no independent user task receipts. **Change:** separate public reachability from actual first-use task completion.
2. **Jargon competes with a simple point.** Evidence: the [spoof lab](https://cocivium.github.io/CoAcademy/coplay/) has a stranger-readable central joke and additional project terminology/navigation. **Change:** external invitation uses zero project terms and links to the already-live joke.
3. **We repeatedly documented far more than we validated with outsiders.** Evidence: the 26 GitHub-source inventory rows versus 11 live website routes, with the audited external-use column unverified for all. **Change:** no new framework explainer before a three-person 30-second test; counts are not a completeness metric.
4. **A browser prototype can demonstrate an interaction without a new agent runtime.** Evidence: the existing spoof, kitten and device-first HTML contain interaction controls. **Change:** choose an already deployed, reversible client-only action rather than wait for universal session orchestration.
5. **Repetition across sessions is not independent distribution.** Evidence: [CoPre's published limits](../../CoPre.md) and [session bootstrap](../../SESSION_BOOTSTRAP.md) require independently proven receiver readback. **Change:** one public WorkID, one elected artifact and exact pickup receipts; no mass re-posting or 30-way task-controller race.

**Stop:** Introducing new terms as prerequisites to public comprehension; equating sources, CI and model agreement with public adoption; serially copying huge context between sessions. **Start:** One existing page, one precise action, three voluntary independent stranger tests and source-linked feedback. **Keep:** Receipts, reversible actions, privacy/consent fences, versions and correction paths.
