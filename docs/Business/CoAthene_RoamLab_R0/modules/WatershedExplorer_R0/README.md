## Purpose

Watershed Explorer is a 60-90 minute inquiry lesson for approximately Grades 7-8 that uses a simple local watershed/stormwater simulation, maps, evidence cards, and optional immersive visualization to help learners reason about:

- where rain and snowmelt go after hitting roofs, roads, lawns and natural ground;
- how hard surfaces change runoff;
- how storm sewers, ponds, creeks and Lake Ontario relate;
- how pollution can move with runoff;
- how a model differs from the real watershed;
- what evidence would help test a prediction.

The module works without VR. A headset is an optional projection, not the lesson.

`VR_NE_LEARNING_BY_DEFAULT`

## Core learning loop

```text
observe local system
-> make a prediction
-> change one variable in a model
-> predict downstream effect
-> inspect evidence
-> identify uncertainty
-> revise explanation
-> choose one real-world observation
```

## Local grounding

Oakville's current public stormwater material says stormwater from precipitation runs off roofs, streets and other surfaces into ditches, drains, creeks and Lake Ontario. The Town reports a stormwater system that includes pipes, catch basins, ponds, creeks, shoreline and ditches.

Conservation Halton currently offers a Grade 8 "Blue Planet" field program at Kelso that includes water-quality testing, watershed concepts and human impacts. This module does not reproduce that program. It treats the program as evidence that a local field-learning extension exists.

## Modes

### Standalone classroom

Required:
- printed or projected watershed map;
- evidence cards;
- learner sheet;
- cups/tray/sponge/foil or digital runoff model;
- facilitator guide.

### RoamLab portable

Adds:
- shared display;
- tablets;
- simple local simulation;
- optional sensors.

### Optional immersive

Adds:
- VR/MR visualization of rainfall, runoff, drainage and creek flow.

The same learning objective must remain achievable without a headset.

## Time

- Setup: 10-15 minutes
- Lesson: 60-90 minutes
- Optional field extension: separate session

## Learner outputs

Each learner/team produces:

1. one prediction;
2. one observation;
3. one revised causal explanation;
4. one uncertainty;
5. one proposed real-world measurement.

## Assessment

This is formative, not high-stakes.

A useful response distinguishes:

- observation from inference;
- model from real world;
- correlation from causation;
- confidence from certainty;
- source from claim.

## Privacy

Default: no learner account, no biometric retention, no recording, no persistent identity.

A team can be identified as `Team A`, `Team B`, etc.

## Accessibility

A non-headset path is mandatory.

Provide:
- seated participation;
- printed/large-text materials;
- captions for audiovisual material;
- tactile/simple physical model where useful;
- shared-display view;
- motion-reduced immersive mode if VR is used.
